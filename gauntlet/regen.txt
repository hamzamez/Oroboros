# The files the gauntlet's harnesses call, each generated from its source by the
# compiler at HEAD. One line per file: target, source, -name, output.
#
# Read by `bash gauntlet/regen.sh`, which writes them, and by `go run ./cmd/check`'s
# gauntlet step, which regenerates them and requires the committed copies to be
# byte-identical (gauntlet/check/README.md). One list, one regeneration
# (cmd/check/gauntlet.go).
#
# A source whose first line says "BUILT WITH `-checked`" is compiled with it, the
# rule the emission sweep uses. A source written `js:PATH` or `java:PATH` is
# PATH, a program written against Go's names, with the host prefix substituted:
# a line `use go` becomes `use HOST`, and every `go.` becomes `HOST.`, the
# derivation jsontok-2026-08-26 §6 recorded.
