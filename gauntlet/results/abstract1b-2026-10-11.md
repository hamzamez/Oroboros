# abstract1b — program declarations as trees; a definition is a named λ

2026-10-11. Step 1b of [spec/abstract.md](../../docs/spec/abstract.md) §13, with
[ADR 0051](../../docs/decisions/0051-a-definition-is-a-named-lambda.md). hamza: *"agreed to all
recommendations, go ahead with 1b"*. It follows [abstract1](abstract1-2026-10-11.md).

## What was built

`core/decl.go` reads a program's declarations into trees.

**The declarations.** Each top-level form becomes a `Decl`:

| form | tree |
|---|---|
| `def` | `DefDecl`, a name bound to a value; a function's value is a `Lam` |
| `sig` | `ClaimDecl` while the file is read, then its definition's `Lam.Claim` (below) |
| `variant` | `VariantDecl`: name, type parameters, constructors and markers in the order written |
| `module`, `use`, `export` | `ModuleDecl`, `UseDecl`, `ExportDecl` |
| `provides`, `prim`, `target` | `ForeignDecl`, the form as written (another reader's, or refused by Load) |
| any other term | `TermDecl` |

**A `sig` is the claim of its definition's λ** (ADR 0051, D1). A `Claim` holds:
- each parameter's set;
- the result's set, whose binder is `result`;
- `where` as φ and `ensures` as ψ.

`carryClaims` moves the claim onto the λ when exactly one claim and one λ definition of its arity share
a name. Anything else stays a `ClaimDecl` for Load, as before.

**D and validation.** D gives the forms back in the order written, the claim where its `sig` stood,
and `toForm` reads them. Each form is first read as today's reader read it, `toForm` on its image, so
every refusal is reported where it was.

**α-equivalent binders.** A claim keeps the names its `sig` wrote, α-equivalent to the λ's (`dot`
writes `p q` over a λ of `a b`), and the position it was written at. Both are there only so D gives
today's forms back.

**The hand-written redex is refused** (ADR 0051, D5). `((fn (x) (again x)) e)` puts a λ between a
loop and its jump. A λ's body is now always an expression, so the jump is demoted and refused, and the
provisional `tlam` and the tail `TRedex` are deleted.

## Planted faults

Each fault was planted in `decl.go` and `go test ./core/` was run; the file was then restored.

| fault | caught by |
|---|---|
| P1 a claim never becomes its definition's | `TestASigIsItsDefinitionsClaim`, the shapes test |
| P2 a claim carried by a λ of another arity | `TestASigIsItsDefinitionsClaim` |
| P3 a claim carried when its name has two claims | `TestASigIsItsDefinitionsClaim`, **after strengthening**: at first the test asked only that *some* claim stay apart, and the second one did |
| P4 a claim written where its definition stands | three tests, the corpus D3 test among them |
| P5 a claim loses its `where` | three tests |
| P6 a positional parameter's set read as named | the shapes test, **added for it**: no program writes a positional parameter, so the corpus test could not fail |
| P7 a variant's success marker dropped | eleven tests |

All seven are caught. Two of them needed a better test first, which is what planting is for.
