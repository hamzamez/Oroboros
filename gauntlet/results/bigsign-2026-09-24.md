# Above the word, one set on every representation

2026-09-24. The build of [ADR 0029](../../docs/decisions/0029-above-the-word-one-set-on-every-representation.md).
It closes the disagreement [contracts-2026-09-24](contracts-2026-09-24.md) §5 named, and a false
proof in ADR 0028 that building the fix found.

## 1. What was measured first

A range above the word is enforced at run time, once per program, at the largest bit length any
signature declares (bigrepr-2026-09-03 §3a). bigrepr's theorem said the limb rung and the host rung
admit the same **magnitudes**. Nothing said what they admit for a negative value. Three probe
programs, `b = 201`, on the three targets with a bignum and on fixed limbs forced on each:

| representation | check | admits | a negative intermediate in `(int 0 N)` | −2²⁰¹ in `(int −2²⁰⁰ 2²⁰⁰)` | −2²⁰⁰ in the same |
|---|---|---|---|---|---|
| Go `math/big` | `BitLen() > b` | (−2ᵇ, 2ᵇ) | answered | trapped | answered |
| Java `BigInteger` | `bitLength() > b` | [−2ᵇ, 2ᵇ) | answered | **answered** | answered |
| JS `BigInt` | `(x >> b) !== 0n` | [0, 2ᵇ) | trapped | trapped | **trapped** |
| fixed limbs | the final borrow | [0, 2ᵇ) | trapped | trapped | **trapped** |

One legal program, three outcomes. The last column is the worst: limbs trapped on a value inside
the program's own declared range.

## 2. What failed first: a false proof in ADR 0028

Writing the rule for a declared result found that ADR 0028's reading of `(the T e)` was false. It
took the ascription to mean "e is in T's set". But the bound is enforced once per program, so a
result declared `(int 0 (pow 2 100))` in a program whose widest type is `(pow 2 200)` is checked
against 2²⁰¹:

```lisp
(sig h ((n (int 0 1))) (int 0 (pow 2 100)))
(def h (n) (* (pow 2 150) (+ n 1)))
(sig g ((x (int 0 (pow 2 100)))) (int 0 (pow 2 200)))
(def g (x) (+ x 0))
(export calc)
(sig calc ((n (int 0 1))) (int 0 (pow 2 200)))
(def calc (n) (g (h n)))
```

This compiled without `-checked`, and at run time `g` received 2¹⁵⁰, twice. It was a declared
parameter range proven by a fact that was not true. It is refused now, naming `g`'s parameter.

## 3. What is built

- **The set.** H = {[0, 2ᵏ)} ∪ {(−2ᵏ, 2ᵏ)}, the sets a sign and a bit length decide, each in O(1)
  on a sign-magnitude integer. A type above the word denotes the least member of H containing it. The
  program enforces the join over all its types (`emit.BigHull`).
- **Two checks.** `big-fit` is [0, 2ᵏ) and `big-fit-signed` is (−2ᵏ, 2ᵏ), declared per host:

  | | `big-fit` | `big-fit-signed` |
  |---|---|---|
  | Go | `Sign() < 0 \|\| BitLen() > k` | `BitLen() > k`, as before |
  | JS | `(x >> k) !== 0n`, as before: the shift floors | the same on the magnitude |
  | Java | `signum() < 0 \|\| bitLength() > k` | `bitLength() > k`, excluding −2ᵏ by its lowest set bit, reached only at length k |
  | limbs | the borrow, as before | not realized |
- **Limbs.** They hold a magnitude, so a signed program takes the host's bignum (`BigRepr`). On a
  target with none, which is `windows`, it is refused at compile time, naming the reason.
- **The ascription.** It is discharged in `requires.go` before the interval analysis, and only when the
  program's set lies in the parameter's. It is not interval evidence, so it left `provenIn`.
- **The differential harness reads a trap.** A run stopping with the bound's own message answers
  what it printed, then `trap`. Before this a case could only print values, so the one outcome this
  change is about could not be stated as an expected answer.

## 4. Checked, and how each check fails

Two differential cases, each printing values and then trapping:
- `big-sign`: a signed range, with −2²⁰⁰, −(2²⁰¹ − 1), then the edge −2²⁰¹;
- `big-negmid`: a negative intermediate in `(int 0 N)`, on host and limbs.

`emit/bigsign_test.go` has four tests. Every rule was removed in turn:

| rule removed | caught by |
|---|---|
| Go `big-fit` tests the sign | `big-negmid`: go/host disagrees |
| Java `big-fit` tests the sign | `big-negmid`: java/host disagrees |
| Java `big-fit-signed` excludes −2ᵏ | `big-sign`: java prints −2²⁰¹ |
| JS `big-fit-signed` shifts the magnitude | `big-sign`: js traps on −2²⁰⁰ |
| the program's set has a sign | `TestTheEnforcedSetHasASign` and two more |
| a signed program leaves the limbs | `TestTheLimbsHoldOnlyANonNegativeSet` |
| a limb-only target refuses a signed program | the same test (windows) |
| a signed program gets `big-fit-signed` | the same test |
| a type's set has a sign | `TestTheSignIsPartOfAParametersSet` (literal −5) and the ascription test |
| an interval is read with the sign | `TestTheSignIsPartOfAParametersSet` (n ∈ [−5, 5]) |
| the ascription is the program's set, not its type's | `TestADeclaredResultIsAFactAboutTheProgramsSet` |
| H's order keeps the sign | the same test (a signed program) |

The first attempt at the sixth plant deleted a line and broke the build. That is a failure to
compile, not a test catching anything, so it was re-planted as a disabled condition; the test caught
it.

## 5. What it cost

- **Emission:** 10 files change, each only by the sign test: Go and Java for `render` (the example
  and the differential case), `fact-limbs`, `big-divmod` and `big-subdiv`. The two new cases add 8. Every other file is
  byte-identical, and JS is unchanged because its shift already said [0, 2ᵏ).
- **Proof counts:** unchanged, 2,387 of 2,434 operations and 349 of 387 loops. No program in the corpus
  declares a signed range above the word, or two big bounds.
- **Compile time:** the sweep flagged `freq` on JS at 1.58×. Serially, warm, against a baseline
  worktree: 7.43 s against 7.54 s (medians of five alternating runs), with identical output. The
  change touches `freq` only through a walk that finds nothing to do.
- **Run time:** the gauntlet's bounded factorial, 200!, one check per multiply, the references
  (`gen_bigbounded.go`, `GenBoundedFactLimbs.java`) regenerated, old against new, alternating on an
  idle machine:
  - Go: median 2,413 ns before and 2,475 ns after, 15 runs each, 1.03×;
  - Java: median 5,274 ns before and 5,344 ns after, 5 runs each, 1.01×.

  Both are well under the 15% noise floor. A first Go measurement, taken while the check's sweep
  ran in parallel, read up to 2.4× and was discarded.

## 6. Not built, and named

- **A declared big result narrower than the program's widest is not enforced at its own bound.** `h`
  above is not refused. Only the use of its result as a proof is. Enforcing each result at its own
  bound would make the ascription mean its type. On limbs, whose width is one per program, it needs a
  narrower-bound test the library lacks, and no program declares two bounds.
- **`(int 0 +inf)` enforces nothing**, so a negative value in a declared ℕ is admitted on every host.
  Every host admits it, so nothing disagrees; enforcing the sign alone would be O(1).
- **Signed limbs.** A signed program on `windows` is refused until the limb library carries a sign.
