# The book's wrong answers: eight programs the compiler accepted and should not

Date: 2026-11-15. Plan item 3, from [docs/book/README.md](../../docs/book/README.md)'s findings.
hamza: "go ahead with item 3, always mathematical and algebraic". [ADR 0114](../../docs/decisions/0114-a-fold-is-an-equation-between-pure-terms.md)
for the one decision among them.

**Each of the eight reproduced at `afb5325`, and each is now refused or computed as the language
says.** Each has a witness whose planted fault restores the wrong answer, and a correct twin that
still builds. The corpus's emission is byte-identical: no program the compiler builds relied on
any of them.

## The algebra, one rule each

|---|---|---|---|
| 19 | `fn f(c ∈ Bool) (Int) { if c { 1 } }` returned 0 when `c` was false | 1 = {()} is the terminal object, disjoint from ℤ. A one-armed `if` is `if c {a} else {()}`, typed A ∨ 1, so it is no Int. | 10 | `fn nothing(n ∈ 0..9) () { n }` returned n | a declared `()` is a claim decided at the definition (ADR 0072). ## What failed first

1. **The unit fix refused a correct `() { () }`.** The IR has no unit sort and represents 1 by
   {0} ⊂ int, so its sort check read the claim as violated. `claimSorts` now accepts an integer
   yield for a declared `()`: the core checker, where 1 is a sort, has already decided it.
2. **`TestASetsNameDenotesASet` refused `fn d(b ∈ Array(F64) linear) (()) { () }`.** The state
   translation's value of a lending definition is the buffers, B × 1 ≅ B, so a declared `()` beside
   a lent buffer is now read as no factor.
3. **Case-exact resolution passed a program that never used the module.** A path with no file is
   one the target provides, so `use Geometry` alone is refused only when a name from it is used.
   The witness uses `Geometry.area`.
4. **The module-block plant was invisible to the first two witnesses I wrote.** A module sees the
   root's bare names, and an export is emitted under its last segment, so neither "helper is
   unbound" nor the emitted name told `run` in the root from `run` in `inner`. A name defined in
   both, `k`, does: u · 2 from the root, u + 1 from the block.
5. **The literal plant was read once.** A map initializer reads a variable when the package
   initializes, so the fault now sits in the rule that reads the map.
6. **The book's witnesses could not build in a temporary directory.** A variant's name is read from
   the repository's `lib/`, which is found from the source's directory, so they compile under
   `cmd/gen`.

## Paid and bought

- **Compile time**: 1.02× the baseline by the median, and no program confirmed slower (the gate's
  paired run).
- **Run time**: none measured, and none expected. The emitted text is byte-identical on every
  target.
- **Code size**: unchanged.
- **Proofs**: 6,977 of 7,031 operations and 747 of 785 loops, unchanged.
- **Refusals changed**: none in the corpus. Eight shapes that were accepted are now refused: the
  seven above, and the impure fold, which now leaves the call.
- **Emitted text changed**: none, on all four targets.
- **Compiler lines**: +183 / −6 non-test (`core/read.go`, `core/reduce.go`, `core/jparse.go`,
  `core/source.go`, `emit/check.go`, `emit/tabletype.go`, `emit/retract.go`, `ir/claim.go`).
  Tests: 230 lines.
- **Language lines**: none.
- **Rules made more general**: Σ_L has its literals; a module path is resolved by the source alone.
  **Less general**: `len` and indexing no longer take text. That is what state.md §3 already said.
- **The book**: every written chapter still passes its checker (chapters 0–4 and 6, 309 blocks).

## What was not built

- **A string's length.** The scalar count, len : Σ\* → (ℕ, +), is a monoid homomorphism every
  host computes (Go's `utf8.RuneCountInString`, iteration by code points on JavaScript,
  `codePointCount` on the JVM). Whether the language has it is strings.md's question for hamza.
- **A lending header's `()` checked on R.** B × 1 ≅ B makes it no factor, so a body yielding a
  value beside its buffer meets only the arity check. I could not exercise that check, because a
  `var` scope whose value is the unit is refused first.
- **A module path in a target's own loader** (`-target=Windows`): a target is named by a flag, not
  by a program, so it is left to the file system.
