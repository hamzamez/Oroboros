# A differential case is held to proving its arithmetic

2026-09-24. Item 2 of the list of things to close before the next package: no step checked whether
a differential case's integer operations are proven.

## 1. The gap

- The differential harness builds every case with `-checked` (run.go says why: ten of the first
  sixteen cases had no signatures, and it exercises the rebuild path).
- `-checked` turns an operation the compiler cannot bound into a trap, and the answer stays right.
  So the harness could not see a lost proof.
- The emission sweep compiles each case on its own, without the harness's `main`. A case without
  `(export …)` emits an empty package. `u128-fact`'s baseline is three lines.

**Witness.** Replacing the remainder's transfer function with ⊤, the harness at HEAD reports
`ok u128-fact` and `ok u128-ops`: the u128 arithmetic, written to be proven, lost its proofs,
became run-time checks, and passed.

## 2. What is built

- **`cmd/build -checked` says what it took**: `note: -checked: N of M integer operation(s) are traps,
  not proofs`. It is the same verdict the build without `-checked` refuses on, computed at the same
  point, so one build answers both questions.
- **A case declares where it is allowed to be unproven**, with the reason:
  `; checked: windows — why`. The harness holds it in both directions:
  - a target that took a trap and is not named fails;
  - a named target where everything is proven fails as stale.

  The reason is required, and an unknown target is refused.
- The build stays `-checked`, so the rebuild path keeps its coverage.

## 3. What the measurement found

40 cases on their non-skipped targets, plus the representation variants. **Seven cases, 17
case×target builds, took traps.** Each was read, and the unproven operations traced to a cause:

| case | targets | cause |
|---|---|---|
| `len-bounded` | go js windows | the elements of a table built by a loop of `set`s get no bound; the sum's interval is exactly 5 · (2⁶³ − 1), a trip count times ⊤ |
| `table-alloc` | all four | the same, for `(alloc (table n f))` |
| `map-keys` | all four | `acc·100 + k` grows geometrically, and intervals widen it; windows also has the map cause below |
| `map-dynamic`, `map-len`, `map-static` | windows | in `emit/winmap.oro` the slot count, `len/3`, is not known to be ≥ 1, so the mask `n − 1` may be −1 and `k & −1` is k. **With the slot count known to be ≥ 1, 260 of 260 operations are proven** (measured by clamping it, and reverted) |
| `match` | all four | the desugared guard `(and (= tag 0) (>= v 10))` does not narrow v (its `(- n 10)` keeps −∞ as a lower bound, while the plain `(>= n 10)` clause is proven). So the reset clause `(again 0 0 c)` shows no descent, no loop is proven to terminate, and the counter has no trip bound |

A signature on `run` does not help any of them. `run` is inlined into `main` at literal inputs
anyway, and what is missing is a bound on elements or a narrowing.

An earlier measurement with `cmd/gen` reported 29 refusals. Twelve of them were the measurement's own:
`gen` compiles every export, so a case's `(export run)` was compiled with no signature and an
unbounded `n`. The harness builds `main`, so the figure is the harness's, from `cmd/build`.

## 4. Checked, and how each check fails

| planted | caught |
|---|---|
| `match`'s declaration removed | four targets: "a trap, not a proof" |
| a declaration added to `u128-fact`, which is proven | "names go, and every operation there is proven. Remove it." |
| `cmd/build` stops reporting its traps | every declared case fails as stale |
| a declaration without its reason | refused by the parser |
| the remainder's transfer function is ⊤ | 25 cases, among them `u128-fact`, `u128-ops` and `u64-digits`. At HEAD the u128 cases pass. |

A first compiler plant, the mask's transfer function set to ⊤, was **not** caught. No case's verdict
depends on it: the masks come from `SelectShifts`, which runs after the verdict. That was a bad
plant, not a gap, and the remainder replaced it.

## 5. What it cost

- Emission is byte-identical (a comment is erased), and the proof counts are unchanged.
- The differential suite runs no extra build.

## 6. Not built, and named

Four analysis limits, each now visible in a case's declaration instead of hidden by `-checked`:
1. element bounds for a table built by `set`s or by `alloc (table …)`;
2. geometric accumulation;
3. `winmap`'s slot count ≥ 1: one fact, and three windows cases become proven;
4. narrowing through a conjunctive guard, which every `match` with a literal pattern and a `when`
   produces.

The third is the cheapest to close. It should be derived, not clamped: the buffer's length is
`3 · slots` with `slots ≥ 1` by `build-map`'s construction.
