## The step limit's message, derived

A reduction with no normal form is a path t₀ → t₁ → … that does not end. Its message names the term
being reduced. The error carried the innermost subterm being normalized when the fuel ran out, a
bound variable `k` for Ω. Each enclosing λ then closed it again under its binder (`reclose`), giving
`fn(k) { k }`: a term built by the error's propagation, not one the reduction met.

The honest term is the outermost application on the path, the redex whose reduction did not end.
`normalize` now records each application the error passes through on its way out, so the last one
recorded is the outermost; `reclose` closes that one too. Ω's message quotes Ω,
`fn() { k = fn(k) { k(k) }; k(k) }`, in the block form §1.12 introduces. Y's quotes the call `Y(f)`.
`PlantFuelInnermost` quotes the innermost again, and `TestTheStepLimitQuotesItsRedex` fails with it.

## The note at an undeclared parameter, derived

A table is a function on [0, len) (data.md), so `k(n)` is a table's read and a function's call alike,
and only a set tells them apart. The refiner reads an unclaimed `k` applied to one argument as a table,
the reading it can compile. The note now says:

- `k` has no set;
- if it is a table, declare it;
- if it is a function, a definition compiled on its own (an entry point, or a library's definition)
  cannot take one, since no function of the program's crosses an entry point;
- a definition that is not exported takes one, where it is applied and inlined.
