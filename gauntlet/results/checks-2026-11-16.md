# Two checks for the round's process failures: line endings, and planted rewrites

2026-11-16. Item 3 of [assessment-2026-11-16](../../docs/assessment-2026-11-16.md) §5, from its
§3.2 ("a remembered rule is not a check") and §3.3 ("a planted fault should assert that it reached
its rule"). hamza: "Go ahead, always mathematical and algebraic".

**`cmd/check` has an `endings` step, and every test that plants a fault by rewriting text goes
through `plantOnce`, which fails unless the fragment occurs exactly once.** The first run of each
found something:
- the step found five tracked files that were CRLF in the working tree and clean to git;
- the helper found a witness that had been vacuous for a month. `TestAStaticLambdaPassesASetOn`'s
  rewrite had matched nothing since 6a5c112 (2026-10-16), so it tested no static λ.

## 1. The rules, as sets

- **Line endings.** Let T be the tracked files whose attribute is `eol=lf` and whose index content
  git classes as text (not `i/-text`). Each must lie in the kernel of ν_CR : bytes* → (𝔹, ∨), the
  monoid homomorphism true on 0x0D, as **read from the working tree**. ADR 0091 uses the same shape
  for NUL. `.gitattributes` keeps the repository LF, but the tests read the working tree, and a
  file a tool rewrote with CRLF stays clean to git, because the conversion maps it to its LF index
  copy. T is read off `git ls-files --eol`. The `.bat` and `.ps1` files (`eol=crlf`) are outside
  it, and so is the emission baseline (`-text`), which is compared byte for byte instead.
- **A planted rewrite.** A fault planted by s ↦ s[old := new] reaches its rule only if old occurs
  in s. With no occurrence the "faulted" program is the original, and a test asserting a refusal
  can pass on it. `plantOnce` requires |s|_old = 1: exactly one occurrence, so the rewrite is a
  function of the fragment and changes s.

**Found vacuous: one.** `TestAStaticLambdaPassesASetOn` replaced `fn f(e) { case … }` in `asType`,
which reads `export fn f(e ∈ error) (Bool) { … }` since the snippets moved to J. The program it
checked had no static λ, and its assertion held of the direct call. Restated, it passes: the static
λ instantiates `AsType` at `NumError`. So the vacuity hid nothing wrong this time.

**A plant by flag that reaches no program.** This is a different class, measured because the
assessment named it: `PlantLoopThresholdFault` (per-loop widening thresholds, ir/interval.go). Its
witness lost its assertion when `ascii` became a definition. A full emission sweep with it planted
gave the same 8,852 of 8,906 operations and 924 of 962 loops, and no emission changed. One attempt
at a program within ten minutes found no difference either, because the descending iterations
recover what the jump to ∞ loses. Thresholds are precision (any set is sound), so nothing unsound
ships, but the rule now has no evidence. A witness is owed, offered as a separate task.
