# Every claim is decided where it is written: the book's findings 80 and 81

2026-11-16. Read from the book's findings index at the end of item 3 (assessment-2026-11-16 §3.4:
the index is read at each item's end, and a wrong verdict goes ahead of the plan). hamza: "Go
ahead, always mathematical and algebraic".

**A false claim was accepted without a word in two cases, and both are refused now for a range.** One was a
range with a variable at an end, `k ∈ 0..n = i`, which compiled and returned i. The other was a
binder nothing reads, `k ∈ 0..5 = n; 0`. No answer was wrong, because neither claim was used as a
fact, but the program stated something false and the compiler passed it. Each is now refused, saying
*the claim … is false* or *is not proven*. The true counterparts build.

## 1. The algebra

- **A claim is a formula of the program's text** (ADR 0049): `b ∈ S = e` is e ∈ S, an obligation
  decided or the program is refused. The obligations of P are a function of P (hazard-2026-10-02),
  so they cannot depend on whether S's ends are literals or on whether anything reads b.
- **x ∈ lo..hi is lo ≤ x ∧ x ≤ hi.** With integer ends it is the range mark `#req`, decided on the
  IR's intervals. With a term at an end it is that formula, a where-mark on the value
  (residualRange's shape), decided by the refinement layer, or by evaluation once inlining makes it
  ground. Before, the reducer met the set under its binder with n free, found it no constant range,
  and dropped the claim (`#claim-set`'s "or e when it is not"). A set with a term at an end has no
  representation, so its ascription is its value.
- **β may drop an unread pure argument but not its obligations.** For x ∉ FV(M),
  (λx. M) N → M preserves the meaning, since ε erases marks, but a claim in N is a statement of the
  program. So each obligation mark in N outside a λ moves onto M as a where-mark, whose value is M's.
  The conditions name only what is in scope at M, since N was bound there.
- **A condition reads values, not marks.** A range mark substituted into a condition (a call's
  argument, n ↦ `#req(f, n, 0..10, 3)`) is an opaque atom to the refinement layer, so the condition
  reads the bare value, and the mark becomes its own formula's where-mark around it. The call's
  obligation is kept, and 50 ≤ 3 is a literal.
- **A ground condition is decided by evaluation**, true being its body and false a `#reqfalse` of
  the condition as written, as markWhere decides one at a call.

## 2. What failed first

1. **The label printed de Bruijn indices**, *k ∈ 0..#0.0*, because the reducer meets the set's
   ends as bound terms. D writes the spelling (`lo..hi - 1`) into the mark instead.
2. **c80a's condition held its argument's mark** after inlining. Stripping marks when the claim was
   made was too early, since n is substituted later. reduceCondition now hoists range marks out of
   any condition it reduces.
3. **The unread claim left by a second path**: ADR 0071's β substitutes an argument evaluated at
   most once, and none is at most once. An argument that syntactically holds a claim is normalized
   there and its obligations hoisted. Only those, so dead code is not normalized at large.
4. **A hoisted claim made under a binder became ground later** and was left to the refinement
   layer, *0 <= 50 && 50 <= 5 does not follow*. needsReduction now takes a ground condition.
5. **Ω overflowed Go's stack again** (TestDiagnosticsUnderABinderKeepTheirNames). The claim rule
   was inline in normalizeStep, whose frame every level of a deep reduction pays. It is a function
   of its own, `claimSet`, as the reducer's comment asks of every rule.
6. **windows printed *is false: false***: a condition already decided false was reduced again, and
   its spelling was lost. A `#reqfalse` condition is left as it is.

## 3. The witness

`TestEveryClaimIsDecidedWhereWritten` (cmd/build, Go and windows):
- **refused, saying so**:
  - a variable end at a call (*the claim k ∈ 0..n is false: 0 <= 50 && 50 <= 3*);
  - a variable end unproven, in a loop;

## What was not built

- **An unread binder's claim at a set that is no range**, `s ∈ String = n; 0`, still compiles
  (finding 81's second half). It is a typing claim, which the checker decides on the residual, and
  the residual no longer holds it. Keeping it needs a typing obligation that survives as logic, and
  no form for one exists yet.

- **Finding 45**, a claimed top-level constant nothing reads (`half ∈ 0..cap = cap * 2`): such a
  definition never reaches a residual. Deciding it at its definition is ADR 0072's rule for results,
  carried to constants, and is owed.
- **A dead call's contract**: a pure unread call `x = f(-1); 0` still takes its parameter's
  obligation with it, since only arguments that hold a claim are normalized for their obligations.
  The principle covers it (the obligations of P are P's). Normalizing every dead argument costs
  compile time and is unmeasured.
- **Findings 82–91**, read with these: 82 and 85 are two procedures disagreeing on what they were
  told (a result's claim by intervals alone; a host result's set unknown to the refinement layer),
  and 83 is three missing facts. None is a wrong answer.
