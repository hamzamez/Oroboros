# claimset-2026-10-26: a declared set is a claim, and the facts choose the representation

The 10-24 plan's item 4: ADR 0079, hamza's decision of 2026-10-25, built; then `Nat`.

## 1. What it is

A value v has a proven fact, an interval I(v), and a representation ρ(v) ∈ {S, U, big} (the signed word,
the unsigned word, the rung above, ADR 0033, 0034). A declared set D is a claim: v ∈ D is an obligation
(ADR 0028), a claim decided at the definition (ADR 0072), or enforced at run time above the word where
unproven (ADR 0029). The decision: **ρ(v) = ρ(I(v))**, the least representation holding the fact, and D
enters only as consent, the demand of ADR 0034 (an operation whose fact leaves the word is refused unless
a claim above the word demands its value). **The declaration is the representation only where it is the
fact**: an entry point's parameter (the host passes it, nothing proves it smaller) and result (the host's
view), a host result declared `big`, and a definition's parameter when the definition is checked alone.

## 2. Where the request lived, measured

The plan named ADR 0034's supply rule. It was already right: it reads a parameter only on the function
compiled. A probe of each case found the request in four other places:

| # | where | what it did | fixed |
|---|---|---|---|
| 1 | `ir/lower.go`: an ascription's declared type recorded as its value's | a helper `fn inc(n ∈ Nat) (Nat)` inlined into `f(x ∈ 0..100)` typed the value `big`: `f` computed `x + 1` in the word, widened it with `big-of`, and returned a `*big.Int` | above the word, the ascription's value is its operand's; demand follows the fact |
| 2 | `ir/big.go`: an unclaimed result a word position | `fn inc(n ∈ Nat) { n + 1 }`, checked at its definition, refused for a representation nobody claimed | an unclaimed result is held as its yields are (ADR 0062 item 8) |
| 3 | `emit/check.go`'s `WiderThanWord`, a sort rule on declared types | `fn inc(n) (Nat)` inlined into `f(...) (0..200)` refused although the fact is [1, 101] | deleted: its premise, "this check runs on a residual whose representation PromoteBig has chosen", left with the term promotion in irstep4j; the IR refuses by the fact |
| 4 | `emit/target.go`'s `ty`: a range above the word spelled through `int64` ends | an entry point `e(n ∈ Nat)` printed `func GenE(v0 /*int 0 +inf?*/)`, which does not build; present at HEAD, met by no program | a range above both words spells as the target's big representation |

## 3. The cases, after

| program | ρ |
|---|---|
| `inc` over `Nat`, used in `f(x ∈ 0..100) (0..200)`, or with no result claim | `func GenF(v0 int) int` |
| `export fn e(n ∈ Nat) (Nat) { inc(n) }` | `func GenE(v0 *big.Int) *big.Int`, which builds |
| `fn grow(n ∈ Nat) (Nat) { n * n }` used on `x ∈ 0..2^40` | exact: grow's claim consents, the fact [0, 2⁸⁰] leaves the word |
| `export fn h(x ∈ 0..2^40) { x * x }` | refused, "cannot be proven to stay inside the word": no claim, no consent |
| grow's value at a result claimed `(Int)` | refused by its fact, "WIDENING" |

One definition over ℕ is a word where its arguments are small and a bignum where the host hands it one.
That is what the name `Nat` needed before it could mean ℕ (ADR 0077 item 5).

## 4. `Nat`

Read in a set position as `0..` (`core/jparse.go`), printed by messages for `(int 0 +inf)`
(`core/jshow.go`), quoted by σ_J when a host name is spelled so. The four `examples/big/` results are
`(Nat)`.

## 6. Not built

- A finite claim above the word (`0..2^100`) still selects the limb width on a limbs target from the
  declared bound, which is ADR 0029's one enforced set: the width is the claim's because the claim is
  enforced, not proven. When the facts prove a smaller bound, a narrower width would do; no program asks.
