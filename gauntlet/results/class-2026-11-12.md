# A region is answered by its capacity class (storage for a growing numeral)

Date: 2026-11-12. [ADR 0107](../../docs/decisions/0107-a-region-is-answered-by-its-capacity-class.md),
amending ADR 0100. **The product of a numeral by a word is at parity with Go** (`factm`, 20,000!
mod 10⁹ + 7: 1.6× → 0.99×), by a change of target data alone, the Windows allocator's: no pass
changed. The 23 windows files the emission step compares changed, the allocator's term substituted
into each (ADR 0089); every proof count is unchanged, 5,710 of 5,764 and 649 of 673.

## What was measured first

After ADR 0106 the product's row is the machine's (`mulq`, `add`, `adc`), its digits about 15 ms of
62 (nat64-2026-11-12), and the rest was named as storage: every step of `fact`'s loop makes a table one
digit longer than the one that dies. ADR 0100's token compares n ≤ k, so a growing numeral's dead
predecessor **never** fits, and every step goes to the heap for a block 8 bytes larger than the one
just freed.

The same sequence in C (scratchpad `alloc/b.c`: 20,000 tables of 2 to 4,102 digits, each freed after
its successor is made, `HeapAlloc` on the process heap, cold, three runs):

| sizes | time |
|---|---|
| exact | 66.3, 80.4, 81.0 ms |
| powers of two | 19.3, 19.3, 18.9 ms |

19 ms is what writing the digits costs, so at exact sizes the allocation was 3.5–4.2× the writes.

## The algebra

- **The class map** c(b) = max(64, 2^⌈log₂ b⌉) is a closure operator on ℕ: extensive (b ≤ c(b)),
  monotone, idempotent. Its image is the classes; its kernel, b ~ b′ ⇔ c(b) = c(b′), partitions the
  sizes into intervals (2ᵏ⁻¹, 2ᵏ]. Fragmentation c(b)/b < 2 for b > 64. Segregated fits by powers of
  two (Knowlton 1965; Wilson et al. 1995).
- **Σ_OS's `class` is the capacity**, the kernel of b ↦ (allocator, capacity): c(b) on the heap,
  −⌈b/4096⌉ committed pages on VirtualAlloc, negated so the allocators' classes are disjoint.
- **The law of reuse** (ADR 0107 item 3) is class equality: release(p, b) ; region(b′) ≡ zero(p, b′)
  whenever class(b′) = class(b), since region(b′)'s block is class(b′)'s capacity, its first b′ bytes
  0, and no view reaches past b′. ADR 0100's n ≤ k is the special case b′ ≤ b. A reuse keeps the
  class, so it remains the block's.

## What was built

- `targets/windows/os.oro`: `region` and `region_raw` ask the heap for `heapclass(b)`; `class` is the
  capacity. `heapclass` is a case on b's thresholds, so its range [64, 65536] is the decision's, the
  join of its arms' constants.
- `targets/llvm/lang.oro`: `reuse_fit` and `reuse_fit_raw` take the token when the classes agree.
- `targets/llvm/os.oro`: `class`'s contract restated, its result −2⁶³..65536.
- `targets/windows/kernel32.oro`: `HeapSize`, for the witness, its SIZE_T result read signed (the C
  ABI's result types have no 0..2⁶⁴ − 1; failure is the word's −1).
- **The witness** (`cmd/build/class_test.go`): a program on windows that checks, for every b < 2¹⁶,
  HeapSize(region(b)) ≥ max{b′ : class(b′) = class(b)}, and from 2¹⁶ that the class is negative and its
  pages cover b, printing the count of failures: 0. **The planted fault**, a copy of the target whose
  `region` asks the heap for b exactly under the same classes (the allocator before ADR 0107), prints
  65,525: every size but the eleven class maxima.

## What failed first

- **`heapclass` as a loop**, `loop c = 64, k = 0 { … again(c * 2, k + 1) }`: its result claim
  [64, 65536] was refused, the loop's widened result [64, 131068], since the decision does not
  relate c to k.
- **As a bit smear**, smear(b − 1) + 1, closed and exact: a realization is a term over the host's
  operations (ADR 0089), and `>>` and `/` are themselves realized by terms (`lang.ashr`, `lang.div`).
  Through `llvm.u_lshr`, whose `ensure` states ℤ's `>>`, it failed W5: the realization is substituted
  after the unsigned word is chosen, so a U₆₄ operation meets a word. The case on thresholds needs
  neither.
- **The relational claim** `ensure r >= b` on `heapclass` is not decided (`EnsuresBounds` decides
  constant bounds), so extensiveness is the witness's at run time, not the decision's. No program's
  refusal names it, so the analysis did not grow for it.

## Measured

Serial, interleaved, 21 rounds, each process timed whole from Python; medians, minima in brackets, ms.
`n ≤ k` is the classes with ADR 0100's test kept, `class =` the law of ADR 0107 item 3:

| program | B = 2⁶⁴ (before) | classes, n ≤ k | **classes, class =** | Go `math/big` | ratio to Go |
|---|---|---|---|---|---|
| the product, `factm` | 116 (97) | 74 (56) | **72 (55)** | 73 (57) | **0.99** |
| fact(20,000), printed | 259 (216) | 228 (177) | **219 (180)** | 81 (64) | 2.7 |
| fib(10⁵) | 135 (111) | 128 (102) | **125 (100)** | 67 (52) | 1.9 |
| 2,000 quotients | 180 (141) | — | **185 (150)** | 201 (154) | 0.92 |

- **The product gained 0.62× its time**, as the C model predicted (the allocation was about two thirds
  of it), and is at parity.
- **`fact`** gained the same 40 ms; what is left, 2.7×, is printing (render's quadratic D,
  nat64-2026-11-12).
- **`fib`** gained inside the noise: its sum's dead predecessor already fit (ADR 0100), so the
  allocation was never its cost. What is left is the sum's carry.
- **The quotients** moved inside the noise (1.03× median), each D step's tables of static shape.
- **Class equality against n ≤ k** is inside the noise on all three: the heap's free list serves the
  class either way. It is kept because it is the law (ADR 0107's "Why not").
- An earlier timing from bash, whose own fork and `date` cost about 100 ms a process, read the
  product 269 → 196–207 against Go's 193; the ratios agree.

**The code.** The class's case is substituted at every allocation site, so the emitted LLVM text grows
by about a quarter (`big-signed-ops` 21,807 → 27,332 lines, the sieve 842 → 1,037); the binaries grow
512 bytes each, one section's alignment (`factm` 5,120 → 5,632, the quotients 66,048 → 66,560), clang
folding the chain.

**The compile.** The sweep ran at 2.26× its baseline's median, the machine slower, not the code: of
79 suspects the second sweep kept, the serial pair against `e173ef0`'s `gen` confirmed none. The
accept would have recorded that slow sweep's time for every compile it did not flag, so
`compiletime.txt` was restored to its committed baseline.

## What was not built

- **Static-size tokens across sizes of one class** (R1b's `reuse` between unequal static sizes): every
  R1b token is between equal sizes; the IR would compute the class itself.
- **Reuse across a call** (ADR 0101 step 2, destination-passing): a program function's result is born
  in the callee; with classes the heap's free list now serves it, and nothing measured names it.
- **An allocator of the layer's own**: the process heap's free lists are per size already.
