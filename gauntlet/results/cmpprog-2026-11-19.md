# cmp, on every host: a program first, and the two things it found

2026-11-19. The 10-24 plan's open item "the Go library, program first: `cmp`, two files compared
chunk by chunk", under hamza's standing goal. `examples/io/cmp.oro`, over the portable `os`.

## 1. The program

Two files are read a chunk at a time, 4096 bytes, into two buffers the program lends to `os.ReadAt`
(pread, ADR 0084), at the same offset. The first differing byte is reported by its 1-based offset;
a file that ends first, by an EOF on it; equal files, by nothing. A failure to read is reported by
its kind.
- **The loop carries what the last chunk found.** A host call's value is no loop guard, and a guard
  case's arms are values (ADR 0076 item 4). So the loop's variables carry where the chunk was read,
  how far each file reached and its first difference, and the guards read them at the head. Each
  read's failure is a variant `case`, a tail (ADR 0076).
- **The second read happens only after the first succeeds**, so neither failure goes unused
  (relevance, ADR 0043).
- **The offset is bounded by its own guard**, 2⁵⁰ bytes. The decision does not derive
  off ≤ 4096 · steps, a relation with a multiplier (owed).

## 2. Measured

`TestCmpComparesOnEveryHost` prints the same four lines on Go, JavaScript, the JVM and windows:
`differ: byte 7`, an EOF on the shorter file in either order, nothing for equal files, and
`not-found` for a missing one.

## 3. What it found

- **A wrong answer on the JVM.** `os.ReadAt` on a missing file reported `other`, where every other
  host and `ReadFile` everywhere report `not-found` (errors.md §6: the kinds agree).
  `lib/os/java.oro`'s ReadAt opened a `RandomAccessFile`, which throws
  `java.io.FileNotFoundException`, and the kinds read `java.nio.file`'s exceptions. It now reads
  through `FileChannel`, whose `open` throws `NoSuchFileException` as `Files` does, and whose
  positional `read` is pread itself. `roundtrip` checked the kind only through `ReadFile`, so no
  test had seen it.
- **A count unbounded on JavaScript.** ReadAt's count is declared in 0..2⁵³−1 there, with
  `ensure n <= len(b') && len(b') == len(b)`. The intervals read a primitive's ensure only for a
  single result, so the bound was lost. `off + n` then left JavaScript's word, and the program was
  refused ("a comparison of a value held in the unsigned word as a pair"). The intervals now read an
  ensure over a product's components (`componentEnsures`): the handed-back buffer is as long as the
  argument, and the count is at most its length. This covers the host's call of a borrow, whose
  buffer is the argument's storage in place.
- **A stale skip.** `TestEveryPortableNameRunsOnEveryHost` skipped windows for roundtrip, "waits on
  P8". It runs there since ADR 0113, and the skip is gone.

## 4. The tests

`TestCmpComparesOnEveryHost`, its fault `ir.PlantComponentEnsuresIgnored`, under which the build on
JavaScript must be refused; `TestEveryPortableNameRunsOnEveryHost` now on four hosts.

## Paid and bought

- **Compile time**: 1.04× the baseline in the emission step.
- **Emitted text changed**: cmp is new on four targets. `roundtrip` and `pe` change on the JVM only:
  ReadAt's template, `FileChannel` for `RandomAccessFile`. The component ensures changed no
  existing program's text.
- **Proofs**: 8,987 of 9,041 integer operations proven (the 114 new are cmp's on four targets) and
  950 of 989 loops (cmp's 25, one not proven: a loop the file system drives).
- **Compiler lines**: `ir/interval.go` +150 (`componentEnsures`). Library: `lib/os/java.oro`'s
  ReadAt. Tests +90. The program 75 lines.
- **A rule made more general**: the intervals' reading of a primitive's ensure, from one result to a
  product's components.
