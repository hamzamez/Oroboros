# η for products: a host call's several results at a scope's exit

2026-09-28. Found by rewriting the README's `encoding/hex` program the way a reader would write it:

```lisp
(let src (array 104 105 33)
     (tuple dst n) (build buf (* 2 (len src)) (hex.Encode buf src))
  (io.print-line (os.text-of dst)))
```

It was refused with a message from inside lowering, *"a producer of 1 values bound to 2 names"*.

## 1. What it is

ADR 0031 (tables.md §2.5) types a `build`'s value, not its spelling: an exit gives C₁ × … × Cₘ, each
component a frozen scope buffer or a buffer-free value. `(hex.Encode buf src)` is a term of that type:
the buffer it write-borrows and returns, and an `int`. So the program is legal by the rule as stated.

The implementation finds a product's components through its **tail tuples**, the literal
`(tuple …)` at each exit. The projections, the refinement layer, the checker and lowering all read
them, and a host call's two results are not one.

**η for products** closes the gap. A term of a product type is the tuple of its projections,
p = ⟨π₁ p, …, πₘ p⟩. For a call eliminated by its continuation (ADR 0027) that reads

```
(p ā)  =  ((p ā) (fn (x₁ … xₘ) (tuple x₁ … xₘ)))          when p declares m results
```

The rewrite is sound: the call is still evaluated once, where it was, and its continuation runs once.

## 2. What was built

- **`emit.EtaTails`** runs after reduction and before any pass reads a clause chain. It rewrites each
  exit of a producer that a tuple pattern of m names takes apart, when the exit is a call declaring
  exactly m results. It walks the forms `projectTail` walks: a scope, a `let`, an `if`'s arms, a
  loop's exits and a host call's continuation. It keeps a rewrite only if the producer then projects.
  It runs in `gen`, `build`, `cmd/intervals`, `CheckSignatures`, and the IR tests' pipelines.
- **A named refusal** replaces the internal one. `CheckJoins` refuses a tuple pattern over a scope or a
  loop whose exits are not m-tuples: *"every exit must give m values: a (tuple …) of them, or a host
  call that declares m results"*.
- **The spec**: tables.md §2.5 gains the law, its premise, and where it runs. S and R1–R3 are decided
  after it, on the tuple.

## 3. Witnesses

| rule | planted fault | caught by |
|---|---|---|
| η itself | disabled | `TestAHostCallsResultsAreAProductByEta`, `TestEtaReachesArmsAndLoopExits` |
| a loop's exits are tails | not walked | `TestEtaReachesArmsAndLoopExits` |
| both arms of an `if` are tails | the second not walked | the same, after a case with the call in the second arm was added: the first version put it only in the first arm, and the plant passed |
| a call already under its continuation is not a tail | expanded again | `TestAHostCallsResultsAreAProductByEta` |
| an exit that is not an m-tuple is refused by name | not refused | `TestAnExitThatIsNotAnMTupleIsRefused` (a 3-name pattern over a 2-result call, and a single value) |

**The law's own witness.** The short spelling and the tuple written out compile to the same Go
function, and `hex.Encode` is called once. The arity premise is enforced twice: by `hostTuple`, and
by keeping a rewrite only if the producer then projects.

## 4. Gates

- **Emission is byte-identical** to the baseline over the whole corpus: η changes nothing that
  compiled before.
- **The gate:** the differential suite, the IR step (250 of 250) and the acceptance programs pass, and
  compile time is 1.03×.
- **The README's hex example** is your program. All three of its claims were re-run:
  - it prints `686921`;
  - `(+ (len src) 1)` bytes is refused, the message now naming `buf`;
  - JavaScript refuses it.

## 5. Found, and not built

**A buffer a loop threads does not carry its length to a host call's precondition at the loop's
exit.** In `(loop ((b buf) (i 0)) (>= i 2) (hex.Encode b src) else (again b (+ i 1)))`, the refinement
layer does not learn `len b = len buf`, and refuses `hex.Encode`'s precondition. The same refusal
happens at the commit before the term analysis's deletion (irstep4j), so it is not a regression. It
is the refinement layer's threaded-buffer length, which reaches an index but not this precondition.
Named, and left until a program needs it.
