# The Go target, file by file

2026-09-30. An audit of every file in `targets/go`, before `bufio`. hamza: *"right now they are
misleading."* This records the state found; each file's repair is its own result.

## 1. Method

The Go survey (`gauntlet/stdlib/survey.go`) generates a declaration for every name the host
exports that the declaration format can express: 5,287 across 161 packages. Each hand-written file
was compared with its package's generated file by `agreeAll`, the comparison
`TestHandDeclarationsAgreeWithTheHost` uses, through a temporary test, since deleted. The files with
no host package behind them (`builtin`, `go`, `bigint`, `u64`) were read.

One measurement error on the way: `emit.LoadTarget` prefers a directory to a file of the same name,
so loading the generated `io.oro` loaded the directory `io/` (`io/fs`, `io/ioutil`). The first
reading of `io` and `os` compared the wrong packages. The files were copied apart and the
comparison rerun.

## 3. Wrong claims

1. **`os.WriteFile`'s `perm` is `int`, converted by `os.FileMode(%s)`.** FileMode is a `uint32`, so a
   value outside [0, 2³²) is truncated silently. It is the one type disagreement the comparison found
   (`int` against `fs-FileMode`).
2. **`go.<<` and `go.>>` declare no domain.** A negative shift count panics (the Go specification,
   "Operators": the count must be non-negative). `/` and `%` declare `b ≠ 0`, and the shifts had no
   equivalent.
3. **`strings` declares every result as ours, `string` (Σ*)**, where Go returns B*, with none of the
   justifications ADR 0030 requires of such a narrowing.
4. **`strings.Fields`, `Split`, `SplitN` and `Join` use the host alias `slice-string`**, where the host
   is `(array go.bytestring)`: the other four disagreements.
5. **`os.Getenv` is `pure`** on an unstated premise (no `Setenv` is declared). **`fmt.Scanln` drops Go's
   error.** `fmt`'s printers return `any` where Go returns `(int, error)`.

## 4. Old spellings

- Positional parameters: `fmt` 17 of 17, `strings` 26 of 26, `builtin` 52 of 70, `bigint` 17,
  `u64` 10. A `where` or `ensures` can speak only of named parameters.
- `builtin`'s names per element type (`at-float64`, `make-int`, `set-string`, `append-*`,
  `copy-float64`) and its one map type `map-string-int`: the suffix explosion tables.md §10 records
  the table type constructor deleting. Twelve gauntlet sources in `examples/native/` still call them.
- `go.oro`'s host types `slice-int`, `slice-float64`, `slice-string`, `slice-bool`, `slice-byte`,
  `slice-any`, `map-string-int` and `map-string-string`.
- `fmt`'s arity-numbered names (`Println2`, `Printf3`), standing in for variadics.
- Headers describing a past: `strings` and `fmt` name multiple results, methods and `io.Writer` as
  missing, and all three are built. Four files mention the deleted portable layer or window. `u64`
  and `bigint` cite deleted files (`emit/wordsel.go`, `emit/bigreuse.go`).
- Helpers that are not Go names in Go's modules: `os.err-nil` and `os.text-of`, and `strings`'s
  `concat` and `string-of`, which realize language operations.

## 5. What stops completion

**Work, not walls.** Every name missing from `strings`, `os`, `io`, `bufio` and `math/big` is
declarable by the generator, including `strings.Cut`'s three results and `strings.Builder`'s methods.
What remains is ADR 0022's part: a reader of the host's source, and the claims that follow.

**Walls, library-wide (the survey):** variadic 171 names (nearly all of `fmt`, 1 of 23 declarable),
an interface value 124, a function argument 89 (callbacks, tiers 1 and 2: `strings.FieldsFunc`,
`bufio.Scanner.Split`), type parameters 83 and generic instantiation 30 (`slices`, 0 of 40), and 104
more (`unsafe`, complex numbers, tables of opaque values, map keys not `int`, channels).

**Not surveyed at all:** package variables. `os.Stdin`, `os.Stdout` and `os.Stderr` are declared
nowhere, and the hand-written `os` has no `File`. `bufio` needs `os.Stdin`, and nothing else in its
62 declarable names is a wall: its one function argument, `Scanner.Split`, is not needed for lines.

## 6. The plan, in order

1. The two wrong claims that can change a value: `WriteFile`'s `perm`, and the shifts' domain.
2. The checker for **partial** files: every name a file declares agrees with the host. That would have
   caught (1).
3. Then each file brought up to date, one result each: `os` (with `Stdin` and `File`), `strings`, `io`,
   `fmt`, `builtin` and `go.oro`'s old types (which touch the gauntlet), and the rungs' comments.
   Each file ends complete and checked, or partial and checked with its header naming exactly what it
   declares and what stops the rest.

## 7. Step 1: the two claims, and the compiler bug under one of them

**The shifts.** `go.<<` and `go.>>` now declare `(where (>= b 0))`, the Go specification's domain,
decided as `/`'s `b ≠ 0` is: a literal, a guard, or a refusal (*"go.>> requires -n <= 0, which does not
follow"*).

**`WriteFile`'s `perm` is `(int 0 4294967295)`, and declaring it found a bug in the compiler, not in
the file.** With the range declared, `(os.WriteFile "p" d -1)` still compiled. A host function's
parameter range was read as a type and nothing more. The template's conversion then made it false:
`(bits.Len32 x)` with `x : int` compiled to `bits.Len32(uint32(x))`, which wraps, and answered 32 for
−1. That reached the checked packages too, since `math/bits` narrows nearly every parameter.

The law was already written. ADR 0028 makes a declared precondition an obligation at every call, on
a `prim` as on a definition, and a parameter's range is the same claim as a `where`. For definitions
the reducer marks each ranged argument, `(#req "def" "param" "type" a)`, and `DischargeRequires`
decides it: a literal, the IR's intervals, the refinement layer. Host functions got no marks. Now
`Target.Env` records each host function's ranged parameters (`hostRequires`, skipping a range that
holds the whole signed word, which is vacuous for an `int`), and the same route decides them. The spec
is refinements.md §6b.

| call | now |
|---|---|
| `(bits.Len32 x)`, `x : int` | *"go/math/bits.Len32's parameter x, declared (int 0 4294967295), requires (<= 0 x) … which does not follow"* |
| `(bits.Len32 -1)` | *"… is declared (int 0 4294967295), and a call passes -1"* |
| `(os.WriteFile "p" d -1)` | *"go/os.WriteFile's parameter perm is declared (int 0 4294967295), and a call passes -1"* |
| `(bits.Len32 x)`, `x : (int 0 5)`; `WriteFile` with 420 | accepted |

**Byte-identical over the corpus, and that explained itself.** Every check passes, the acceptance
programs included, with no emission changed. That could have meant the marks never reached a corpus
call. A plant narrowing every host range to [0, 1] refused `examples/u128/factorials.oro`
(`bits.Div64`'s divisor, 10¹⁸) and the `math/bits` acceptance program (`bits.OnesCount16`'s
argument, 65535). So the marks reach real calls, and every existing call is proven inside its range.

| rule | planted fault | caught by |
|---|---|---|
| host ranges are marked (the shipped bug) | not marked | `TestAHostParametersRangeIsAnObligation` |
| `InstallRequires` keeps them | replaces the map | the same |
| a shift's domain is b ≥ 0 | not declared | `TestAGoShiftCountMustBeNonNegative` |

**Found, and queued: the portable `os.WriteFile` gives `perm` three meanings.** Go truncates it
(`lib/os/go.oro` had the same `int`), node passes it as `mode`, and Java **ignores it**: `Files.write`
takes no mode. That is an observable disagreement behind a portable name, which belongs to `lib/os`
and is fixed after the Go target. No program in the corpus calls it.

## 8. Step 2: the checker reads partial files

**The rule.** Write H for a hand file's declarations and G for the generated ones, each a map from
name to declaration. A complete file is checked as before: dom H = dom G, and H(n) agrees with G(n)
everywhere. A **partial** file is checked on what it declares: dom H ⊆ dom G ∪ E, and H(n) agrees
with G(n) on dom H ∩ dom G. E is the exemptions, each a name or a whole module the generator cannot
produce, with its reason. Two guards against a check that cannot fail:
- an exemption for a name the host does declare is an error, so none goes stale;
- the planted mistakes are caught, and in partial mode a *removed* name is **not** an error.

`os` and `io` are checked this way now. `strings` and `fmt` join in their own steps, since each
disagrees with the host today (`slice-string`, the arity-numbered names).

**A fourth justified difference, and the fact it needs.** `WriteFile`'s `perm` is `(int 0 4294967295)`
by hand and `fs-FileMode` on the host. The hand file reads a FileMode's value as an integer of its set
and converts it, `os.FileMode(%s)`. That is right only because Go's `type FileMode uint32`, and the
generated file did not say so. So the survey now states every named type over a basic integer,
`(underlying fs-FileMode (int 0 4294967295))`: 151 of them, read from the manifest's own type lines,
with every other generated line identical. It is a claim the generator can justify (ADR 0023), in a
form the compiler ignores (target-files.md §2a). The checker accepts a hand range R for a named host
type T exactly when R ⊆ underlying(T) **and** the template converts with `T(`.

**A loader fix found by the audit.** An explicit `.oro` path now names the file when a directory of
the same name also exists, which is the case for a generated `io.oro` beside `io/`.

| checker rule | planted fault | caught |
|---|---|---|
| a named integer type admits a range inside its set | never | `go/os` |
| …only when the template converts | conversion not required | `go/os` (the planted mistake is no longer caught) |
| a partial file is judged on what it declares | judged as complete | `go/os`, `go/io` |
| an exemption for a host name is stale | not noticed | `go/os` |
| an exempt name is exempt only by its entry | exemptions ignored | `go/os` |
