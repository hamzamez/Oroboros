# The Go target, file by file

2026-09-30. An audit of every file in `targets/go`, before `bufio`. hamza: *"right now they are
misleading."* This records the state found; each file's repair is its own result.

## 1. Method

The Go survey (`gauntlet/stdlib/survey.go`) generates a declaration for every name the host
exports that the declaration format can express: 5,287 across 161 packages. Each hand-written file
was compared with its package's generated file by `agreeAll`, the comparison
`TestHandDeclarationsAgreeWithTheHost` uses, through a temporary test, since deleted. The files with
no host package behind them (`builtin`, `go`, `bigint`, `u64`) were read.

One measurement error on the way: `emit.LoadTarget` prefers a directory to a file of the same name,
so loading the generated `io.oro` loaded the directory `io/` (`io/fs`, `io/ioutil`). The first
reading of `io` and `os` compared the wrong packages. The files were copied apart and the
comparison rerun.

## 3. Wrong claims

1. **`os.WriteFile`'s `perm` is `int`, converted by `os.FileMode(%s)`.** FileMode is a `uint32`, so a
   value outside [0, 2³²) is truncated silently. It is the one type disagreement the comparison found
   (`int` against `fs-FileMode`).
2. **`go.<<` and `go.>>` declare no domain.** A negative shift count panics (the Go specification,
   "Operators": the count must be non-negative). `/` and `%` declare `b ≠ 0`, and the shifts had no
   equivalent.
3. **`strings` declares every result as ours, `string` (Σ*)**, where Go returns B*, with none of the
   justifications ADR 0030 requires of such a narrowing.
4. **`strings.Fields`, `Split`, `SplitN` and `Join` use the host alias `slice-string`**, where the host
   is `(array go.bytestring)`: the other four disagreements.
5. **`os.Getenv` is `pure`** on an unstated premise (no `Setenv` is declared). **`fmt.Scanln` drops Go's
   error.** `fmt`'s printers return `any` where Go returns `(int, error)`.

## 4. Old spellings

- Positional parameters: `fmt` 17 of 17, `strings` 26 of 26, `builtin` 52 of 70, `bigint` 17,
  `u64` 10. A `where` or `ensures` can speak only of named parameters.
- `builtin`'s names per element type (`at-float64`, `make-int`, `set-string`, `append-*`,
  `copy-float64`) and its one map type `map-string-int`: the suffix explosion tables.md §10 records
  the table type constructor deleting. Twelve gauntlet sources in `examples/native/` still call them.
- `go.oro`'s host types `slice-int`, `slice-float64`, `slice-string`, `slice-bool`, `slice-byte`,
  `slice-any`, `map-string-int` and `map-string-string`.
- `fmt`'s arity-numbered names (`Println2`, `Printf3`), standing in for variadics.
- Headers describing a past: `strings` and `fmt` name multiple results, methods and `io.Writer` as
  missing, and all three are built. Four files mention the deleted portable layer or window. `u64`
  and `bigint` cite deleted files (`emit/wordsel.go`, `emit/bigreuse.go`).
- Helpers that are not Go names in Go's modules: `os.err-nil` and `os.text-of`, and `strings`'s
  `concat` and `string-of`, which realize language operations.

## 5. What stops completion

**Work, not walls.** Every name missing from `strings`, `os`, `io`, `bufio` and `math/big` is
declarable by the generator, including `strings.Cut`'s three results and `strings.Builder`'s methods.
What remains is ADR 0022's part: a reader of the host's source, and the claims that follow.

**Walls, library-wide (the survey):** variadic 171 names (nearly all of `fmt`, 1 of 23 declarable),
an interface value 124, a function argument 89 (callbacks, tiers 1 and 2: `strings.FieldsFunc`,
`bufio.Scanner.Split`), type parameters 83 and generic instantiation 30 (`slices`, 0 of 40), and 104
more (`unsafe`, complex numbers, tables of opaque values, map keys not `int`, channels).

**Not surveyed at all:** package variables. `os.Stdin`, `os.Stdout` and `os.Stderr` are declared
nowhere, and the hand-written `os` has no `File`. `bufio` needs `os.Stdin`, and nothing else in its
62 declarable names is a wall: its one function argument, `Scanner.Split`, is not needed for lines.

## 6. The plan, in order

1. The two wrong claims that can change a value: `WriteFile`'s `perm`, and the shifts' domain.
2. The checker for **partial** files: every name a file declares agrees with the host. That would have
   caught (1).
3. Then each file brought up to date, one result each: `os` (with `Stdin` and `File`), `strings`, `io`,
   `fmt`, `builtin` and `go.oro`'s old types (which touch the gauntlet), and the rungs' comments.
   Each file ends complete and checked, or partial and checked with its header naming exactly what it
   declares and what stops the rest.

## 7. Step 1: the two claims, and the compiler bug under one of them

**The shifts.** `go.<<` and `go.>>` now declare `(where (>= b 0))`, the Go specification's domain,
decided as `/`'s `b ≠ 0` is: a literal, a guard, or a refusal (*"go.>> requires -n <= 0, which does not
follow"*).

**`WriteFile`'s `perm` is `(int 0 4294967295)`, and declaring it found a bug in the compiler, not in
the file.** With the range declared, `(os.WriteFile "p" d -1)` still compiled. A host function's
parameter range was read as a type and nothing more. The template's conversion then made it false:
`(bits.Len32 x)` with `x : int` compiled to `bits.Len32(uint32(x))`, which wraps, and answered 32 for
−1. That reached the checked packages too, since `math/bits` narrows nearly every parameter.

The law was already written. ADR 0028 makes a declared precondition an obligation at every call, on
a `prim` as on a definition, and a parameter's range is the same claim as a `where`. For definitions
the reducer marks each ranged argument, `(#req "def" "param" "type" a)`, and `DischargeRequires`
decides it: a literal, the IR's intervals, the refinement layer. Host functions got no marks. Now
`Target.Env` records each host function's ranged parameters (`hostRequires`, skipping a range that
holds the whole signed word, which is vacuous for an `int`), and the same route decides them. The spec
is refinements.md §6b.

| call | now |
|---|---|
| `(bits.Len32 x)`, `x : int` | *"go/math/bits.Len32's parameter x, declared (int 0 4294967295), requires (<= 0 x) … which does not follow"* |
| `(bits.Len32 -1)` | *"… is declared (int 0 4294967295), and a call passes -1"* |
| `(os.WriteFile "p" d -1)` | *"go/os.WriteFile's parameter perm is declared (int 0 4294967295), and a call passes -1"* |
| `(bits.Len32 x)`, `x : (int 0 5)`; `WriteFile` with 420 | accepted |

**Byte-identical over the corpus, and that explained itself.** Every check passes, the acceptance
programs included, with no emission changed. That could have meant the marks never reached a corpus
call. A plant narrowing every host range to [0, 1] refused `examples/u128/factorials.oro`
(`bits.Div64`'s divisor, 10¹⁸) and the `math/bits` acceptance program (`bits.OnesCount16`'s
argument, 65535). So the marks reach real calls, and every existing call is proven inside its range.

| rule | planted fault | caught by |
|---|---|---|
| host ranges are marked (the shipped bug) | not marked | `TestAHostParametersRangeIsAnObligation` |
| `InstallRequires` keeps them | replaces the map | the same |
| a shift's domain is b ≥ 0 | not declared | `TestAGoShiftCountMustBeNonNegative` |

**Found, and queued: the portable `os.WriteFile` gives `perm` three meanings.** Go truncates it
(`lib/os/go.oro` had the same `int`), node passes it as `mode`, and Java **ignores it**: `Files.write`
takes no mode. That is an observable disagreement behind a portable name, which belongs to `lib/os`
and is fixed after the Go target. No program in the corpus calls it.

## 8. Step 2: the checker reads partial files

**The rule.** Write H for a hand file's declarations and G for the generated ones, each a map from
name to declaration. A complete file is checked as before: dom H = dom G, and H(n) agrees with G(n)
everywhere. A **partial** file is checked on what it declares: dom H ⊆ dom G ∪ E, and H(n) agrees
with G(n) on dom H ∩ dom G. E is the exemptions, each a name or a whole module the generator cannot
produce, with its reason. Two guards against a check that cannot fail:
- an exemption for a name the host does declare is an error, so none goes stale;
- the planted mistakes are caught, and in partial mode a *removed* name is **not** an error.

`os` and `io` are checked this way now. `strings` and `fmt` join in their own steps, since each
disagrees with the host today (`slice-string`, the arity-numbered names).

**A fourth justified difference, and the fact it needs.** `WriteFile`'s `perm` is `(int 0 4294967295)`
by hand and `fs-FileMode` on the host. The hand file reads a FileMode's value as an integer of its set
and converts it, `os.FileMode(%s)`. That is right only because Go's `type FileMode uint32`, and the
generated file did not say so. So the survey now states every named type over a basic integer,
`(underlying fs-FileMode (int 0 4294967295))`: 151 of them, read from the manifest's own type lines,
with every other generated line identical. It is a claim the generator can justify (ADR 0023), in a
form the compiler ignores (target-files.md §2a). The checker accepts a hand range R for a named host
type T exactly when R ⊆ underlying(T) **and** the template converts with `T(`.

**A loader fix found by the audit.** An explicit `.oro` path now names the file when a directory of
the same name also exists, which is the case for a generated `io.oro` beside `io/`.

| checker rule | planted fault | caught |
|---|---|---|
| a named integer type admits a range inside its set | never | `go/os` |
| …only when the template converts | conversion not required | `go/os` (the planted mistake is no longer caught) |
| a partial file is judged on what it declares | judged as complete | `go/os`, `go/io` |
| an exemption for a host name is stale | not noticed | `go/os` |
| an exempt name is exempt only by its entry | exemptions ignored | `go/os` |

## 9. Step 3: `os`

**The algebra first**, and it is the file's header now:
- **(T, error) is Go's encoding of a sum T + E**, and `err-nil` is its discriminant. It belongs to the
  type `error`, so it moved from `go/os` to `go` (builtin). The five acceptance programs that called
  `gos.err-nil` call `go.err-nil`; their own comment already said it was *"a fact about the target
  rather than about a package"*.
- **The file system is a store F : Path ⇀ B*.** `ReadFile` and `WriteFile` are its get and put, with
  the read-after-write law of lenses (Foster et al., 2007), stated, not checkable.
- **A file is a byte stream.** `File.Read` is a write-borrow, B ⊸ B ⊗ int ⊗ error, with io.Reader's
  0 ≤ n ≤ len p; `Write` has io.Writer's n = len b exactly when err is nil. `Stdin`, `Stdout` and
  `Stderr` are declared: package variables, fixed for the process, which the survey cannot generate.
- **The environment is a map E : Name ⇀ B*.** `LookupEnv` is the exact read and `Getenv` is it composed
  with absent ↦ "". With `Setenv` and `Unsetenv` declared, **no read of E is pure**, so `Getenv` lost
  its `pure`: that premise was unstated before.
- **Paths, names, keys and values are the host's strings**, `bytestring`, in both directions (ADR
  0030); ours is accepted wherever B* is, for nothing.
- **`Exit`'s precondition is 0 ≤ code ≤ 255.** On POSIX the status is the code mod 256, so Exit(256)
  exits 0. It is a `where`, not a narrowed type: the checker refuses a narrowed argument type, rightly,
  since a type states the host's domain, and this is a claim beyond it.

**What it declares:** 34 names across `go/os` and `go/os/File` (files, directories, the standard
streams, the environment, the process, the error predicates). 30 are host names out of the 130 the
survey can declare, every one checked against the host; the other 4 are package variables (`Args`,
`Stdin`, `Stdout`, `Stderr`), exempt with that reason. Its header names the remaining 100, in groups. None of them is a wall;
each is work.

**The checker gained a guard the change showed was missing:** an exemption for a name the hand file no
longer declares is dead, and is an error, as a stale one already was.

| rule | planted fault | caught by |
|---|---|---|
| `Exit`'s code is a status | no precondition | `TestExitsCodeIsAStatus` |
| a dead exemption | an exemption for a name the hand file lacks | the checker (`no longer declares it`) |

`gos.text-of`, the other helper, was Go's `string([]byte)`, which `builtin` already had as
`string-of-bytes` over the old `slice-byte`. That is now typed over `(array (int 0 255))`, and the two
acceptance programs call it.

## 10. Step 4: `strings`, and the language's string monoid on three targets

**The algebra first**, now the file's header. A Go string is B*, the free monoid over bytes; ours is
Σ*, held as V = enc(Σ*) ⊆ B*. So every parameter is the host's `bytestring`, ours accepted for nothing,
and a result is ours only where the host maps every input into V. The laws the declarations mean:
predicates as subsets of B* × B*; indexes as byte offsets in [−1, |s|]; `Cut` as the factorisation
s = before·sep·after; `Join (Split s sep) sep = s` for sep ≠ "", so Split is a section and Join its
retraction; a `Builder` as a monoid accumulator, String() = w₁·…·wₙ.

**Which results are ours was measured.** `ToLower`, `ToUpper`, `ToTitle`, `Title` and `ToValidUTF8`
(with a valid replacement) go through `strings.Map`, which re-encodes an invalid byte as U+FFFD. On
1,011,155 inputs none left V, where the control, `TrimSpace`, left it 832,506 times. The measurement is
now a test (`sigma_test.go`). It reads the set of `string` results from the file, so a result made ours
without a witness fails, and its control must leave V or the inputs test nothing.

**What it declares:** 61 host names across `go/strings`, `Builder` and `Reader`, which is all 66 the
survey can declare less the five named below, every one checked against the host as a partial file;
plus `NewBuilder`, which is `new(strings.Builder)`: a construct, exempt
with that reason. Named parameters throughout; the four `slice-string` disagreements are gone (the host's
table is `(array bytestring)`); index results are `(int -1 9223372036854775807)`, `Compare` is
`(int -1 1)`. `Repeat` and `Builder.Grow` declare their counts non-negative. `Repeat`'s other panic,
|s|·count overflowing an int, is a product of two variables, outside the linear fragment, and is named in
the file rather than checked.

**Not declared, and why:** the three `*Special` functions take a `unicode.SpecialCase`, and the only
values are `unicode` package variables; `Replacer`'s methods, because `NewReplacer` is variadic, the one
wall in this package. Not surveyed at all: the functions taking a `func(rune) bool`, which are callbacks.

**`concat` and `string-of` moved to `go`.** They are Go's spellings of language operations, found by
spelling, not part of Go's package. And `string-of` gained a precondition **on Go, JavaScript and Java
together**. η's domain is Scalar = [0, D7FF] ∪ [E000, 10FFFF] (string-operations.md §7), and outside
it the hosts disagree observably: Go gives U+FFFD, JavaScript a lone surrogate or a RangeError, Java an
exception or a lone char. A language operation states one domain everywhere.

**That needed one rule in the refinement layer** (refinements.md §3b). Scalar is not an interval, so
the precondition is a disjunction, and the fragment is conjunctions of linear inequalities. A goal built
by ∧ and ∨ is decided by the right-hand rules of Gentzen's sequent calculus (1935): Γ ⊢ A ∧ B iff both,
and Γ ⊢ A ∨ B if either side follows or the disjunction is an assumption, the same term. It is sound,
and incomplete in one named way: a disjunctive fact is never split. It applies only to a goal containing
a disjunction, so every other obligation is decided as before.

| rule | planted fault | caught by |
|---|---|---|
| a `string` result has a witness | `TrimSpace` declared ours | `TestStringsResultsDeclaredOursLandInUTF8` |
| `string-of`'s domain is Scalar | Go's declared without it | `TestStringOfsDomainIsScalar` |
| a disjunction is proven by a side | never proven; left side only; anything | the same |
| …or by the same-term assumption | the assumption not read | the same (the guarded call) |
| the checker on `strings` | `slice-string`; a wider index; IndexByte as a rune; the wrong callee; a name the host lacks | the checker |

**A harness error of mine, caught before it was recorded.** Three of the first plants did not compile
(a variable left unused), and the harness counted "no failing test" as "survived". Rewritten to compile,
all three were caught; the harness now tells a failed build from a pass.

**What telling the truth about `Fields` found.** With `strings.Fields` returning the host's strings,
gauntlet programs 3 and 4 (`generic-go`, `wordcount-go`) were refused: *"%13 is go.bytestring and flows
into go.inc-map's argument 2, which is string"*. `builtin` declared a Go `map[string]int`'s key, and a
`[]string`'s element, as ours, Σ*, when Go's are B*. `Fields`'s old claim, that its elements were ours,
had hidden that one. Both claims were wrong, and the fix is `builtin`'s: `at-map`, `set-map`, `inc-map`,
`delete`, `at-string`, `set-string` and `append-string` now say `bytestring`. It is the first of
`builtin`'s old-spelling problems to be settled, ahead of its own step.

## 11. Step 5: `io`

**The algebra first.** A Reader is a stream consumed in pieces: Read p fills p[0, n) with 0 ≤ n ≤ len p,
n > 0 delivers bytes even beside an error, and EOF is the one error meaning the stream ended. A Writer
reports n with n < len b ⇒ err ≠ nil. `ReadFull` fills exactly len p or fails; `ReadAtLeast` gives
ErrShortBuffer, not a panic, when min > len p, so neither has a precondition. `Copy` is the fold of Read
into Write until EOF, with a count never negative. `LimitReader`, `TeeReader` and `NopCloser` are stream
transformers; `Pipe` is a synchronous channel. An interface's method set is its companion
(theories.md §3.3), and `include` is theory inclusion: a WriteCloser has a Writer's and a Closer's.

**What it declares:** nine interfaces with their methods; of the 32 declarations the survey generates
for `io`, 19 (10 functions, the three `Seek` constants, and `Pipe`'s two types' 6 methods), every one
checked; and `io.EOF`, five other error values and `Discard`, as package variables. The other 13 are
`CopyBuffer`, which waits on its scratch buffer, and `LimitedReader`, `OffsetWriter` and
`SectionReader`, which need `ReaderAt`/`WriterAt`, with their 9 methods. `Read`-shaped operations are write-borrows, as `os`'s are.

**The interfaces' methods are checked now, and were not.** The generator declares no interface
methods, so the hand-written `Writer.Write`, `Closer.Close` and `ByteReader.ReadByte` were exempt, which
means unchecked. But the manifest lists every interface method: `pkg io, type Writer interface,
Write([]uint8) (int, error)`. The checker now reads those lines, translates each Go type into the hand
files' vocabulary, and compares with the same `agreeOne` as every other declaration. Its own guards: a
method the interface lacks, and a result dropped, must both be refused.

**A *File is an io.Reader, and that is tested now.** `(io.ReadAll (os.Stdin))` over the hand-written
target alone compiles and runs: 9 bytes read, error nil. Before `io` declared anything taking a Reader,
the edge `os.oro` declares could not be exercised.

| rule | planted fault | caught by |
|---|---|---|
| interface methods agree with the manifest | `Writer.Write` without its error | the checker (`go/io`) |
| …argument types too | `ByteWriter.WriteByte` taking a rune | the checker |
| the check can fail | a method the interface lacks; a result dropped | the checker's own guards |

**The view check needed the buffer difference too.** The acceptance programs build with the generated
declarations layered over the hand files, and the loader checks each `implements` edge as a view
(theories.md §6.1). With `io.Reader.Read` declared by hand as a write-borrow, the generated
`strings.Reader.Read`, which takes an `array` because a generator cannot know the host writes, was
refused against it. A buffer and a table of one element are one host slice, declared once as written
and once as read, and the hand-declaration checker already accepts that difference; the view check now
does too (`sameSlice`), with the element still required to agree. Found, not built: the view check
compares a method's single `Result`, so a multi-result method's results are not compared there.

| rule | planted fault | caught by |
|---|---|---|
| a view meets a buffer with a table of its element | the rule off; any two tables | `TestAViewMeetsABufferWithATableOfItsElement` |

## 12. Step 6: `fmt`

**The algebra first.** `fmt` is one function and three uses of it: F : Format × Value* → B*, with
Print = write stdout ∘ F, Fprint = write w ∘ F, and Errorf = error ∘ F. Every one is variadic,
f : A* → B, and the declaration format has none: 22 of `fmt`'s 23 names. A variadic function is a
family (fₙ : Aⁿ → B), one per arity, and each member is a sound declaration of part of the host
function, the **restriction** f|Aⁿ. So the arity-numbered names were never wrong in kind; what was
wrong was that nothing said so and nothing checked them.

**What changed:**
- **The restrictions are complete and checked.** Every printing function is declared at arities 1–3
  (B, B2, B3), 36 in all. The checker reads the manifest's variadic signature, `pkg fmt, func
  Println(...interface{}) (int, error)`, builds f|Aᵏ from the name's suffix, and compares. A statement
  may discard the host's results, and its header says it does: the restriction composed with the
  projection that forgets (n, err). Its guards: an arity not the suffix's, and a name that restricts
  nothing, must be refused.
- **The `Fprint` family** over `io.Writer`, which exists now, returns the honest `(int, error)`: the
  way to see a failed write, which `Println` cannot show.
- **`Stringer`** is declared as an interface, checked against the manifest, and `strings.Builder`
  implements it.
- **`Errorf` is no longer `pure`.** Each call allocates a new error and Go's `==` on errors is identity:
  with e bound once, `(== e e)` is true, and with the call duplicated it is false. Purity licenses
  duplication (ADR 0010), so a value with identity is not pure. **No program can observe the difference
  in this compiler today:** the reducer shares a let-bound call by need whether it is pure or not. A
  witness test was written and removed, because it passed with the fault planted. The claim is
  corrected because a purity bit describes the host function, not one reducer.
- **`Scanln` is removed.** The scan family stores what it reads through a pointer, and the language has
  none: the declaration took an `any`, compiled, and could do nothing. That is a wall, stated in the
  header with the rest (`Append`'s family, left as work; `Formatter` and `State`, which only a
  callback could implement).

| rule | planted fault | caught by |
|---|---|---|
| a restriction agrees with the variadic signature | `Fprintln` without its error; `Sprintf2`'s format as `any` | the checker (`fmt`) |
| the restriction check can fail | an arity not the suffix's; a name that restricts nothing | the checker's own guards |
