# handle — a handle is a host type, and a failed call's handle a niche (P3), 2026-11-20

hamza, 2026-11-20: "Go ahead always mathematical and algebraic", after the recommendation: the plan's
item 2 starting with P3 (ADR 0084 item 10, views-finish-research §1, equality (a) hamza's), with the
book's finding 105 folded in, since TinyRetroPad's save meets it. ADR 0146 states the decision.

## The law

- **A handle kind is a set with one operation**, equality, its carrier the host's: C's own expansion of
  `DECLARE_HANDLE(HWND)`, `struct HWND__ *`, so `set HWND = host "HWND__*"`, and two kinds are one type
  exactly when their realizations are (`typedef HICON HCURSOR`). HANDLE is `typedef void *HANDLE`,
  `host "void*"`.
- **A failed call's handle is a niche**: Option(K) ≅ K ⊎ {none}, realized on the host's pointer set P by
  K ↪ P and a point n_f ∈ P ∖ K, the retraction r_f : P → Option(K), n_f ↦ none, p ↦ some(p). Win32 has
  no niche shared by a type's every function, so n_f is the declaration's: `niche -1` (CreateFileA),
  `niche NULL` (CreateWindowExA).
- **An `_In_opt_` handle parameter is Option(K)**, the same partial isomorphism read the other way, its
  section s(none) = NULL, s(some(h)) = h, r ∘ s = id. The declaration's definition is r ∘ raw ∘ s, the
  identity where a factor is no Option (ADR 0040's construction, `emit/retract.go`).
- **A block's components carry its spine's facts** (finding 105): the strongest postcondition composes,
  sp(let ȳ = v in P, Γ) = sp(P, Γ ∧ ȳ ≐ v), through a host call's continuation and a region's `build`
  to the tail tuple, and x̄ = ē there; the spine's binders are named apart (ADR 0036), so in the
  continuation they stand for themselves, ∃ȳ. sp ∧ x̄ = ē. A branching producer is a join, a
  disjunction, and is read as before.

## What failed first

- **The C ABI refused a kind**: "windef.HWND is no C type". A host type realized `T*` is the triple's
  pointer; and the declaration's set was `windef.HWND` as written, unresolved through its `use`, where
  an alias was resolved. One rule for every set's name.
- **x.null() where an Option is wanted was refused in the lowering's words** ("a producer of 1 values
  bound to 2 names"), and so was a program's own `case` on an Int ("an application of 3"): finding 106.
- **`==` between two windows**: first refused as integer equality; then the lowering's `eq` reached
  IR_P with handles (W5); then the arm's π's, made for an integer comparison, stated a fact the call
  implies nothing about (W6). The rewrite runs after typing, and the π's are renamed away.
- **The callback claims kept their written names** (WNDPROC's `windef.HWND`): resolved by
  `CallbackDecl`'s `resolveSet`, which now resolves a host type as an alias.
- **status-win refused `LineIndex`'s argument unproven**, a misleading first message: the program,
  still in the old form, passed CreateWindowExA's Option(HWND) to `status(h ∈ HWND)`, and the
  refinement layer reported before the checker (finding 107, not investigated).
- **lib/os's `open` returned (Option(H), code)** across a `loop once` join, and `roundtrip` no longer
  reduced within the step limit: the option was eliminated again in each caller, after the join. The
  sum is now eliminated where it is made, as `readat` did, and `open` is gone.
- **The save program met three gaps in turn**: GetWindowTextA's count did not cross its block
  (finding 105, sp); GetWindowTextA's `0 ≤ r`, in an `ensure` holding a formula, reached no linear
  fact, so a segment's formation was refused (the split stage 3 removed as unwitnessed, restored with
  this witness); and ReadFile's count had no bound, then its bound named the `_Out_` cell and not the
  value read.
- **A struct's handle field** (WNDCLASSA's, MSG's, PRINTDLGA's) is a kind that may be NULL, an
  `Option(K)` field: ADR 0136's optional field, not built. The fields stay the layout's `ptr`, and no
  program reads one as a kind.
- **The survey's counts moved**: "callable" 36.2% → 35.7%, 47.6% → 46.6%, "callable and it links"
  31.1% → 30.6%. The survey counted an `_Out_` pointer to a handle as a word's cell while the kinds
  were `ptr` aliases, a call no C type the compiler passes could make (a cell of `ptr` is none): the
  new figures are the more accurate.
- **The prototype check skipped 16 declarations**, every one with an Option, its raw call `#raw:…`
  outside the loop; then panicked in a planted mistake that named CreateFileA by its declaration. Both
  read a raw call as its declaration now.
- **A raw call's name leaked into a refusal**, `#raw:windows/libloaderapi:GetModuleHandleA`; J in
  messages names the declaration.
- **The first full check found four more**:
  - **six tests' programs**, written inside Go test files, passed `x.null()` for CreateFileA's
    template or UnregisterClassA's instance: refused as intended, and rewritten with `expect
    'some(h) = …`, ADR 0057's one way to give up;
  - **a planted fault lost its witness**: `PlantTypingResult`'s was lib/os's `open`, whose unstated
    result took `failed`'s 1..2³²−1 by unification, and `open` is gone. Its shape, a kept `code`
    with an unstated result, is the witness now: twelve 1s, and with the fault twelve 2s;
  - **status-win was refused on gen's path** (`cr.cpMax − start` unbounded) and not on build's: a
    defect older than this step. A struct cell's leaves take their sets from the cell's statement,
    found by `structOfCell`, whose own walk followed statements' regions and not a branch's arms
    (`Then`, `Else`). Nothing made a struct cell in an arm until a `case` on CreateWindowExA's
    Option did. It walks every region now (`Func.Walk`), with `PlantStructCellArmsUnread` and
    `TestAStructCellInAnArmKeepsItsLeaves`;
  - **two compiles were confirmed slower**, windowtext 3.00× and status-win 2.02× paired: the handle
    kinds doubled `tg.Types`, and `tableAlias` built a unifier sorting all of them for every declared
    value. A kind is never a table's realization on LLVM (a table is `ptr`, a kind `HWND__*`), so
    `aliasOf` answers at once, and `tableAlias`, a function of the loaded target and the type, is
    kept. status-win is then 0.76× its baseline; windowtext 2.1× but 185 ms, its program larger (a
    kept `show`, the promise across the block, a `case` on the option);
  - the book's §16.8 refusal shows `len(a) >= 1` among the known facts, the restored split's.
- **Every changed program that runs prints Go's output on windows**, byte for byte: fnv, crc32,
  count, freq, jsonfmt, ledger, roundtrip and wc on one input each.
- **The heredoc trap**, three more times (a `\b`, a `\t`, a `\n`).
