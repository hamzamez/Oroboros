# A program's obligations, in every pipeline

2026-10-02. The hazard [bufio-2026-10-01](bufio-2026-10-01.md) §8 named: *"A declared parameter range
is an obligation only where `InstallRequires` ran."* Closed, by
[ADR 0037](../../docs/decisions/0037-a-programs-obligations-are-in-its-residual.md).

## 1. What it was

An obligation is the domain condition of an application: for f : A → B, the term (f a) denotes only
if ⟦a⟧ ∈ A. So the obligations O(P, T) of a program on a target are a function of the two.

The mechanism (ADR 0028) had a third argument, the pipeline:
- reduction placed a mark only when a driver had called `InstallRequires`;
- a failed literal went to a callback filling a set that driver held, and its mark was dropped;
- every consumer after reduction is transparent to a mark, so one that arrived undecided was read as
  its value and compiled.

`build`, `gen` and `intervals` performed the ritual, so every real compile was checked. `ir.Entry`
called directly and each backend's `FromResidual` were not, and most soundness tests run through
those.

## 2. Measured before

[emit/hazard_test.go](../../emit/hazard_test.go), run against the commit before (`1750e74`, in a
worktree), with one program per kind of obligation:

| | through `ir.Entry` | through `FromResidual` |
|---|---|---|
| `(bits.Len32 n)`, n any `int`, into a `uint32` | compiled | compiled |
| `(bits.Len32 -1)` | compiled | compiled |
| `(digit n)` against `(sig digit ((x (int 0 9))) int)` | compiled | compiled |
| `(digit 12)` | compiled | compiled |
| `(half n)` against `(where (>= x 0))` | compiled | compiled |
| `(half -4)` | compiled | compiled |

The residual carried no mark for any of them. `emit.Refine` read a marked residual without a word,
and the Go printer printed a function lowered with its marks.

## 3. What changed

1. **`Target.Env` installs every contract** (`installContracts`), the host functions' and the
   program's. There is no environment for a target without them, so reduction marks every obligation.
2. **A decided literal is in the term.** One inside its range is discharged by evaluation and leaves
   nothing. One outside keeps its mark, and a `where` that reduced to false keeps
   `(#reqw "def" (#false clause) body)`. `core.Env.OnRequire` and the literal set are gone;
   `core.Env.InRange` decides a literal, and `DischargeRequires` reads the failures from the term.
3. **Deciding is one procedure**, `ir.DecideMarks`: evaluation, the IR's intervals, the refinement
   layer. `ir.Entry` and the four `FromResidual`s call it.
4. **A consumer transparent to a mark requires the marks decided.** `emit.Refine` refuses a residual
   that carries one. Lowering counts the marks it meets, of both kinds, and `ir.ToP`, which every
   printer comes through, refuses a function with a count.

All twelve cells of §2 are refused now, each with the obligation's own message, and the programs
that do bound their arguments compile.

## 4. Witnesses

| rule | planted fault | caught by |
|---|---|---|
| the environment carries the contracts | `installContracts` not called | all three tests, 16 failures |
| a literal outside its range keeps its mark | every literal taken as in range | `TestAResidualCarriesItsObligations`, `TestEveryPipelineDecidesItsObligations` |
| a false `where` keeps its mark | it is dropped | the same two |
| a failed literal is read from the term | the scan removed | `TestEveryPipelineDecidesItsObligations` |
| `ir.Entry` decides | the call removed | the same: refused, by `Refine`'s guard and not by the obligation |
| `FromResidual` decides | the call removed | the same: refused, by `ToP`'s guard |
| `Refine` refuses a marked residual | the guard removed | `TestAnUndecidedObligationIsNotCompiled` |
| `ToP` refuses a marked function | the guard removed | the same |
| a range mark is counted | not counted | the same |
| a where-mark at a tail is counted | not counted | the same |
| a where-mark bound by a `let` is counted | not counted | the same |

The two "decides" rows show the guards doing their work: with the deciding call removed the program
is still refused, by the next consumer, with a message naming `ir.DecideMarks`.

## 5. What failed first

- **A second decider in the refinement layer.** The first form of rule 4 had the refiner's ordinary
  walk prove a mark it met, in the linear fragment, or refuse. A carry chain over `bits.Add64`, whose
  parameters are in [0, 2⁶⁴ − 1], was refused: that bound is above the signed word, the linear
  fragment cannot state it, and the IR's intervals prove it from the declared type. Two decision
  procedures with different verdicts on one program is the hazard in another shape. The layer
  requires its input decided instead.
- **A witness that tested one site twice.** The where-mark count has two sites in lowering, a tail
  and a value. `(+ (half n) 1)` was written for the second, and its plant survived: reduction hoists
  a where-mark out of an operator's argument to the tail. A `let`-bound value keeps it in place.
- **A test whose reference was the hazard.** `TestTheMarksLeaveTheResidualUnchanged` compared the
  discharged residual with "the plain one", reduction under an environment no driver had prepared.
  That environment marks now, so the reference empties the tables explicitly.

## 7. Not built

- **A host function's interval `where` on the IR's intervals** (bufio-2026-10-01 §6). This step
  removes what stopped it. No program refuses for want of it.
- **The two refinement-only test helpers erase their marks**, in sight and with the reason at the
  call: their package cannot import the pipeline that decides. What they test is the layer's own
  rule, a host function's `where`.
