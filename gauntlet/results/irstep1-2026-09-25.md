# IR step 1: lowering, the verifier and the canonical printer, in the compiler

2026-09-25. The first step of ADR 0032's migration, built from [docs/spec/ir.md](../../docs/spec/ir.md).
The IR now exists in the compiler, beside the backends. Every program that emits is lowered, typed,
verified and printed, and nothing any backend emits has changed. Printers come next.

## 2. The typing, stated as algebra

A value's **sort** is the most general unifier (Robinson) of a set of equations over the free
algebra of type constructors: `int`, `f64`, `bool`, `string`, host atoms, `table` (arity 1) and
`map` (arity 2). The equations come from literals, signatures, primitive declarations and the flow
edges of regions.

The algebra is taken **modulo ρ_T's kernel**, where the target declares one:
- `slice-float64 ≡ (array f64)`, inverted over a finite candidate set and only when the inverse is
  unique;
- `big ≡ (array int)` where the target stores big integers as limbs.

`any` is the top of the checker's relation, not a constructor. Buffer and table are one sort, and
bufferness is the least solution of ADR 0018's flow rules. Ranges are not unified: a range is written
only where a definition declares one, since the analyses decide the others (IR_P).

**W5 has two readings**, and the first sweep found why it needs them. In IR_A it compares sorts,
because a range is an obligation (ADR 0028) and not a typing question. `freq` passes an unranged
table to `os.text-of`'s `(array (int 0 255))`, which is well typed with its range proven elsewhere.
In IR_P it is containment, ⟦τ⟧ ⊆ ⟦σ⟧.

## 3. What the sweep found, in order

The first full check lowered 235 of 242 emitted programs. The 7 it refused were three species, each
a claim the lowering had made that the algebra does not support:

1. **JavaScript's `+` over floats was classified as ℤ's `add`.** JS declares `+` over `any`, because
   the host has one number type. An overloaded host symbol is ℤ's operation only when its operands'
   sort is `int`. A primitive whose declaration fixes integer operands is classified at lowering; one
   declared over `any` is lowered as a `call` and **promoted after typing** when both operands are
   integers. Promotion only adds equations, so re-typing reaches a fixpoint. A guard on an overloaded
   comparison still gets its π, which is sound by L9 whatever the sort.
2. **A tuple was recognised by its binder's name**, `#k`. A variant crossing a boundary is
   `(fn (#x) (#x tag payload))` (sums.md), the same product under another hint. A product is
   λk. k a₁ … aₙ with k occurring only as the head, and it is now recognised by that structure.
3. **`len` of a big integer on windows.** With `(big-repr limbs)`, ρ_T realizes a big integer as a
   table, so it has a length (W6), and a limb buffer may flow into a `big` result (W5). Both are
   ρ_T's kernel again. Whether a value has a length is a property of its representation, not of its
   language type.

Then, once the differential runner lowered its cases (§4):

4. **W7 was stricter than the language.** The Windows map library reads `(len m)` after storing into
   `m`. The language's checker allows that because a length cannot observe a store (len ∘ set =
   len ∘ π₁), and `emit/linearity.go` says so. W7 now makes the same exemption, and spec §3 states it.
5. **The verifier's value ids were lowering's, and the printer's were canonical**, so a refusal could
   not be read against its text. Lowering now ends by renumbering in definition order
   (`Canonicalize`, an α-renaming). Doing it in place renamed shared slices twice: a leaf's values are
   an operation's result slice. It builds fresh ones.

## 4. Two soundness bugs in the shipped backends, found by writing the rules down

Neither is fixed here. Each is queued as its own change, with its witness.

- **Bounds-check re-slicing has no premise** (found writing spec §9.4). `emitNarrow` re-slices a
  table `Y` to `len X` without proving `len X ≤ len Y`. The witness in spec §9.4 panics on a legal
  program whose answer is 10.
- **`alloc` of a live buffer aliases it** (found lowering `alloc`). Every backend emits a non-rule
  `alloc` as its argument unchanged. That is η-tab, true for an immutable table and false for a
  buffer. The witness stores 7, allocates, stores 9, and reads the allocated table: Go emits
  `t := b1; b1[0] = byte(9)` and returns 9 where the answer is 7. The IR lowers `alloc t` to its
  meaning, `tabulate (len t) (i ↦ t i)`, and spec L12 states when the copy may be dropped.

## 5. What the check measures now

| | |
|---|---|
| emission | 242 emitted, 278 refused; **byte-identical** to the baseline; 2,007 of 2,054 operations and 343 of 381 loops proven, unchanged |
| compile time | 1.04–1.09× the baseline across three runs, below the rule's 1.5× and noisy at this size |
| `ir` step | **242 of 242** emitted programs lowered and verified; 140 functions, 15,095 operations; print ∘ read ∘ print = print on every one |
| differential | 44 cases, **169 builds**, each lowered and verified before it runs; all agree on four targets |
| `ir` tests | the corpus (14 programs on four targets), the round trip, determinism, the type spellings, and planted faults for W1–W7, W9 and W10, each shown not to fire on the unmutated program |

**The scope, stated.** 128 of the 242 sweep programs emit no function, because they have no export and
no top-level term: the differential cases' entry points are compiled only by their runner. The `ir`
step reports that number instead of counting those programs as coverage, and the runner's check is
what covers them.

**The harness can fail.** A planted refusal of `keys` failed the differential run. The first real run
failed on 7 programs and later on `map-keys` for windows, before each fix.

## 6. Not built

- **IR_P.** Final ranges are not written: the analyses still run on terms. `Options.Decided` writes
  modes from the legality the pipeline already checked: a plain operation is `exact`, because
  `Unbounded` refused otherwise, and a checked primitive is `trap`.
- **`require` and `the` in lowering.** Contract marks are discharged and erased before L sees the
  residual. `the` is lowered, and `PromoteBig` has already erased most ascriptions.
- **A W8 check.** Effect order is the list order, and no pass rewrites the IR yet.
- **Globals.** No program produced one: a free name is refused, and the refusal names it.
- **Printers.** The Go printer (P2's, rebuilt on this package) is step 2.
