# IR step 4d: termination is proven on the IR

2026-09-27. The second analysis ADR 0032's step 4 ports. The term analysis proved **343 of 381** loops
terminating, by size-change termination with interval floors (emit/sct.go, emit/interval.go). **The IR
now proves 359 of 381**, over the same loops, never fewer in any function. `gen` and `build` report
the IR's count, and no longer run the term interval analysis at all: it stays only behind `-irproof`,
as the shadow.

## 1. What termination is, on the IR

Size-change termination (Lee, Jones and Ben-Amram, POPL 2001) in its integer form.
- **One graph per back edge** some execution takes, over the loop's parameters.
- **An arc i → j** says μⱼ after the edge < μᵢ before it (strict) or ≤ (weak), in an oriented measure
  μ = σ·p: σ = +1 for a parameter that never rises, −1 for one that never falls.
- **Theorem.** If every idempotent graph in the closure under composition has a strict arc j → j
  whose measure has a floor at the loop head, the loop terminates. An infinite run factors, by
  Ramsey's theorem, into segments with one idempotent graph, along which μⱼ would fall without bound.
  The floor is the interval domain's post-fixpoint, demanded of the witness only: an unbounded
  accumulator does not carry the argument, so it need not be bounded.

**The port is one observation.** Every arc label is a property of a single quantity the IR already
computes: the step aⱼ − pᵢ at one continue. For σ = +1 the arc is strict when Δ.hi ≤ −1 and weak when
Δ.hi ≤ 0; σ = −1 is the mirror. The step is the symbolic one (`deltaFrom`, against base pᵢ) met with
the difference of the two facts at that continue. So every step law step 4b and 4c built is already a
descent law: `x ± e`, an inner loop's monotone result, a reset below its guard (`match`'s
`(again 0 …)`). The step rule gained only division's two:

- x ≥ 1, b ≥ 2: 0 ≤ ⌊x/b⌋ ≤ x − 1, so ⌊x/b⌋ − x ∈ [−x.hi, −1], since x − ⌊x/b⌋ ≥ x/2 ≥ 1 for x ≥ 2;
- x ≥ 0, y ≥ 1: 0 ≤ x mod y ≤ y − 1, so (x mod y) − y ∈ [−y.hi, −1]. That is Euclid, the example the
  principle was invented for.

Both apply through `u64/`, `u64%` and the right shift (⌊x/2ᵏ⌋), and through a conversion of a value
in S ∩ U, where the residue map is the identity.

## 2. What measuring found

**Parity took four fixes, all in the interval domain, not in the size-change part.**

1. **A nested `where` lost its inner conjuncts.** `gcd`'s precondition is `(and (and …) (and …))`, and
   case-of-case lowered the inner conjunct as a `branch` terminator rather than a yield. `assume` read
   only yields, so `(<= 0 b)` never reached `b`, and the loop's floor was −∞. The law is the
   conjunction's, whatever its shape: assuming a region's boolean true assumes its yield. A region
   that branches with one arm yielding `false` assumes the guard (or its negation) and the other arm.
   `(if x false y)` is ¬x ∧ y.
2. **A single value excluded from itself was not emptied.** In `run(0)` of `match`, v = 0 and the arm
   under v ≠ 0 kept v ∈ [0, 0], so its continue looked live. {k} ∖ {k} = ∅: the arm is dead, no back
   edge is taken, and the loop halts vacuously.
3. **A guard with no π narrowed nothing where the steps are read.** A u64 loop exits on `u64=`, whose
   narrowing `cond` applies only while the arm is evaluated. The quotient law read v's fact afterwards,
   without v ≠ 0. Each continue's steps are now read under its own recorded parameter facts
   (`atContinue`), which is what those facts are for.
4. **A promoted host operation was treated as ℤ's everywhere.** This one is a soundness fix. The 13
   JavaScript functions where the IR first proved more had loops over `js.+`, which lowering promotes
   to `add`. JavaScript's `+` is ℤ's only inside ±(2⁵³ − 1); past it, `x + 1` can be x. Where ℤ's
   result lies in the word the two agree, and elsewhere the value is the host's, of which the domain
   now claims nothing. The same premise guards the step rule. The gains survive it legitimately:
   i < len ≤ max-len keeps i + 1 inside the word.

**Both populations were measured, the lesson of step 4c.**

| population | term | IR | functions short | functions over |
|---|---:|---:|---:|---:|
| `gen`'s exports, 528 runs | 343 of 381 | **359 of 381** | 0 | 13 (all JavaScript, `js.+` loops) |
| `build`'s entry points, every differential case on Go and JavaScript | 227 of 255 | **227 of 255** | 0 | 0 |

On the entry points, three cases first fell short (`match`, `u64-digits`, `u64-values`), which fixes 2
and 3 closed. Operation proofs are unchanged at 2,007 of 2,054.

## 3. Soundness: a false "halts" is the dangerous direction

- **`TestTheClosureDecidesTheTheorem`**: the closure on graph sets whose answers are known. The
  alternating descent and Euclid are proven. A weak self-arc, a strict one with no floor, a swap and a
  descent undone on another edge are not.
- **`TestADivergentLoopIsNotProven`**: seven programs, each with an input on which its loop runs
  forever, each aimed at one law's premise:
  - a descent with no floor, and an ascent with no ceiling;
  - `x / 2` at x = 0;
  - a remainder by a divisor that is not the variable, and a remainder against its dividend
    (x mod 13 = x for x < 13);
  - a reset not below the guard;
  - a parameter that does not move on one path.

  None may be proven.
- **`TestTheLawsProveWhatTheyShould`**: the same shapes with the premise restored are proven, so the
  divergent cases fail for the premise and not for want of a rule.

| law | planted fault | caught by |
|---|---|---|
| the floor | none demanded of a descent | the descent with no floor |
| the ceiling | none demanded of an ascent | a divergent loop proven |
| the arc label | a weak arc labelled strict | the reset not below the guard |
| the quotient law | allowed at x = 0 | `x / 2` at 0 |
| the remainder law | read against the dividend | the remainder cases |
| idempotence | not tested | the weak self-arc |
| composition | strict only when both legs are | the alternating descent (a lost proof) |

The fixes in §2 were run against the loop-rule and interpreter tests of irstep4b and 4c, which pass:
the narrowing's soundness table includes the new ≠ case.

The 11 notes: the eight JavaScript native programs whose loops over a promoted `js.+` are now proven,
and `power.oro` on three targets. Its square-and-multiply loop halves an exponent k ∈ [1, 64] on both
continuing arms, so k/2 < k with floor 0. The term side, whose `acc` and `x` are promoted to arbitrary
precision there, did not prove it.

Compile time fell because `gen` and `build` no longer run the term interval analysis: legality, modes
and termination all come from the IR's one analysis.
