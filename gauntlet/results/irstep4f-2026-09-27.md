# IR step 4f: obligations are discharged by the IR, and an allocation's size is one

2026-09-27. Two changes, one kind of object: an **obligation**, a condition every execution reaching
a point must satisfy for the program to denote (refinements.md §3a), discharged or refused. Step 4f
moves the interval route of a contract's range onto the IR's facts. It also makes an allocation's size
an obligation, which closes the wrong answer queued since irstep3java §3.

## 1. A range obligation, decided by the IR

A range mark `(#req d p τ a)` is the value ⟦a⟧, with the obligation ⟦a⟧ ∈ ⟦τ⟧: an argument inlined
into d's parameter p, declared τ (ADR 0028).

- **Lowering is transparent to contract marks**, which is their meaning. It records the values each
  range mark's argument became, and `Canonicalize` renumbers the record with everything else.
- **`ir.DischargeRanges` decides on their joined fact.** The obligation is on every value the argument
  became, so on the join. A value numbering dropped decides nothing.
- **The sets are defined once**, in `emit.DecideRange`, for every route: [lo, hi] within the word, a
  range containing the word vacuous for an `int`, and above the word the least set a sign and a bit
  length decide (ADR 0029).
- **An obligation on [lo, hi] is two half-lines**, lo ≤ a and a ≤ hi. An end the facts establish is
  dropped, and the other goes to the refinement route as a residual `where`. The routes prove it
  together, as u128 needs: 0 ≤ Rem64(…) from the facts, and Rem64(…) ≤ 10¹⁸ − 1 from Rem64's
  `ensures`.
- **`emit.DischargeRequires` takes the interval route as a parameter**, so `emit` stays independent
  of `ir`. `MeasureRequires` is gone, and `gen -report-requires` reads the IR's verdicts.

**Measured first (ADR 0008).** With the interval route switched off, 10 runs were refused (u128 and
its factorials program, `big-divmod` and `render`), so the route carries real proofs. With the IR's
route, emission is byte-identical and every outcome unchanged.

**ADR 0029 had to be kept by the IR.** Above the word an ascription tells only the one set the program
enforces, not its own type. `h` declared 2¹⁰⁰ in a program enforcing 2²⁰¹ may return 2¹⁵⁰. The IR's
`the` met with the ascribed type, which was harmless while `PromoteBig` removed ascriptions before the
decision. But this route lowers before `PromoteBig`, where it would be a false proof. `the` above the
word now passes its operand's fact alone, and `TestADeclaredResultIsAFactAboutTheProgramsSet` fails
against the old transfer.

## 2. An allocation's size is an obligation

`build` and `tabulate` make a table whose length is exactly the size (tables.md §2.3), and a target
realizes lengths up to max-len_T (§2.3.1): Java's `new T[n]` takes an `int`, so 2³¹ − 1. So the size is
in [0, max-len_T]: **the allocation's domain condition**, discharged or refused. Like an index,
`-checked` does not clear it.

Java realized a size past 2³¹ − 1 as `new T[(int) n]`, of length n mod 2³², so
`(len (build b 4294967297 …))` was 1. That was queued in irstep3java §3. The IR's domain had also been
*assuming* the condition, meeting a build's length with [0, max-len] with nothing proving it; now the
assumption is discharged.

**Measured before refusing:** one program's allocations were unproven, `jsonfmt`, on all three
targets. Its output buffer is sized by `(outlen src)`, whose facts were about
[−4.3 × 10⁹, 4.3 × 10⁹]: past 2³¹ − 1 on Java, and not proven ≥ 0 anywhere. Neither end was true,
and two laws the domain lacked prove it.

- **The relational difference.** If x's step against y is Δ, then `(- x y)` ∈ Δ. The interval
  difference fact(x) − fact(y) forgets that x was computed from y. `(- ni i)`, for a scanner
  ni = tok-end(src, i) started at i, is ≥ 0 by the inner-loop rule, so the counter's step is
  non-negative and the size is ≥ 1.
- **Theorem 1 on a difference.** φ = p − q is a function of the parameters, so Theorem 1 applies to
  it: φ ∈ φ₀ + B·Δφ, and p = φ + q. The step is taken on linear forms (Σ cₐ·atom + an interval), so
  atoms cancel before an interval is taken. At the scanner continue, (n′ − n) − (i′ − i) = pad, where
  interval arithmetic sees pad + (ni − i) − (ni − i + 1) with no cancellation. So n ≤ i + 128·B,
  where the parameter alone gave n ≤ 65663·B. This is the relational counter the term analysis had.

`jsonfmt`'s size is now proven in [1, 8388482], matching the hand derivation (8.45 × 10⁶, a little
tighter since pad ≤ 127), and every allocation in the corpus is proven, on exports and on the
differential entry points.

## 3. Soundness

| rule | planted fault | caught by |
|---|---|---|
| ADR 0029's ascription | read above the word as its own type | `TestADeclaredResultIsAFactAboutTheProgramsSet` |
| the joined argument | only the last value | `TestARangeObligationIsOnEveryValueAndBothEnds` |
| an open end | read as the number canonical form leaves under it | the same |
| a dropped value | ignored | the same |
| the relational difference | the mirror not negated | the scanner shape (loop generator) |
| linear forms | `+` read as `−` | the scanner shape |
| Theorem 1 on a difference | p rebuilt as φ − q; q's own term signed wrongly | tree `run`, the scanner shape |

The first plants of the range route survived: the source-level tests never passed an argument with an
open upper end, nor lowered one mark twice. The verdict was factored out (`argumentFact`,
`decideMark`) and tested directly with two values whose facts disagree, in both orders. The obligation
tests that ran the old route moved to external tests, where they run the drivers' pipeline.

`TestAnAllocationsSizeIsAnObligation` is the queued bug's witness: a size of 4294967297 is refused on
Java and accepted on Go, where max-len is the word; a size that may be negative is refused on both; a
proven one is accepted.

## Correction (irstep4g)

The gates above did not include the acceptance programs, the third population of entry points. There,
`encoding-hex` was refused by the size obligation: its buffer is sized by `hex.EncodedLen`, whose
`ensures` the IR did not read. irstep4g reads a primitive's `ensures`, and the acceptance programs now
run with every change.
