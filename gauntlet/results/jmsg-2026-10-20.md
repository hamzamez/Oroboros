## 1. What a message quotes, and the derivation

A message is a function of the program, and the program is J, so every fragment of the program it
quotes is a rendering in J. There are four kinds, and each has one renderer, not a list of edits:

| quoted | renderer | example |
|---|---|---|
| a name | σ_J, `core.ShowName` | `io.print-line` → `io.print_line`; `go.>=` → ``go.`>=` ``; `num/vec.dot` → `` `num/vec`.dot `` |
| a set | `core.ShowSet` | `int 0 9` → `0..9`; `array int 0 255` → `Array(0..255)`; `int 0 +inf` → `` 0..`+inf` `` |
| a core term | `core.ShowTerm`, `ShowIndex` | `(>= n 0)` → `n >= 0`; `(b i)` → `b[i]`; `((fn (x) (+ x 1)) (f y))` → `{ x = f(y); x + 1 }` |
| a form keyword | the message's own words | `(use go)` → `` `use go` ``; `(implements T I)` → `` `axiom T ⊆ I` `` |

**ShowTerm inverts D on D's image** (spec/j.md §6.1): a redex is a block, a Church tuple its pair,
the connectives and comparisons infix, a right-nested `if` chain a guarded `case`, a loop's arms with
the guards D negated (mkIf's `(if (not c) a b) = (if c b a)`) come back as `!c -> …`. Its law,
**parse_J(ShowTerm(t)) = t**, is tested on every definition the corpus reads to: 492 hold, 100 are
skipped for a compiler-made name (`#w1`, `#place`) or an ascription, which J writes only as a binder's
claim (`core/jshow_test.go`). Two planted faults fail it: `=` rendered as `=` (82 failures) and `-` at
multiplication's precedence (6).

## 2. What failed first

The law found three things the first renderer got wrong, each a term that printed as J and read back
as a different term:

1. **A loop's negated guard.** `!Scanner.Scan(in) -> finish(…)` is D'd to `(if c rest finish)`, so a
   chain whose continuation sits in the then branch printed as `if c { … } else { …again… }`, which J
   refuses (`again` under an `if`). The arm is `!c -> b` and the chain goes on in the then branch.
2. **An integer in a term as a power.** `9223372036854775807 + 1` printed `2^63-1 + 1`, which J's
   reader folds into one literal. A term's integer is decimal; a power is a set's spelling.
3. **A block as a callee.** `{ (n, f) = v; f }(i)` ends a statement at the brace; it is parenthesized.

## 3. What changed

About 130 message sites in `core` (reduce, cell, outcell, place), `emit` (check, tabletype, requires,
refine, linearity, prodresult, product, instance, bigrep, target, alias, companion, constend, retract,
fact), `ir` (final, lower, decide, words, limbs) and `cmd/build`, found by a type-checked scan of every
`Errorf`/`Sprintf` whose arguments hold a term or a tree or whose format names a form (187 sites; the
IR's own text format is excluded). Examples, before and after:

- `in num/vec.dot: num/f64.mul is not bound` → ``in `num/vec`.dot: `num/f64`.mul is not bound``;
- `(use go) matched no file` → `` `use go` matched no file ``;
- `digit's parameter x is declared (int 0 9), and a call passes 12` → `digit's parameter x is
  declared in 0..9, and a call passes 12`;
- `half requires (>= n 0) at a call` → `half requires n >= 0 at a call`;
- `(b i) is an indexing, and (< i (len b)) does not follow` → `b[i] is an indexing, and i < len(b)
  does not follow`;
- `(len …) is int, but string is required here` → `len(…) is Int, but String is required here`;
- `discard it with (ignore …)` → `discard it with ignore(…)`;
- target files: `` `set NAME = host "spelling"` ``, `` `axiom T ⊆ I` is false ``, `` `repr LO..HI word` ``,
  `` `backend NAME` ``, `` `fact max_len (a ∈ Array(A)) len(a) <= N` ``, `` `comma_ok` ``; the refused
  spellings (`int-repr`, `big-repr`, `max-len`, …) name their J replacements.

A host's raw call name (`#raw:go/fmt:Fprintln`) no longer reaches a type error: it is the name the
program wrote (`spelled`).
