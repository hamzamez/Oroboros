# jprint-2026-10-15 — today's corpus printed in J, every comment carried

Step 2 of the plan after ADR 0068 (J is the surface): the printer print_J and the translator
tr_{T→J} = print_J ∘ (id × transport) ∘ μ (abstract.md §9.2, spec/j.md §7), applied to the whole
corpus. The J text is not yet read back; that is step 3, the reader, whose check is that the J tree
desugars to the core term today's notation gives.

## 1. What was built

**2a, the concrete tree** (`core/concrete.go`). abstract.md §9.1's c = (a, g): `ReadConcrete` builds
`ReadTrees`' declaration trees and, beside them, the source span of every tree node and declaration and
every comment as a gap with its position; `ReadRawConcrete` does the same for raw reading, as target
files are read. An ordinary read records none of it: one flag on the reader.

**2b, print_J** (package `j`):
- `doc.go`: Wadler's prettier printer, with Leijen's alternative line and Wadler's fill. A document is
  text, a break, a concatenation, a nesting or a group; documents form a monoid, and layout is a function
  of the document and the width (100), so the printer is deterministic by construction.
- `spell.go`: σ_J (ADR 0067): `-` as `_`, a final `?` kept, a name outside the identifier alphabet or a
  reserved word quoted in backquotes; set names in UpperCamelCase; a literal 2ᵏ or 2ᵏ − 1 from 2¹⁶ up as
  a power.
- `print.go`, `walk.go`: one clause per operator of abstract.md's Σ as `core/abs.go` builds it.

**2c, the translator over programs** (`file.go`, `data.go`): declarations (no library header, `private`
for what a library does not export, `export` for an entry file's entry points, a variant as a set
definition, a definition's `sig` as its header), comments transported by position, and `cmd/toj`, which
prints one file.

**2d, target files and fragments** (`target.go`): the wrapper dropped (the target is the directory), a
host declaration as a definition with a host body and named splices, a static head as a λ returning a λ,
`type` as `set`, `const` with its value as a singleton claim, `implements` as an `axiom` inside its type's
module, the model's data in its own words.

## 3. What printing has to decide, and how it does

**Synonyms print as J's one form with the same D-image** (core/desugar.go):
- a continuation `((f a) (fn (q r) e))` is the binding `(q, r) = f(a)`, since D of a tuple let is that
  application (ADR 0066 item 8);
- a λ applied where it stands is a binding, D of a let;
- a `match`'s patterns are guards over the loop's variables, a name pattern a renaming, as D builds them;
  μ's anonymous state variables (`#m0`) are named after the names their column binds, or `s1`, `s2`;
- a constructor is a tag, `'ok(v)`, `result.'ok(v)`;
- a right-nested `(and a (and b c))` is the chain `a && b && c`, whose D-image is the same; a
  left-nested one keeps its parentheses.

**Today's semantics in J's spelling where an ADR is not built**: a buffer is a binder in the linear mode,
`b linear = array { 0 : _ ∈ 0..63 }`, threaded through a loop, and a store is the call
`store(b, i, v)`; ADR 0052's step will rewrite both into `var b := …` and `b[i] := v`.

**Indexing against application.** J marks indexing (ADR 0050 item 6); today's notation writes `(t i)` for
both, and D reads an index as an application, so the choice never changes a D-image. The printer decides
from evidence in the file: a claim's table or map, a name handed to `len`, `keys` or `insert`, stored
into or copied, a binder whose value is a table former, a scope or a call of a definition returning
data, and a least fixpoint over the file's own calls (what each parameter receives); an application to a
λ is a call. Of the corpus's one-argument applications of a local name, **12 stay undecided** and print
as calls: `f` in `lib/result` and `show` in `tally` are functions, correctly; `a`, `b`, `t` in
`examples/big/limbs.oro` and the differential `big-limbs`, and `nodes` in the JSON tree (twice), are
tables that reach their definition through a tuple pattern or an unclaimed parameter. A typed check of
the marks (an index whose head reduces to a λ, or a call whose head reduces to a table, refused) is the
way to close them, with the reader.

## 4. What failed first

1. **Comments landed inside the first item of their owner.** A line-start item received its document
   already built, so the first statement of a definition took the comment above the definition. Fixed by
   building an item after printing its leading gaps.
2. **A trailing comment added a blank line**: the break it forced was a newline, and the separator added a
   second. A new document, `Force`, keeps its group broken and prints nothing.
3. **An integer past the word printed as Horner's form**, `18446 * 10¹⁵ + …`: the reader writes such a
   literal as a term (bigLiteral). A literal is printed from its source text.
4. **`(implements go/strconv.NumError error)` had no spelling**: an absolute name does not lex in J, `/`
   being division. The inclusion moves into its type's module, `axiom NumError ⊆ error` (a target file
   is the glue of its forms, so a form's place carries nothing), and a name in another module of the
   model is quoted, `` `go/io`.Writer ``.
5. **The spec had five errors**, corrected in spec/j.md: C7, ADR 0064's `MaxRune ∈ {1114111}` written
   before ADR 0065 required a former's keyword (`set { 1114111 }`); a set's carrier and a constant's
   spelling have no host kind; the model's data keeps target-files.md's positional holes, since its forms
   bind no names (§2.12's `"${e} == nil"` was wrong); `max-len` and its kin spell as `max_len`; and
   **G4**, x86's `%u`, a number unique to each use (30 sites), proposed as `${#}`.
