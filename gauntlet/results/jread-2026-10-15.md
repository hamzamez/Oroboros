# jread-2026-10-15 — J's reader: every program and target file reads back to its meaning

Step 3 of the plan after ADR 0068 (J is the surface): parse_J, J's reader, for programs and for target
files. Its law is abstract.md §9.1's R2 on the corpus: for every source s of today's notation,
D(parse_J(tr_{T→J}(s))) = D(μ(s)), so a program compiled from its J text is compiled from what it was.
Step 2 (jprint-2026-10-15) printed the corpus in J; this step reads it back.

## 1. What was built

**The lexer** (`j/lex.go`, spec/j.md §1): identifiers with a final `?`, backquoted names, integers,
floats, strings, TLA+'s symbols and their ASCII names (`\in`, `\union`, `\subseteq`, …, ADR 0065), a
tag `'name` told from a prime `x'` by what precedes it, line comments as gaps, and Scala 3's line rule
(a newline ends a statement unless inside parentheses or brackets, or the line ends in an operator).

**The program reader** (`j/parse.go`): `ReadProgram(src, module, dir, root)` builds abstract.md's
trees, `core.Decl` and `core.Expr`, the same carrier μ builds from today's notation, so D is shared and
nothing below the reader learns which rendering a program was written in.
- A block's statements fold right into scopes (ADR 0054): a binding, a tuple binding, a cell's `var` and
  its write, `try` (ADR 0057) and `expect` each take the rest of the block as their body.
- Expressions by precedence climbing over spec/j.md §3's one table; `&&` and `||` right-associative, so
  that a chain is D's right-nested `and`.
- `^` folds a power of literals, and `+`/`-` beside a folded power fold with it (`2^62-1`), so a bound
  reads as the literal it denotes; a parenthesized power is a term.
- A set's name by the convention's inverse (UpperCamelCase back to kebab-case) only for names the file
  or its imports declare as variants; a host's carrier is not one (`isVariantAt`).
- σ_J⁻¹: `_` is `-`; the wildcard `_` is itself (spec/j.md §1.5, amended below).

**The target reader** (`j/readtarget.go`): `ReadTarget(src, target, root)` reads a target file or a
fragment into today's raw forms, the input `emit`'s loader reads, since Σ_T has no abstract tree yet
(abstract.md §2.6). A host declaration's named splices go back to positional holes (`positionalHoles`):
numbered (`%n`, `%r`, `%br`) where the template splices the result, as x86's do, `%s` in order
otherwise, `${#}` as `%u` (G4), `$${` as a literal `${`, a literal `%` as `%%`. A program's definition
inside a fragment, tally's `provides go tally/host { fn capture(r, s) { … } }`, goes to the program
reader and becomes D of its declaration, which is what the loader makes of today's datum.

**The gate** (`j/via.go`, `cmd/gen`, `cmd/build`): with `ORO_VIA_J` set, a driver reads its entry
source as `core.FormsOf(ReadProgram(Translate(s)))` instead of `core.Read(s)`. `core/concrete.go` gained
`DeclTerms`, `FormsOf` and `ReadDeclTerms`; `core/decl.go`'s `forms` split into `placed` (D of each
declaration, in source order, now a stable sort) and `toForm`.

The checks are `j/read_test.go`'s `TestEveryProgramReadsBackToItsMeaning`, which requires every program
of at least 150, and `j/readtarget_test.go`'s `TestEveryTargetReadsBackToItsForms`, which requires all
of at least 40 and both fragments with definitions.

**What the comparison identifies, and why each law is a law.** Core terms close their λs over indices
(core/term.go), so equal keys are α-equivalent terms. Beyond α the comparator applies exactly these:
- a module's declarations are a multiset, and its export list a set (theories.md §3: a module is the
  glue of its forms);
- `use P` is `use P as last(P)` (ADR 0064 item 3: an import carries its alias);
- a `sig` binds its own parameter names, so they are keyed by position;
- `(pow a b)` of literals is keyed as its value, the literal today's reader also makes of it;
- in a target file, the wrapper goes (the target is the directory), an inclusion stands in its type's
  module (ADR 0064 item 9), several results are one product whether written `(int int)` or
  `(tuple int int)`, and a template's holes are keyed by the parameter each splices, whatever their
  style.

## 3. What failed first

Each of these was a difference in a D-image, found by the comparison, not by reading code.

1. **`store(b, i, v)` read as a call of a definition named `store`**: the transitional spelling of
   today's three-argument `set` (jprint §3) has to read back as `set`.
2. **`a && b && c` read left-nested**; D's chain is right-nested, `(and a (and b c))`. Both
   connectives are now right-associative, as conjunction's associativity permits and D prints.
3. **η applied to every one-argument application** where the indexing evidence said "data": only `t[i]`
   is indexing. An application written as a call stays a call; the D-image is the same either way, but
   the reader may not guess.
4. **A top-level `fn(` was read as a definition missing its name**; it is an expression (a λ standing
   as a term, as in `examples/modules.oro` and `examples/native/filter-go.oro`).
5. **An entry file's `export fn main()` produced no `ExportDecl`**; a library's public names did.
6. **A variant's place** (`At`) was taken after its constructors', so a module section sorted it after
   a definition that used it.
7. **`Unspell("_")` was `-`**, so a wildcard pattern became a name.
8. **σ_J was not invertible**: the four host names holding `_` (`ERROR_FILE_NOT_FOUND` and its kin)
   printed unquoted and read back with `-`. σ_J now quotes a name holding `_`, so an unquoted `_` is
   always 𝒩's `-` (spec/j.md §1.5).
9. **The printer, three places where its output did not parse as it meant**: a block as a `case`'s
   scrutinee (now parenthesized), a cell write as an arm's body (now `{ c := v }`), and a power literal
   as an operand (now parenthesized, since `^` folds).
10. **A claim written apart, a `sig`, names its parameters itself**; the printer put the sig's names in
    `where` and `ensure` beside the def's in the header. It now renames them to the def's (ADR 0051).
11. **Target files**: `repr big host` (a bare `host` is a word, not a host body); a method name read as a
    set name; the reader's set registry not filled for a target file; a host carrier taken for a
    variant; a range whose bound is a literal past the word (Horner's form) printed as a product,
    `Int × 0 × 18446744073709551614` (math/bits `Rem`; `isBound` now admits sums and products of
    literals); `fact max_len (a ∈ Array(A)) …`, the fact's name read as an application.

## 4. Not built

- **The target loader reading J.** `ReadTarget` reads J into today's raw forms; `emit` still loads
  `.oro`. Step 5 switches the corpus, and the loader with it.
- **Library modules through the gate.** `ORO_VIA_J` reads the entry source in J; a module it imports
  (`lib/os.oro`, `lib/result.oro`) is loaded by the module loader from today's notation. Each such module
  is itself in the corpus and reads back to its D-image above, so the gate's result holds for them by
  the test, not by the sweep.
- **The 12 undecided indexing marks** (jprint §3): they print as calls and read back as calls, the D-image
  the same; a typed check of the marks closes them.
- **Arms aligned at `->`**, and Code_T's requirements returned rather than collected in `emit.Imports`.

## 5. What it cost

`go run ./cmd/check -skip tooling` passes with and without `ORO_VIA_J`. Without it, emission is
byte-identical at 1.01× compile time (freq's suspect cleared at 0.99× paired). Through J, compile time
is 1.10×: the translator and the reader run in the driver on top of today's reader, which step 5
removes. Code: `j` +2,729 lines (lexer 248, program reader 1,337, target reader 620, gate 70,
tests 454) and +144 −22 in the printer and translator; `core` +55 −8; `cmd` +12.
