# jswitch-2026-10-16 — step 5a: the corpus is J, and the compiler reads J

Step 5 of the plan after ADR 0068. hamza: "remove it [today's notation]. go ahead with step 5, and it
is still .oro — the language is oroboros after all." Done in two commits:
- **5a, this one**: every `.oro` file in the repository is J, and the drivers, the module loader and
  the target loader read J;
- **5b, next**: the tests' inline snippets, still today's notation, rewritten in J; then today's
  reader, μ, the translator and the bridge below deleted.

## 1. What was built

**Every source is J.** `cmd/toj -w` translated all 223 `.oro` files in place, once: 179 programs and
libraries and 44 target files and fragments, every comment carried. These include the IR's test
sources, the book's code, the old experiments, the language's facts, the limb library and the Windows
map. The extension stays `.oro`.

**core reads no source.** A `Resolver` returns a module's forms, not its text (`core/reduce.go`), so
reading belongs to the rendering: `j.ReadEntry`, `j.ReadModule`, `j.ReadTargetSource` and `j.Resolver`
(`j/via.go`). The drivers (`gen`, `build`, `oro`, `intervals`), the target loader (`emit/target.go`, its
facts, retraction and limb and map libraries) and the Go coverage script read J.

**What a file is** (ADR 0064 item 1, a file is a theory named by its path): a file compiled directly is
the module named by its path relative to a library directory of the search path (`lib/num/u128.oro` is
`num/u128`), whose public names are its entry points, as today's header's exports were; any other file
is the root module, its entry points `export fn`. A target file is its directory's or its file's
target, `targets/go/…` is `go`, and J writes no `(target T …)` header; the loader gives the name.

**The bridge** (`j.Todays`), removed in 5b: a source whose first token is `(` or whose first comment is
`;` is today's notation, and is read by today's reader. No corpus file is: `TestEveryCorpusFileReadsInJ`
refuses one. It exists for the tests' inline snippets and the Go, JavaScript and JVM surveys'
generated target files, which 5b moves to J.

## 2. What failed first

Each found by compiling the J corpus, not by the round-trip tests of step 3, which compared up to laws:

1. **The language's facts did not read**: after a fact's parameters, its guard and conclusion are
   formulas, and the model-form reader took the conclusion's first word for a name.
2. **An inclusion is an axiom of the model wherever it is written** (ADR 0064 item 9); J writes it in its
   type's module, and the loader reads `(implements P.T I…)` at the top. The reader lifts it out.
3. **A variant's set name from an import** was read from the imported file in today's notation.
4. **x86's templates number their holes; every other target's fill `%s` in order.** The reader chose
   numbered holes from a template's splicing its result, which x86's do, and so did `lib/os/js.oro`'s
   `WriteFile`: roundtrip on JavaScript and Java emitted `%!,(MISSING)`. Step 3's round trip keyed holes
   by the parameter each splices, whatever their style, a law false for a backend's fill, so it hid this.
   The style is now the model's: `windows`, or a fragment `provides windows`.
5. **A borrow's continuation binds exactly the lent buffers and the result's rest.** U consulted the
   hand-written `File.Read`, which hands its buffer back first, while the acceptance program `os-methods`
   is compiled against the survey's generated declaration, which does not: U took the count for the
   buffer. A different arity is no borrow U may assume. All 223 files were translated again with the fix.
6. **tally declared `(module tally)` and exported `main`**, printed as a library; it is an entry, so its
   J writes `export fn main()`.
7. **The limb library's `guard` returns its buffer unchanged**, a borrow that writes nothing; U required
   a borrowed parameter to be written, which kept gcd's integer from being a place. A parameter is
   borrowed when the definition returns it and writes it, or a call hands it a buffer.
8. **A fragment is found by a line that begins `provides`**, not by a parse, so one that does not parse is
   refused naming its file, never skipped (hoststring-2026-09-24's lesson again).
9. **The differential runner's driver** was written in today's notation around a J case; it is written in
   J, and the cases' `// inputs:`, `// expect:`, `// checked:` and `// skip:` are read as J comments.
10. **Tree usage and borrowed parameters** (ADR 0043 on trees): an element write uses its place's current
    version, and a borrowed parameter is handed back on every path.
11. **The Win32 survey read `windows.oro`'s link libraries by a regex for `(link "…")`**: the published
    counts and the link-line acceptance program failed until it read J's `link "…"` line.
