# A kept definition's parameter is no sink

Date: 2026-11-22. hamza, 2026-11-22: "yes, fix 112 now, always mathematical and algebraic", on the
book's finding 112 (ADR 0155).

## The law

Under `-checked` an operation is proven in the set its representation holds, trapped, or closed on
the word (finding 93, Lemma C). ρ chooses the representation (ADR 0150): an operation past S, U and E
that reaches no sink is held in ℤ, closed under +, − and ·, so it is proven there, and only a value
that must stay a word can trap. Which values must stay words is the taint, the least fixed point
backward from the program's sinks.

A kept definition is a factoring of the program, and a factoring never changes an answer (ADR 0102):
the program's sinks are the sinks of the program with every definition inlined. A kept definition's
parameter is held in the word because a kept parameter above the word is not built (ADR 0113), a
representation of the factoring, so it is no sink of the program's. The argument's use is the body's,
and P4 already inlines a call whose argument leaves its parameter's set (`CheckCallSets`).

## Measured first

On HEAD (5a0adebc), `grow.oro` (3 squared seven times, printed) under `-checked`: Go, JavaScript and
the JVM print 3¹²⁸, windows stops on a trap (exit 132); without `-checked` windows prints 3¹²⁸. The
notes differ in one line: unchecked, *1 definition kept, 1 inlined by its contract*; checked, *2 kept,
0 inlined*. Windows' `io.print_int(n)` calls the kept `win/print.print_int(n ∈ Int)`, whose parameter
is a word: unchecked, p fails the call's set and P4 inlines print_int, whose body holds p in ℤ; under
`-checked`, the taint had made p a word for that parameter, `p * p` was trapped into it, and by the
trap's checked form the call met its set, so print_int stayed kept and the program stopped.
