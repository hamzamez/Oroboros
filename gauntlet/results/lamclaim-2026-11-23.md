# A claimed λ is a definition with a name of its own

Date: 2026-11-23. hamza, 2026-11-23: "yes, record it and build it now. always mathematical and
algebraic" (ADR 0158), on the book's finding 121: chapter 1 §1.4 showed
`export fn run() { fn(n ∈ Int) { n }(1) }` refused, though ADR 0051 and j.md had decided it.

## The law

ADR 0051 says a λ carries what it claims, and a definition is the name bound to one. So the claim is
the set membership f ∈ Π(x̄ ∈ P). R, where:

- P = {x̄ ∈ S̄ : φ} is the domain;
- R = {r ∈ U : ψ} is the codomain.

That membership has two halves:

- **the domain**: each argument is in P. This is an obligation at each application.
- **the codomain**: ∀x̄ ∈ P. ⟦e⟧ ∈ R. This is decided at the λ, not at its applications; a claim
  proven only at the arguments the λ meets is a different, weaker statement.

A definition's claims are already decided this way (ADR 0028, 0072, 0154). The λ is given a name by
λ-lifting (Johnsson 1985), with ȳ its free variables bound around it:

    λx̄.e = (λȳ.λx̄.e) ȳ

This is an equation by β, so staging changes no answer. The lifted definition's claim is decided in
Γ, the part of the λ's context that is declared:

- a yᵢ that is the enclosing definition's parameter keeps its set, which the body assumes and the
  call obliges;
- any other yᵢ claims nothing, and the codomain is decided for every value of it. That is sound but
  not complete.

At a host's callback parameter, the wrapper `fn(x̄) { f#λN(ȳ, x̄) }` composes the host's claim with
the λ's. The wrapper's parameters take the host's sets, and the call obliges them to the λ's
(contravariant). The host's result claim reads the wrapper's answer (covariant).

## What was built

1. **The reader** (`core/jparse.go`): an anonymous `fn` reads `lamHeader`, the definition's header.
   - Kept: a non-name in its parameters is refused, with the message now saying a binder may carry
     `∈ S`.
   - New refusal: a mode (`inout`, `linear`) on its parameter, naming the form that works, a named
     definition.
   - `Lam.Line` records where it was written.
2. **D marks a claimed λ** (`core/desugar.go`): `(#claimed-λ k fn)`. A definition's own λ (its root)
   is excluded, since its claim is its `sig`.
3. **The lifting** (`core/lamclaim.go`, `liftClaimed`), run by `placed` on each definition's term:
   - ȳ is computed from the λ's free variables, bound by the enclosing `fn`s;
   - a captured place is refused: a `#cell`, `#place`, `#mapplace` or `#borrow` binder's name;
   - it writes `(def f#λN (fn (ȳ x̄) e))` and its `sig`, each yᵢ either the enclosing definition's
     parameter set or `any`;
   - the λ's place becomes `(fn (x̄) (f#λN ȳ x̄))`.

   `forms` now returns `placed`'s error, which it used to drop.
4. **Messages**:
   - `ShowName` shows `f#λN` as *the λ at line N*;
   - `CheckSignatures`' prefix names it the same way (`core.ShowLifted`), and leaves every other
     name as before.
5. **Tests**:
   - `TestALambdaCarriesItsClaim` (cmd/gen): a false result, an argument outside the domain, a false
     `where` and a false `ensure`, each refused on four targets and compiled with
     `PlantLambdaClaimDropped`; true claims on four targets; a claim resting on a computed value
     refused at the λ.
   - `TestALambdaAtACallbackContainsTheHostsDomain` (cmd/gen): `strings.Map`'s int32. A λ claiming
     int32 compiles. One claiming 0..127 is refused at its parameter, and compiles with the plant.
     One answering past int32 is refused at the host's result.
   - `TestAClaimedLambdaComputesItsBody` (cmd/build): applied in place, through `twice`, with
     `where` and `ensure`, and in a loop. It prints `7 28 7 0 2 4` on four targets, and on windows
     again with every definition kept.
   - `TestALambdasParametersAreBinders` (core): the reader's refusals, a mode, a captured cell, and
     the lifted form itself.
6. **The book**:
   - chapter 1 §1.4: the refusal replaced by the working form `claimed.oro`; its summary's lines
     made true, including "Only integer arithmetic on literals is computed … only when the answer is
     the one the target would give", stale since ADR 0156;
   - chapter 6 §6.12: a λ's header, with its false result, its argument outside the domain, the
     context's parameter, and a computed value refused with its remedy;
   - chapter 14's `inout` section: a claimed λ writing a cell refused, then the named definition
     with `inout`;
   - finding 121 in the index.
7. **The specs**: j.md's status and §2.7, and state.md.

## What failed first

- **The lifting walked the definition twice** where the enclosing parameters' sets were added, which
  lifted each λ twice (`run#λ1`, `run#λ1_2`). Caught by the first printed `sig`s.
- **The refusal of a captured cell first named a remedy that does not compile.** The remedy was a
  named definition with `inout` and a result claim, refused with *#setref is not a primitive of
  target go* (an older gap: a result claim on an `inout` definition is not decided on its body
  alone). The message now names the form that compiles, `fn f(n ∈ S inout, …)` called by an
  unclaimed λ, and chapter 14 runs it.
- **`go test ./core/ ./emit/ ./ir/...` failed in `ir`** at Go's default 10-minute limit. The packages
  ran at once, and `ir` alone outlasts it under that load (`TestADeadRegionCrossesACall` was running
  at the time). It is no failure of this step: the check's compiler step, scheduled, passed all 955
  tests.
