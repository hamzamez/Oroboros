# libalone-2026-10-20 — a library file compiled alone, refused for its own reasons

The second half of item 1 of the 10-20 plan (assessment-2026-10-20 §5, jmsg-2026-10-20 §5). The
emission sweep compiles every file under `lib/` as an entry, and `lib/result.oro` was refused for
reasons that were not its own: "`io.print-line` is declared twice" on Go, JavaScript and Java, and on
Windows an indexing of a λ, `r[fn(#t, #p, #p1) { … }]`, demanding `0 <= λ`.

## 1. What each was, and the fix

**A library file reached by two roots was read twice.** A driver's module search path is the entry's
own directory, then `-path` (default `lib`): an entry in `lib/` gives `[lib, lib]`, one in `lib/num`
gives `[lib/num, lib]`. For modules both roots mean something, each resolving paths from its own base.
But `loadProvides` walks each root whole, so every target fragment under `lib/` was read twice and
glued with itself, which declares every name it provides twice. **A file is read once, however many
roots reach it** (`emit/target.go`, keyed by absolute path). It hid two refusals, `lib/result.oro`'s and
`lib/os.oro`'s, on three targets each.

**An index is an integer, so an application to a λ is no indexing.** The refinement layer reads a
one-argument application of a bound name as an indexing (tables.md §3.2: in a residual, a bound name
applied is a table). `err_map(f, r)` has no header, and its `case r { … }` is `r` applied to its
continuation, a λ; a table's domain is [0, len) ⊂ ℤ, and a λ is no integer. Such an application is no
longer an indexing (`emit/refine.go`).

**A parameter read as a table is said to be.** With the λ excluded, the next reading was `f(e)` as
`f[e]`: `f` is a function, but a table's read and a function's call are one form, and only a set tells
them apart; on Go and Java the IR's typing refuses the headerless parameter honestly, on JavaScript and
Windows nothing types it. The rule is kept (the corpus has headerless exported tables, `smooth(a)` and
library definitions, that rely on it), and **a refusal of that reading now names it**: the parameter no
header gives a set, read as a table, and that a function there is a definition that takes one and
cannot be compiled alone, since a function does not cross an entry point (closures-direction.md).

**What the duplicate hid in `lib/os.oro`.** Compiled alone, `os.ReadFile` reaches lowering: its failure
is `'err(kind(e))`, a variant whose payload is a variant, and ADR 0042 makes a variant's value its tag
and slots, several values where a slot holds one. In a whole program case-of-case removes it, which is
why `examples/io/roundtrip.oro` builds on three hosts; alone, it reaches the slot. Lowering's message
said "a tuple"; it now says "a tuple, or a variant, which is its tag and its slots (ADR 0042)", and its
terms render in J. **jmsg's pass missed lowering's eleven messages**: it scanned `Errorf` and `Sprintf`,
and these go through `l.fail(format, args…)`. The printers' and the verifier's helpers are about the IR's
text and stay; J's reader's already quote J.

## 2. Now

| | Go, Java | JavaScript, Windows |
|---|---|---|
| `lib/result.oro` | the constructor `'err`, exported first, has no declared set for its payload (the IR's typing: "no header declares it") | `f[#p1]`, with the note: `f` is a parameter no header gives a set, read as a table; a function there cannot cross an entry point |
| `lib/os.oro` | the nested variant in `ReadFile`'s slot, in J (Go, Java, JavaScript) | Windows: `os/host` is not provided, as before |

Each refusal is now true of the file. Neither file is meant to compile alone: `err_map` takes a
function, and `lib/os`'s results are variants whose meaning is fixed where a program eliminates them.

## 3. Checked

  and with the dedupe removed all three cases fail, "declared twice".
- `TestAnApplicationToALambdaIsNoIndexing`, with its control (an integer argument is an indexing):
  passes, and fails with the λ guard removed.
- `TestAnUndeclaredParametersReadingIsNamed`, with its control (a declared table gets no note): passes,
  and fails with the note applied to every parameter.
- `go test` passes. `cmd/check -skip tooling -accept`: 7 changes, every one a refusal's text,
  `lib/result.oro` on four targets and `lib/os.oro` on three; emission otherwise byte-identical
  (2,039 of 2,084 operations, 352 of 371 loops); differential passes.
