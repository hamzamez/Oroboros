# The portable `os`: WriteFile compiled on one host of three

2026-09-30. The next item after the Go target
([gotarget-2026-09-30](gotarget-2026-09-30.md) §14): `lib/os`'s `WriteFile` took a mode that Java
ignored. Building it on each host found it worse than that.

## 1. What was found

`examples/io/roundtrip.oro`'s first draft, a WriteFile, built with `cmd/build` on the three hosts
that provide `os`:

| host | result |
|---|---|
| Go | built and ran; the file held the bytes |
| JavaScript | the emitted module is not JavaScript: `%!r(MISSING)0 = null`, which Node refuses |
| Java | javac refused the file: `final short[] $oroS = "wf-out.txt"` |

Two faults, each silent until something ran it:
- **Neither printer filled a destination hole at one result.** The destination shape,
  `try { %r0 = … } catch …`, was taken only at two or more results. At one, `%r0` reached `Sprintf`
  and came back `%!r(MISSING)`, although `emit/values.go` said *"`%r` is `%r0` at arity one"*.
  `ReadFile`, at two results, worked, and it was the only fallible name any program called.
- **Java's template named the data first**, and holes are filled in argument order, so the path went
  into a `short[]`. The mode, the third argument, fell off the end of the fill.

**Why nothing caught it.** `TestTheUnprefixedModulesShareOneInterface` compares the three cells'
signatures, and a template is not a signature. The README's behavioural check was the three tools in
`examples/io/`, measured byte-identical once, by hand (portableio-2026-09-09 §5). None of them
writes a file, and nothing re-runs them. *A path nothing runs is a path nothing checks.*

## 2. The algebra first

Σ is nine names. The file names are **get and put on a store** F : Path ⇀ B\*. Their law is
put-get: after `WriteFile p d` succeeds, `ReadFile p` gives d (the lens laws, Foster et al., 2007).
A program can observe the law, and `roundtrip.oro` observes it.

**The mode is not in Σ.** A portable name is a claim that several hosts agree, and on the mode they
do not:
- Go's `os.WriteFile` creates with perm before the umask;
- Node's `writeFileSync` does the same with `{ mode }`;
- Java's `Files.write` takes no permissions at all. `PosixFilePermissions` would give it a mode on
  POSIX and throws `UnsupportedOperationException` on Windows, where Go and Node reduce a mode to
  the read-only bit.

What all three do without being asked is the same: create with 0666 before the umask, and truncate
an existing file without changing its mode. That is the intersection, so that is Σ's `WriteFile`,
`((path string) (data (array (int 0 255)))) error`. A program that wants a mode names
`go/os.WriteFile`, which is Go's and says so.

**`Getenv` is a read of state, not a function of its key.** It was `pure` in all three cells. On Go
that is false as soon as a program loads `go/os` beside `os`, since `go/os.Setenv` writes what it
reads. Purity licenses substitution (ADR 0010), and the reordering gotarget §13 showed for `at-map`
happens here too: the read bound before a `Setenv` was substituted after it. It is impure on all
three hosts, because the interface is one claim. On the JVM, whose environment is fixed, the bit is
the interface's and not the host's, and the Java cell says so.

## 3. What changed

- `ir/java` and `ir/js` take the destination shape at one result as at several, so
  `emit/values.go`'s sentence is true.
- `WriteFile` loses `perm` in all three cells. Go passes `0o666`, Node takes its default, and Java's
  template names the path first.
- `Getenv` is impure in all three cells.
- **`examples/io/roundtrip.oro` calls every name of Σ**: it writes `hi €\n`, reads it back, and
  prints the text, an environment variable and the length. **`cmd/build`'s
  `TestEveryPortableNameRunsOnEveryHost`** builds it on Go, JavaScript and Java, runs each artifact
  and requires one output, byte for byte. The file is checked too. Its guard reads Σ from the loaded
  target, so a name added to `os` or `io` that the program does not call fails the test.
- `lib/os/README.md` states Σ with each name's law.

## 4. Witnesses

| rule | planted fault | caught by |
|---|---|---|
| a destination at one result | both printers' one-result case removed | `TestEveryPortableNameRunsOnEveryHost`: `node --check` and javac refuse, Go passes |
| holes in argument order | Java's template with the data named first | the same test: javac refuses, Go and JavaScript pass |
| the guard: every name of Σ is called | `os.Getenv` replaced by a literal in `roundtrip.oro` | *"os.Getenv is in Σ and roundtrip.oro does not call it"* |
| an environment read stays before a Setenv | `Getenv` declared `pure` on Go | `TestAnEnvironmentReadStaysBeforeASetenv`, printing the reordered term: `(let (go/os.Setenv k "v") (fn (_) (os.Getenv k)))` |

The last row is the reordering itself, on this name. The read bound before the store is evaluated
after it.

## 6. Not built

- **The survey's other surfaces are not portable names**, and none is wanted yet: `bufio` is next,
  program first, and the names it needs will say which belong in Σ.
- **windows has no `os` cell**: `kernel32.ReadFile` is handle-based, so there it is a library
  written in the language (README, "What is missing").
