# local-2026-10-08 — a scope of local state: buffers by their initializer, cells as loop variables

Stage A of `local` ([ADR 0047](../../docs/decisions/0047-local-state-is-a-scope-and-a-cell-is-a-loop-variable.md),
[spec/local.md](../../docs/spec/local.md)), from mutscope-research.md and hamza's decisions on it.
Stages B (a host call writing a cell) and C (`(out τ)`) are next.

## 1. What was built

```lisp
(local buf (table n 0)                 ; a buffer of zeros: build's own core form
       sq  (table n (fn (i) (* i i)))  ; filled by a rule
       lit (array 9 0 7 8 9)           ; filled by a graph
       cp  (table (len xs) xs)         ; thaw: a table is a function
       sum 0                           ; a cell
  body)
```

- **The initializer decides**: a table makes a buffer, anything else a cell (Ref τ ≅ Buffer τ 1).
  `(table n 0)` reads as exactly `(build n (fn (b) …))`, the core form every backend already consumes.
- **The migration**: all 137 binder sites of `build` (examples, lib, the gauntlet's sources, tests,
  `emit/bignum.oro`, `emit/winmap.oro`, the IR's test data, the docs) now read
  `(local b (table n 0) …)`, and **their emission is byte-identical**. `(build b n body)` is refused
  naming `local`.
- **Cells by the state-passing translation** (`core/cell.go`), in the loader after `case` expands: the
  state is the flat tuple of every cell in scope, a loop carries the cells it touches as more loop
  variables, an inner scope pushes its cell and projects it off. Nothing below the loader learns
  cells exist.
- **Two reductions the translation needed**, each a law: a projection of a loop moves into its exits
  (π ∘ loop = loop with π at its exits), and a residual `let` is β when its value is duplicable, and
  is its value when its body is its variable (the monad's right unit law).
- **An elimination the translation assumes is an obligation** in the residual, `((#elim op) λ)`,
  decided by the reducer on op's normal form (§3.4).
- **A literal indexed at run time** lowers (`ir/lower.go`), owes its bound (`emit/refine.go`), and a
  literal's length is a constant of the linear fragment (`emit/linear.go`): the thaw of a constant
  table needed all three.
- **`MaxDepth`** bounds normalization's recursion (§3.5).
- `examples/io/count.oro`, the first program with cells (§4.2).

## 2. Measurements

**A cell costs what a loop variable costs.** `TestACellReducesToTheLoopVariableItMeans`: a sum
written with a cell reduces to a residual α-equivalent to the same loop written with a loop variable.
A write under a condition is a statement, so its program goes round once per branch, each with its
own state: a loop the surface cannot spell (`again` may not sit under `if` in source), pinned as its
residual.

**Emission.** 548 runs, 19 changes, accepted. The 137 migrated scopes are byte-identical; 16 runs
are new (three differential cases and count.oro, on four targets; count is refused on windows, which
has no `io.print-line`). Three files changed, all on windows, all limb
programs (`fact-limbs`, `big-divmod`, `render`): each loses a dead test of a literal against 0,

```asm
        mov rax, 54
        cmp rax, 0
        jge Lelse19
        mov r14, 0
        jmp Ldone20
Lelse19:
```

folded once a residual `let`'s literal is substituted (decision 7). The proof counts move only by
count.oro's own: 2,023 of 2,068 operations (+48, its 16 on three targets) and 350 of 368 loops (+3).

**The differential suite**: `local-cells` (two cells, one written on some iterations), `local-tables`
(every initializer, and thaw copying), `local-case` (a cell written in `case` arms and under a host
call's continuation) agree on go, js, java and windows.

## 3. What failed first

1. **Translating each cell on its own nested the pairs**, ((v, b), a), and the lowering refused the
   inner pair as "2 values where one is wanted". ADR 0031's join point takes one product apart.
   Products are associative only up to isomorphism, so the state is the flat tuple, the canonical
   representative, and the outermost scope translates every cell inside it.
2. **Case-of-loop**, `(K (loop F z…))` ⟶ the loop with K at its exits, was built to make a cell's loop
   yield its value. It was unsound: K's `again` of an enclosing loop was captured by the inner loop
   (`TestAJoinPointAndAScopeRefuseWhatIsNotBuilt`). It also moved every tuple pattern's body over a
   loop into the loop's exits (`TestEachComponentHasItsOwnFacts`). Removed. Its sound case, a
   projection, which moves no code, is decision 6.
3. **The literal index.** Case-of-loop put `((array …) i)` where a name stood, and an out-of-bounds
   literal index was accepted (`TestALiveArmIsStillChecked`): the refinement layer made no obligation
   for an indexing whose table is a literal, since lowering had always refused the shape. The shape
   is reachable without case-of-loop, a constant table unfolded at its use, so the obligation stayed
   (`TestALiteralIndexedAtRunTimeOwesItsBound`).
4. **try-loop stopped building on Go** once the residual `let`'s β folded its one success away. Every
   exit of the loop then held `#any` in the success slot. The checker typed that slot's binder by its
   demand, `go.Value` (fmt.Println's box), so the conditional's branches were `go.Value` and `int`. A
   slot no tail selects has every type, so it is now typed bottom, which agrees with every demand and
   learns nothing. The first fix, returning "unknown" from the name rule for a demand with subtypes,
   was wrong: it also forgot a parameter's type, and `TestAConditionalJoinsAtTheLarger` lost its
   refusal of `(if c os.File io.Writer)`. And `#any` itself had gone through the name rule's
   inference: its first demand's type became every later `#any`'s. It is ∀α. α now
   (`TestTheUnconstrainedValueIsOfEveryType`).
5. **Ω overflowed the stack.** `normalize`'s frame grew from 0x1218 to 0x1318 bytes with the new
   rules, and Ω under a binder, which recursed about 210,000 frames before its fuel ran out, crossed
   Go's 1 GB stack. Fuel bounds steps, not depth, so depth is bounded too, and the rules moved into
   helpers.

### 3.4 A hole found by planting faults

Planting "every application with a λ is an elimination" was caught by nothing, and asking why found
the rule unsound as built. The translation took `(op λ)` for an elimination whenever op was an
application or a let-bound name, and the static level is higher-order:

```lisp
(def twice (n) (fn (body) (seq (body n) (body n))))
(local c 0 (seq ((twice 0) (fn (i) (set c (+ c 1)))) c))
```

reduced to 1 for 2: the translated λ is pure, so the reducer dropped the first call. Whether op's value
is data is known only after β, and the translation runs in the loader on the term as written, which
it must: the reducer substitutes a read past a write. So the translation marks each elimination it
assumes, and the reducer decides the mark on op's normal form (no tail a λ but a tuple) or refuses.
The first version of the mark was discharged too early, because the reducer normalizes a λ's body
before applying it: `g` was still a variable, taken for data, when `(let g (twice 0) (g …))` was
reduced. A mark over a variable waits for β now, and one left at the end is over data and stripped.
A primitive name is a function, not data: `(let g each (g (fn …)))` passes a host callback.

### 3.5 Planted faults

Every rule this stage added, each planted alone, with the test that fails:

| fault | caught by |
|---|---|
| a write does not update the state | TestACellIsALocalVariableInProgramOrder |
| a loop does not carry the cells it touches | TestACellReducesToTheLoopVariableItMeans |
| an inner scope yields its cell, not its value | TestACellIsALocalVariableInProgramOrder |
| every application with a λ is an elimination | TestACellIsRefusedWhereItsOrderWouldNotBeTheProgramsOrder |
| a primitive name is data | TestAnEliminationIsDecidedOnTheNormalForm |
| a binder may hide a cell | TestACellIsRefusedWhereItsOrderWouldNotBeTheProgramsOrder |
| a tuple is not threaded as a value | TestACellIsALocalVariableInProgramOrder |
| no β for a duplicable residual let | TestAResidualLetObeysBetaAndTheUnitLaw |
| no right unit law | TestAnEliminationIsDecidedOnTheNormalForm |
| a projection stays outside its loop | TestACellReducesToTheLoopVariableItMeans |
| an elimination mark discharged unconditionally | TestAnEliminationIsDecidedOnTheNormalForm |
| a mark over a variable decided at once | TestAnEliminationIsDecidedOnTheNormalForm |
| the translation marks no elimination | TestAnEliminationIsDecidedOnTheNormalForm |
| a literal indexed makes no obligation | TestALiteralIndexedAtRunTimeOwesItsBound |
| a literal has no constant length | differential local-tables |
| a literal indexed at run time does not lower | differential local-tables |
| an unselected slot is typed by its demand | TestASlotNoTailSelectsHasEveryType, differential try-loop |
| `#any` is a name the checker infers | TestTheUnconstrainedValueIsOfEveryType |

Four were missed on the first planting (the elimination rule, the tuple value, the residual let's β,
the literal's obligation), and each now has its witness; the first of them was §3.4.

### 4.2 count

`examples/io/count.oro`: the lines, words and bytes of a file in one pass, with three cells
(`lines`, `words`, `in-word`), 32 lines of code. Accepted on go, js and java with 16 of 16 operations
bounded and its loop proven; it agrees with itself on Go, Node and the JVM. Against GNU wc 8.32 its
lines and bytes agree and its words are higher on three files of this repository (3,677 against 3,669
on freq.oro). The definitions differ: count's is POSIX's (a non-empty run delimited by white space),
and GNU's counts only runs holding a printable byte, so a UTF-8 dash between two spaces is a word in
one and not the other. Computing both definitions over the bytes gives exactly the two programs'
counts on all three files.

## 6. Not built

- **Stage B**: a host call writing a cell (Go's `&x`: the Scan family, `binary.Read`; Win32's
  out-cells), a write-borrow or consume at length one.
- **Stage C**: `(out τ)`, a fresh consumed cell, and `errors.As`.
- A closure over a cell, and a λ passed to a function: callbacks tier 1.
- A cell holding a tuple: its initializer is a λ to the translation, refused as "holds a function".
- `build-map`'s binder form, kept until a map value carries its capacity.
- Thaw in place, when the source is dead (Perceus; ADR 0034's ownership).
- A declared range on a cell.
