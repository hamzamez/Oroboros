# logic2 — the logic's stage 2: formulas, `assert`, and claims decided by polarity, 2026-11-20

hamza, 2026-11-20: "build stage 2". ADR 0145 decided L1–L7, and logic-research.md fixed the
procedures. This stage builds the formulas from the reader to the decision, and two programs that
need them.

## The programs

- **`examples/logic/leap.oro`: the Gregorian rule as a formula.** `ensure r ⇔ (((∃ k ∈ Int : y ==
  4 * k) && !(∃ k ∈ Int : y == 100 * k)) || (∃ k ∈ Int : y == 400 * k))`, the body computing the
  remainders. Proven for every y in 1..9999, and it prints **0 1 1 0** on every target (1900, 2000,
  2024, 2023). With 200 for 100 the claim is refused, 1900 the countermodel.
- **`examples/logic/midpoint.oro`: Bloch's midpoint** (the binary search bug, 2006). `ensure lo <= m
  && m <= hi && (2 * m == lo + hi || 2 * m == lo + hi - 1)` of `lo + (hi − lo) / 2`, proven, and it
  prints **5 3 3458764513820540928**. On JavaScript, 2⁶² is past the word ±(2⁵³ − 1), and the program
  is refused there: portability computed (ADR 0026).
- **The book's §16.7**: `clamp`, a claim relating the result to the parameters, refused until this
  stage, now proven. The leap year, refusal first. An `assert` refused (2m = lo + hi for an odd sum)
  before the one that holds, `∀ j ∈ lo..m : 2 * j <= lo + hi`, in a loop over k.

## What failed first

- **`∧ ∨ ¬` are not J's.** The first program wrote them, and the lexer has no such tokens. A
  formula's connectives are the computation's `&&`, `||` and `!` (ADR 0062: one equality and one set
  of connectives in formulas), so L1 adds only `∀ ∃ ⇒ ⇔`.
- **A formula `ensure` was refused soundly before anything was built**, by CheckEnsures, as outside
  the fragment, which is the right first answer.
- **The first decision ran out of budget.** Each remainder's definition sat under its atom's ∃, so
  under negation each was a ∀ eliminated by Cooper, the work multiplied. Defined once among the
  hypotheses, Skolem constants, it is immediate.
- **Resolution, Law S and the header's set check each refused a formula**: `#forall` "not bound",
  `0..m` "a range reaches the program as a value", `0..r` "a set has no representation". Each now
  reads a claim's condition as logic, which ε erases.
- **A `where` on a remainder did not reach the formula**: assumed as a fact, `n % 4 == 0` is no atom
  of the linear fragment. The sequent states Γ₀'s `where` as a premise of the formula itself.
- **clamp's body is a conditional**, `case { … }`, which the translation first read as one opaque
  variable. An atom over a conditional is now the case split.
- **An assertion over a let-bound midpoint failed in a loop**: m = k + (10 − k)/2 is no linear fact.
  A pure definition is now its name's meaning for the logic, recorded by the binder's name.
- **The first full check found three defects of mine**:
  - **a soundness hole**: CheckEnsures skipped a formula claim on the premise that DecideClaim had
    run, so a caller that ran CheckEnsures alone accepted it unchecked
    (`TestAnUndecidedPostconditionIsRefused`, which reached that path). CheckEnsures refuses again
    what it cannot decide, and each caller holding the residual decides the formula first, handing
    on the range alone: no check rests on a caller remembering to ask;
  - **a route too wide**: every `ensure` that was no constant bounds went to the logic, `lang.cat`'s
    `utf8_valid(result)` among them, a predicate with its own decision. The route takes only formulas
    and arithmetic (`arithClaim`);
  - **the book's chapter 6** still showed `ensure r >= a` refused. It now shows `r > a` refused (b may
    be 0) before `r >= a` proven.
- **A planted fault that could not be one**: `assert`'s assumption after its point is a completeness
  gain, so forgetting it is sound and no program shows a wrong verdict. It was removed. The
  soundness side, a false assertion refused, is witnessed directly.
- **The heredoc trap, four more times**, in a debug print, a removal pattern and two test strings.
  Every script with a backslash went into a file by the Write tool after the fourth.
