## 1. What the obligation needed, found by printing it

In scope at freq's clamp were `0 ≤ u`, `u + 1 ≤ nw`, and nothing relating `nw` to `len src`. `nw` is the result of
`nwords`, a loop. Three things were missing, and each is its own piece of mathematics.

### 1.1 Invariants over templates

inductive-2026-09-16 decided `0 ≤ v` by Houdini. The same theorem holds for any finite set of linear candidates, so the
template set is now

```
0 ≤ v      v ≤ s, s ≤ v  (s a guard side)      z ≤ v  (z a frame-term initial value)      u ≤ v  (difference)
```

**Theorem (inductive invariant).** If every φ ∈ C holds on entry, and every back edge preserves `⋀C` under the facts
there, then `⋀C` holds at every iteration. The greatest such C is found by Houdini within |C|+1 dry walks. For `nwords`
it gives `n ≤ i`, the difference template (count ≤ trips), and `i ≤ len src`. **This is the first octagon-shaped fact
the corpus has needed** (maxlen-2026-08-28's trigger: *"a bounded difference of two unbounded quantities"*). It arrived
as one template in a finite set, not as a domain.

### 1.2 The result summary

**Theorem (result summary).** If every exit value `r_j`, under its path facts `P_j` and the invariants I, satisfies
`φ(r_j)`, then `φ(result)`. A loop has a value only at some exit, where I and that path hold; this is partial
correctness. Both of `nwords`' exits return `n`, so `nw ≤ len src`. Candidates are `result` against the loop's
frame-term guard sides and initial values, and 0.

### 1.3 Naming a loop or conditional wherever it sits

β substitutes a scanner used once straight into its consumer, so `word-end`'s loop arrived **as an `again` argument**
and `nwords`' loop **inside a guard**, `(< u (loop …))`. The algebra of the two positions differs.

- **In a goal, split** (split-2026-09-16), and a loop is named: `C[loop] = let x = loop in C[x]`, with `x` carrying
  its summary.
- **In a hypothesis, only name.** Splitting a fact `C[if c a b]` gives a disjunction, which a conjunction of
  inequalities cannot hold. Naming loses nothing: the original opaque atom is kept beside the named comparison, since
  both are true, and a goal written the same way still matches the atom.

### 1.4 Entailment is Farkas, decided by Fourier–Motzkin

`len src ≥ 1` needs **three** facts, `0 ≤ u`, `u + 1 ≤ nw` and `nw ≤ len src`. `entails` tried one fact, a scaled
fact, a sum of two, and one elimination step.

**Theorem.** Over the integers, `{aᵢ ≤ 0} ⊢ g ≤ 0` holds if `{aᵢ ≤ 0} ∪ {1 − g ≤ 0}` has no rational solution: a
rationally infeasible system has no integer point, and for an integer `g`, `g > 0` is `g ≥ 1`. Rational infeasibility
of linear inequalities is decided exactly by Fourier–Motzkin elimination (Fourier 1826, Motzkin 1936). The
contradiction row it reaches is a Farkas certificate (1902), of which every earlier check was a special case. Each row
is also divided by the gcd of its coefficients with the constant rounded UP, the normalisation step of Pugh's Omega
test (1991), which is sound over ℤ.

`farkas` runs only after the cheap checks fail. It uses only facts connected to the goal's variables, and it **gives
up** past fixed sizes. Giving up means "not proven", never a guess.

**The caps were wrong once, and the measurement found it.** At 48 facts, naming guards put more true facts in scope and
freq lost four proofs, because the procedure gave up instead of using them. At 160 facts and 4,096 rows every proof is
recovered, and the sweep's time does not move.

## 2. Soundness, checked rather than argued

`TestFarkasIsSoundAgainstEnumeration` builds 4,000 random systems over three integer variables, each boxed in
`[−4, 4]`, and checks every claimed entailment against all 729 points. Every claim holds. **It proves 727 of the 760
entailed goals.** The misses are what only integrality proves, which a rational certificate cannot.

The test **fails at trial 64** with the ceiling rounding pushed one step too far. It passes with rounding pushed down,
and correctly so: that weakens a row, which is sound. The anti-vacuity guard fails if fewer than half the entailed
goals are proven.
