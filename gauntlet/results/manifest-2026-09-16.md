# A manifest type is what it means

2026-09-16. `emit/alias.go`, `emit/target.go`, `targets/go/go.oro`,
`targets/go/unicode-utf8.oro`, `emit/declforms_test.go`.

The other half of step 4 of the build order ([theories-b-or-c.md §9](../../docs/theories-b-or-c.md)),
beside `const` and the range endpoint.

## 1. The second cell, at the type level

[theories.md §2](../../docs/spec/theories.md) classifies every declaration by two bits: whether it has
a **definiens** `t` and whether it has a **realization** `ρ`. At the term level the four cells are a
`sig`, a `def`, a `prim` and a constant, and all four are built. At the TYPE level they are the same
four, and only two were:

| | no definiens | definiens |
|---|---|---|
| **no realization** | an abstract type a program cannot hold | **a manifest type** — `(type int32 (int -2147483648 2147483647))` |
| **realization** | `(type NAME (host "spelling"))` — the host type | refused, §3 |

A manifest type is an EQUATION, so unfolding it is **δ**, exactly as it is for a definition, and δ
erases the name: `((r int32))` IS `((r (int -2147483648 2147483647)))`. Nothing downstream learns that
manifest types exist — no backend, no analysis, no generator — which is the same property the constant
endpoint has one level down and is why both are spellings rather than features.

## 2. It is unfolded after the glue

A manifest type may be declared in another file, or in another layer: `unicode-utf8.oro` writes
`int32` and `go.oro` says what it is. A file is a FRAGMENT and
`load(F₁ ++ F₂) = load(F₁) ⊔ load(F₂)` (loader-2026-09-15), so the unfolding waits for the glued
target, beside `resolveDeferred`, the companion expansion and the view check.

Here it costs no deferral, because a canonical type is a STRING with a small grammar —
`array T`, `buffer T`, `map K V`, `int LO HI`, `prod(A, B)`, `F(A, B)`, a name — and the rewrite is a
walk over it. δ runs **to a fixpoint**, since one manifest type may be written in terms of another, and
terminates unless the definitions are circular. The invariant is checkable and stated: after the pass
**no manifest name occurs in any declaration**.

Resolution is a term's: the module's own name first, then the bare one (theories.md §3.4).

## 3. Four refusals, each an equation's own rule

- **A realization.** After δ the name is gone, so a host spelling attached to it could never be
  reached, and a claim nothing can use is a claim nothing checks. `(type t (host "T"))` beside
  `(type t (int 0 1))` is refused: *a type has one definition*.
- **A cycle.** `(type a (array b)) (type b (array a))` has no normal form; refused naming the chain.
- **A language type.** `(type int …)` and `(type array …)` are refused — a target does not get to say
  what `int` means, which is booleans.md's rule at the type level.
- **A tuple.** Several results are read from the declaration ITSELF: `primOf` splits a `tuple` result
  into `Prim.Results` while reading the sig, and an alias is unfolded later, so a name standing for a
  tuple would be one result where the tuple it means is two. Writing the tuple says it.

And one message improved: `(type t "spelling")` used to be refused off the shape and now says what the
two forms are — a host spelling goes inside `(host …)`, a bare τ is a manifest type.

## 4. What it is worth

**`targets/go/go.oro` states Go's integer types as the ranges ADR 0003 says they are**, once:

```lisp
(type int8   (int -128 127))
(type int16  (int -32768 32767))
(type int32  (int -2147483648 2147483647))
(type uint8  (int 0 255))
(type uint16 (int 0 65535))
(type uint32 (int 0 4294967295))
```

`int` and `int64` are deliberately absent, and that is ADR 0012 rather than an omission: a range past
the portable window would promote the value to arbitrary precision and stop it being the host's word.

`unicode-utf8.oro` then reads like the package's own documentation — `((r int32))`, `(array uint8)`,
`(buffer uint8)` — where it had twelve occurrences of two literal intervals. Together with the
constant endpoint the same morning, that file now states every bound it knows by NAME and every literal
that is left is one that has no name: `(int 0 9007199254740991)` is ADR 0012's window.

**The acceptance is the hand-declaration checker**, not a new test: `TestHandDeclarationsAgreeWithTheHost`
requires every declaration in that file to carry the host's own types, and after δ the string it compares
is character for character the one it compared before.

## 6. Not built

- **A manifest type in a program module**, for the same reason `const` is not: `core.Module` has no
  `type` form yet.
- **A manifest type whose definiens names a constant** — `(type rune (int 0 MaxRune))`. The two δs are
  at different phases: the endpoint is substituted on the TERM before parsing and the manifest type on
  the canonical STRING after the glue, so a type declaration is elaborated too early to see a constant.
  Nothing wants it.
- **The survey's own table.** `gauntlet/stdlib/survey.go` holds the same six ranges in Go, for the
  generator. It is a host fact written twice, and moving it is the linkline-2026-09-13 move on a second
  host fact — worth doing and not done here.
