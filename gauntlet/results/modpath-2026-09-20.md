# A module path is the host's path

2026-09-20. `gauntlet/stdlib/survey.go`, `jvm.go`, `js.go`, `emit/target.go`, the two hand-written
declarations and every program that imports one. Decided in
[ADR 0025](../../docs/decisions/0025-a-module-path-is-the-hosts.md); the research is
[declaration-surface.md §1](../../docs/declaration-surface.md), which leaned this way on 2026-09-14
and was never built.

```lisp
(use go/encoding-hex as hex)      ⟶      (use go/encoding/hex)
(use go/unicode-utf8 as u)        ⟶      (use go/unicode/utf8)
(use java/java-util-regex/Matcher as mt)  ⟶  (use java/java/util/regex/Matcher as mt)
```

## 1. The algebra, which is the whole argument

A module path is a word in the free monoid `Seg*`. A host package path is a word in the same kind of
monoid — `encoding/hex`, `java.util`, `fs/promises` — so there are exactly two ways to put the
second inside the first:

| | map | injective? | `lastSegment` |
|---|---|---|---|
| flattening (until today) | `p ↦ HOST ++ [join(p, "-")]` | **no** — `a/b` and the package named `a-b` collide, and Go import paths permit `-` | `encoding-hex`, so every import needed an `as` |
| the embedding (now) | `ι(p) = HOST ++ p` | **yes**, and a monoid homomorphism | `hex`, the host's own name |

The second row is the finding. `lastSegment ∘ ι = lastSegment` is why `(use go/encoding/hex)` binds
`hex` with nothing further said — and it means **an `as` on a host import was a repair for a broken
equation**, not a choice. The two Go packages dropped theirs today. The JVM's remain
(`(use java/java/util/regex/Matcher as mt)`), and they are the honest kind: a programmer shortening
a long name, not a programmer undoing a flattening.

Non-injectivity was the other half. It costs nothing in the standard library, where no package has a
hyphen, and it is a real collision for third-party paths — which is the kind of latent wrongness
this project prefers to remove before it is reached rather than after.

## 2. What made it affordable now

[declaration-surface.md §1.3](../../docs/declaration-surface.md) named the obstacle: `/` would then
carry two meanings — package nesting, and a type's method set (`go/os/File`) — told apart only by
the host's convention that types are capitalised and packages are not.

§1.6 said what would settle it, and it has since been built: **types are owned by their module, and
companions exist** ([ownedtypes](ownedtypes-2026-09-16.md), [companions](companions-2026-09-16.md)).
A child module whose name matches a type in its parent *is* that type's method set; any other child
is a nested package. The distinction is a checked fact about a declaration, not a fact about letter
case, so the host convention is no longer load-bearing.

## 3. The file is the path

`Seg*` ordered by prefix is a trie, and a directory tree is that trie. So the declaration of
`go/encoding/hex` belongs at `targets/go/encoding/hex.oro`, and `loadTargetDir` now walks instead of
reading one directory level.

This is layout, not mechanism: nothing reads a file's name — a target file declares its own module
path inside — and the flat layout would have been sound. What it removes is **two spellings of one
tree**, a trie of module paths beside a directory of flattened names. `loadProvides` has always
walked the library layer, so the two halves of target loading now agree.

The rule is *the file is the path* **where a path exists**. An acceptance program keeps its flat
name (`acceptance/encoding-hex.oro`), because a program is a file someone named, not a word in
`Seg*`.

## 4. What it cost

| | |
|---|---|
| generators | three sites in `survey.go` (the constant module, the function module, the receiver's companion) and one file writer each in `survey.go`, `jvm.go`, `js.go` |
| loader | `loadTargetDir` walks; 10 lines |
| declarations | `targets/go/encoding-hex.oro` → `targets/go/encoding/hex.oro`, `unicode-utf8.oro` → `unicode/utf8.oro`, module paths inside them |
| programs | the two hand-package acceptance programs, `jvm-object.oro`, `examples/tally/host-java.oro` |
| tests | `tooling_test.go`'s hand-declaration table (which now loads the **target directory** rather than the file's parent — since a package lives at its own path, a file's parent is a fragment, not the target), the generated-file names in the acceptance table, and two module names in `emit/declforms_test.go` |

**Acceptance.** `go run ./cmd/check` passes every step. Emission moved in **one run of 456**, and it
is the rename itself: `examples/tally/tally.oro` on `java` is a refusal, and the refusal names the
module — `java/java-util-regex/Matcher.find` became `java/java/util/regex/Matcher.find`. Accepted
with that reason; no program's code moved, which is the expected answer rather than a lucky one,
because a module path is resolution and never reduction
([ADR 0011](../../docs/decisions/0011-modules-add-nothing-to-the-reducer.md)) and the Go import
string in a declaration was always the host's own `"encoding/hex"`.

The tooling suite is where this change lives, and it passes: the surveys run twice and agree, every
hand declaration still agrees with the host, every planted mistake is still caught, and all eighteen
acceptance programs build and print what the host prints.

## 5. The JVM's doubled prefix, named rather than hidden

`java.util` is `java/java/util`. The first segment is the **host**, the second is the package root,
and they are different things that happen to share a name. `javax.swing` is `java/javax/swing` and a
Kotlin package would be `java/kotlin/…`, so the doubling is not a special case — it is what the
embedding says, and hiding it would mean teaching `ι` an exception.

## 6. Not built

- **Option C**, a second separator for companions (`go/encoding/hex:InvalidByteError`). Held in
  reserve for a host that puts a subpackage and a type under one name on purpose; the loader refuses
  such a collision rather than misreading it.
- **§2 and §3 of the research** — constants as sugar, and names for ranges — still research.
- **Renaming the acceptance programs**, §3.
