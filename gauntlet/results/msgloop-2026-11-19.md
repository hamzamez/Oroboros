# The message loop: MSG, GetMessageA and DispatchMessageA (ADR 0133 step 2)

2026-11-19. Declarations for TinyRetroPad's loop, by header, in ADR 0131's notation.

## 1. What was built

- **`set MSG = record { hwnd, message, wParam, lParam, time, pt ∈ POINT }`** and
  `repr MSG c(…)`. `lPrivate` is `_MAC`'s.
- **`GetMessageA(w, lo, hi) (msg ∈ MSG, r ∈ BOOL)`**, its `LPMSG` an `_Out_` result, called
  `call GetMessageA(&msg, w, lo, hi)`.
- **`TranslateMessage(msg ∈ MSG)` and `DispatchMessageA(msg ∈ MSG)`**, by `&msg` (ADR 0130).
- **`PostMessageA(w, m, wp, lp)`**.

The program, on both triples: a window whose procedure, a λ at the field, answers WM_USER + 1 by
posting WM_QUIT with w as the code. `main` posts WM_USER + 1 with 7 and dispatches until
`GetMessageA` answers 0, then prints the quit's wParam: 7.

## 2. What failed first

- **A nested record curried at a binder was one leaf.** After `(msg, r) = GetMessageA(…)`, MSG's
  `pt` is a name bound to a record, and the `#ref` boundary flattened only record values. So
  `DispatchMessageA(msg)` passed six values to a struct of seven leaves. Older than this step: no
  struct with a nested record had made the round trip. The value is now walked with its record set,
  and a nested record not yet a value is projected along each leaf's path, `(#get "x" pt)`.
- **A narrowed WPARAM reached a C `int` unsigned.** In the procedure, `w < 100` narrows w to 0..99,
  but the unsigned-word pass converts a call's argument only where the parameter is the word or
  `int`, and never for a `host stmt`. `PostQuitMessage(w)`, a `void` C function with an INT, then
  failed W5. Older than this step: an export with a WPARAM parameter fails the same way. The
  conversion now covers a range with a negative end inside the signed word, a C int's, at a call
  and at a C function's statement. A range of naturals, a DWORD's, is inside both words, and the
  value flows as it did. It is the conversion ADR 0033 already decides, refused where the value is
  not proven inside the word. The first, wider version, every signed range and every argument of a
  C statement, changed nine programs by an identity `or i64 x, 0` (RtlZeroMemory's SIZE_T among
  them) and was narrowed until they were byte-identical.
- **A loop carrying the whole MSG** was refused, rightly: WPARAM's set is the unsigned word, which a
  loop variable cannot hold. The loop dispatches in the iteration and carries only a narrowed exit
  code.
- **The guard form of `case` is no tail.** `case { r > 0 -> { …; again(n + 1) }; else -> … }` was
  refused, "a case arm is no tail": only a loop's arms and a variant `case x { … }` are tails, and a
  guard case's arms are values. A message loop's shape in J is a loop whose guards read its
  variables.

## 3. The test

`cmd/build` `TestAWindowRunsItsMessageLoop` prints 7 on windows and windows32. Its faults:
`core.PlantNestedLeafUnprojected` (pt one leaf, refused "is 2 values where one is wanted") and
`ir.PlantCStmtUnconverted` (refused by W5).
