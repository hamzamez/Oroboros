# No binder binds a symbol of the language's signature

Date: 2026-11-23. hamza, 2026-11-23: "yes, build it now. always mathematical and algebraic"
(ADR 0159), on chapter 1 §1.6's `fn(`+`) { 1 + 2 }`, the book's finding 122.

## The law

Σ_L is the language's signature: the names J's reader writes its constructs with. `a + b` is
app(+; a, b), and `if c { a } else { b }` is if(c; a; b). In a binding signature (ADR 0050) these
are operation symbols, and a binder binds a variable. α renames a variable together with its
occurrences, and `1 + 2` is no occurrence of one. So a binder of `+` cannot be read as shadowing a
name. Read that way, it captures the construct.

The condition is bv(t) ∩ Σ_L = ∅. Here bv is the bound variables, defined by structural recursion
over the signature's arities. This is defects-2026-10-26's rule, which says a definition introduces
a fresh symbol, stated for a binder, which introduces a fresh variable.

## Measured first

On HEAD (877433f9), Go:

| program | compiled to |
|---|---|
| `fn(`if`) { if c { 1 } else { 2 } }(fn(x, a, b) { 7 })` | `return 7`, whatever `c` was |
| `fn(`+`) { x + 2 }(fn(a, b) { a * b })` | `v0 * 2` |
| `case m[k] { 'some(`if`) -> if k > 3 { 1 } else { 2 } … }` | `(#p (> k 3) 1 2)`: the payload applied as the choice |

The first passed the type checker and the refinement layer: it was a wrong answer. That met
def.md §11's condition for reopening its decision ("a real shadowing bug that survived both the
type checker and the refinement checker").

The corpus held one binder of a Σ_L name besides the book's example:
`experiments/java-toplevel/tally.oro` bound `keys`, in `slot(keys, cap, k)` and `keys =
a.make_int(cap)`. No corpus program bound an operator.

## What was built

1. **bv on the reader's tree** (`core/binder.go`). It has one clause per binding operator of
   abstract.md §1.1:
   - a λ's parameters, a quantifier's and a table rule's among them;
   - a let's pattern;
   - a loop's variables and its match arms' patterns;
   - a case arm's pattern;
   - a state binder (a cell, a buffer, a map buffer);
   - a binder's claim `x ∈ S = e`;
   - the pattern of `try` and `expect`;
   - a separate `sig`'s parameter names.

   `noLanguageBinder` runs it from `placed`, before D, on every declaration. That covers programs,
   libraries and target files. `PlantLanguageBinder` skips it.
2. **The refusal**: *a binder in f names `+`, which is the language's own: J's reader writes its
   constructs with these names (`a + b` is `+`, `if c { a } else { b }` is `if`), so the binder
   would capture each of them in its scope. A binder introduces a fresh name; choose another*.
3. **`TestNoBinderOfALanguageName`** (cmd/gen):
   - `if` bound by each of seven forms is refused: a λ's parameter, a definition's, a block's
     binding, a `var`, a loop variable, a claimed λ's, a case arm's;
   - `+` and `len` are refused;
   - a target's `h` is bound and compiles;
   - with the plant, the λ form compiles to `return 7`.
4. **The book**:
   - chapter 1 §1.6: `an_operator` moved out of `shadow.oro` into `no-operator.oro.txt`, refused,
     then `operator.oro`, a parameter `plus` beside `+`, whose `1 + 2` folds to `3`;
   - the summary line "A parameter shadows anything, an operator included" made true;
   - chapter 2 §2.4's reference to §1.6.
5. **The specs**: def.md §11 gets a subsection, "Reopened for the language's own names", and its
   list item 6b is amended. state.md states the rule.
6. **The corpus**: tally.oro's variable `keys` renamed `slots`; its comments, which speak of keys,
   are kept.

## What failed first

- **The check on the core's λ parameters after `Load`'s expansions** passed the case arm. That was
  the first placement, chosen because the one clause covered every λ. `expandCase` substitutes a
  pattern's binder for the payload's slot and binds no λ, so `'some(`if`)` reached no parameter
  list. D also renames a match loop's arm pattern away. The check moved to the reader's tree, where
  every binder stands as written.
- **ADR 0158's book example `no-claimed-cell.oro` failed `TestEveryCorpusFileReadsInJ`** once
  committed. The reader refuses it, and the corpus test reads tracked files only, so the check run
  before that commit, with the file untracked, passed. Renamed `no-claimed-cell.oro.txt`, the
  book's suffix for a reader refusal, and chapter 14's directives with it. Before this check, every
  new file was added to the index so the corpus test would read it.

## Not built

- A message naming the binder's line. The tree carries a line on a λ only, and the refusal names
  the definition.
- Σ_L's ordinary words (`keys`, `set`, `table`) as names a program may bind. It would need the
  language's operations reached by a qualified name, `lang.len`, so that a local `len` captures
  nothing. Waiting on a program that wants the word.
