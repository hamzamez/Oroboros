# nodepin-2026-10-20 — the JavaScript survey re-measured on Node v26.8.1

The first item of the 10-20 plan (assessment-2026-10-20 §5). `TestPublishedCountsAreTheCounts/js`
pins the JavaScript survey to the Node it was measured on, v26.7.0, and fails on any other, so a
re-measure cannot be skipped by accident; this machine's Node became v26.8.1 around 2026-10-13
(typevalues-2026-10-13), and `cmd/check`'s tooling step has failed on every full run since. hamza ran
`winget update --all` on 2026-10-20; Node stayed v26.8.1, the newest offered, as did Go 1.27.0 and JDK
17.0.12, so the re-pin is to v26.8.1.

## 1. Measured

`node gauntlet/stdlib/jsdump.mjs`, then `go run gauntlet/stdlib/js.go`, on v26.8.1:

| | v26.7.0 (surveys-2026-09-10, corrected 09-11) | **v26.8.1** |
|---|---:|---:|
| members walked (globalThis and 53 `node:` modules) | 3,913 | **3,943** |
| callable (function, class, getter) | 2,340 | **2,356** |
| declarable, nameable and emitted | 2,326 | **2,342** |
| a key the host accepts and our reader does not (`RegExp.$1`) | 10 | **10** |
| reporting arity zero | 604 (26.0%) | **618 (26.4%)** |
| emitted files (roots) | 48 | **48** |

Sixteen callable members more, every one declarable: Node grew its surface, and the survey's only
refusals of our own, the ten `$` names, are the same ten. **No conclusion moves**: declarable is still
~100% and still measures nothing, since `targets/js` types everything `Any`; usable is still not
answerable; and the arity is still misreported for natives, 26% reporting zero.

Which sixteen cannot be listed: v26.7.0's manifest was never kept, only the counts it gave. Keeping the
manifest beside the pin would make the next re-measure a diff rather than a count.

**The `$` refusal is still ours.** The survey's `readable` copies an identifier alphabet with no `$`.
Today's reader, which defined it, is deleted, and J can write such a name quoted, `` RegExp.`$1` ``; but
the alphabet still governs `validName` (`core/read.go`, `symbolChars`), which the raw reader applies to
every name in the IR's text, and every printer reads that text. So a `$` name is refused by the
compiler, as before, and the count of 10 stays a fact about us.
