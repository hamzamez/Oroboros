# A compile that did not end: it ended, and the library was not checked once

2026-11-17. Item 1 of [assessment-2026-11-17](../../docs/assessment-2026-11-17.md) §5, "a compile
that does not end is a refusal", research first. The research reversed the item's premise. No
compile fails to end. The 20 minutes were a library defect that inlining hid, and the rule that
catches it is ADR 0035's, now checked.

## 1. What was measured

- **The reproduction.** `big-nat-div` was compiled on windows32 with `div` undecided, as before ADR
  0124's lemma, through `gen` with `-checked` and a CPU profile (a temporary build, reverted):
  - it **ends**, in **2m48s**, at 12,342 integer operations against 107 for the decided program,
    115× as large, the instances inlined at every site;
  - **half the time is the IR's interval analysis** (`ir.analyse`, 49% cumulative in `afterRung`),
    run again after each round of realization and storage over a function that size;
  - **a third is the garbage collector**.
- **`cmd/build` took over 20 minutes** on the same case in the differential runner. Its P4 net
  retries the whole program each time a kept definition is dropped, ending with every definition
  inlined, so its time is a multiple of `gen`'s.

## 2. The algebra

- **Every loop of the compile has a measure**, so the compile ends:
  - reduction runs on fuel (`core.DefaultFuel`);
  - `Keep`'s retries each add a definition to `drop`, and the program has finitely many;
  - `Entry` reruns at most once per instance;
  - storage and ι stop at 8 rounds (ADR 0092);
  - the interval analysis terminates by widening (Blanchet et al. 2003).

  So the cost is polynomial in the residual, and the residual is what inlining made of it.
- **Refusing the program is ruled out by ADR 0102's Theorem 1.** Which definitions are kept is no
  part of a program's meaning, and inlined, `big-nat-div` is decided and right. A refusal would
  make the verdict depend on the library's proofs on the target.
- **A bound on the work would change a verdict by a measure of effort**, for a program inlining
  accepts.
- **The defect was the library's.** ADR 0035 makes the library a theory checked once, and ADR 0101
  decides each instance once under its parameters' sets. Nothing checked windows32's instances
  until a program paid for one. P4 is right for the program, but it hid the library's failure.

So the rule is the existing one, enforced: **every instance a program calls is decided on every
target whose integers above the word are K(ℕ\*)**, a check of the compiler. Both rejected
alternatives join ADR 0102's "Why not". No ADR is new: this enforces ADR 0035 and reverses nothing.

## 3. The witness

**`TestTheLibraryIsDecidedOnEveryTargetItServes`** (ir) builds every called instance (`natCalled`:
add, sub, mul, sqr, mul-small, div, rem, render) on every target whose integers above the word are
K(ℕ\*), and requires each decided:
- **the targets are derived**: every directory of `targets/` that loads, has no bignum and holds ℤ
  by the limb rung, so today windows and windows32, and a new member is checked when it is added;
- **the planted fault** reads the two-digit lemma on ℤ's operations alone (`PlantQuotientWordOnly`):
  windows32's `div` is then undecided, and the check reports it.

It supersedes D2's lemma test, which checked two instances on one target.

## 4. What failed first

1. **The plan item's premise.** "A compile that does not end" was what I saw: two processes at 1,200
   CPU seconds, stopped by hand. Measured, the compile ends. The item named its symptom, not its
   cause.
2. **The README's plan section was overwritten.** A Python patch to the plan's script failed, and the
   next line of the heredoc ran the unpatched script. The section's earlier plans were replaced, it
   was restored from git, and the intended edit was applied. A heredoc line after a failing
   command is a separate command, which `&&` on the previous line does not guard.
3. **A heredoc ate a backslash once more**, in `"\n"`. The edit was redone with the Edit tool.

## Paid and bought

- **Compile time**: unchanged for programs, since no compiler code changed. The check pays the
  test, about 50 s in `ir`'s package.
- **Run time, code size, proofs, refusals, emitted text**: unchanged.
- **Compiler lines**: none outside tests. `ir/digit_test.go` is now 87 lines, the library check
  replacing the lemma's test.
- **Documents**: ADR 0102's "Why not" +2 entries.
- **Rules made less general**: none.

## What was not built

- **A refusal for a long compile**: rejected (§2).
- **The fallback's cost when it is right**: a program's own definition inlined by P4 at many sites
  is still compiled at its full size. P8 keeps one when keeping pays. The compile-time gate measures
  the corpus, but windows32 is not in the sweep (d6, hamza's).
- **`of` and `rem-small` as callees**: neither is decided under its parameters' sets on either
  target, and neither is called (`natCalled`), so neither is checked here. ADR 0102's consequence
  (an `ensure` carrying the relation) would make them callable.
