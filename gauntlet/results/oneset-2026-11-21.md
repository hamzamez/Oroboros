# The one set checked where it claims

Date: 2026-11-21. ADR 0152. hamza, 2026-11-21: "I agree, go in that order: 2, then 1, then 3". This
is 3, option A.

## The law

ADR 0029's one set (the program's declared sets above the word, closed by sign and bit length) is
unchanged; where it is checked changes. A fit (`big-fit`) is placed

1. at each claim: a value held exactly that a declared set above the word is ascribed to, the
   ascription a definition's result keeps through inlining (`ascribeResult`); and
2. at each operation of the rung whose result has no finite fact, the declared set its only bound;

and not at an operation with a finite fact, a theorem, ℤ's where no set claims the value (ADR 0150).
Fixed limbs check the width at every operation, which agrees with this exactly when no finite fact
of a value the rung holds passes it; where one does, the program leaves fixed limbs for the host's
integer, or K(ℕ\*), as a program with an operation no limb instance has does.

## Measured first

The claims survive to the rung: printed before `eraseThe`, `big-sign` inside the harness's `main`
carries `the int −2²⁰⁰ 2²⁰⁰` at each inlined call of `calc` and at `calc` itself, five ascriptions.

## What was built

1. **`proven` and `fitClaims`** (ir/big.go): no fit at an operation with a finite fact; each
   ascription above the word on a value held exactly becomes its fit at the one set, before the
   ascriptions are erased.
2. **`limbsBeyondWidth`** (ir/limbs.go): a D_A value with a finite fact past the plan's width, or
   negative under an unsigned one, sends the program from fixed limbs to the host's integer or
   K(ℕ\*), through `SelectRung`'s existing fallback.
3. **`TestTheOneSetIsCheckedWhereItClaims`** (cmd/build), three planted faults: `PlantFitEveryOp`
   (ADR 0029's every operation) stops `x * 3 / 4` over S₆₄ on JavaScript again; `PlantLimbsBeyondWidth`
   keeps x·x − x·x + x over naturals declared 0..2¹⁰⁰ on 101-bit limbs, and it stops; `PlantNoClaimFit`
   lets a yield past its declared −2²⁰⁰..2²⁰⁰ answer, inlined, the wrong answer the claim prevents.
4. **The cases**: `double-word` runs on JavaScript, its skip removed; `big-negmid`'s third input
   answers, its expectation restated; the skip test's control is `u128-fact` (Go's `math/bits`).

## What failed first

- **`big-negmid`'s stop**: it pinned ADR 0029's per-operation check, a negative intermediate `d = a − b`
  under the non-negative 0..2²⁰⁰ caught at its operation, though `calc`'s result, `d + b = a`, is in
  the set. Under ADR 0150 the intermediate is ℤ's; the expectation was the old law's, and is the
  integer now, the planted fault restoring the stop.
- **The limbs witness**: `x * 3 / 4` leaves fixed limbs without the new rule (no division by a value
  held exactly on them, and on JavaScript no signed form), so its plant could not fail; x·x − x·x + x
  over naturals, ring operations alone, is one they hold.
- **Two pinned witnesses**: the pair test's x·3/4 stop (pinned so the fix would restate it, and
  removed), and the skip test's control, `double-word`'s skip, gone with the stop.
