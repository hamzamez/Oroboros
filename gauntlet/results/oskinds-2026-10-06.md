# The portable os returns kinds: one classification over three hosts

2026-10-06. Step 5 of errors.md §12, its first half: the portable `os` in the error model, with the
kinds errors.md §6 decided, on Go, JavaScript and Java.

## 1. The algebra decided the structure

A host's file call is partial, Path ⇀ B\*, and fails with the host's error. errors.md §6 decided what a
portable program sees: kinds K = `not-found | exists | permission | (other e)`, the three portable
sentinels of Go's io/fs with the host's error as the residue, and a classification h : E_host → K. So
a portable call is

```
os.ReadFile = (id + h) ∘ host.ReadFile
```

and `id + h` is `result.err-map h`, lib/result's functoriality in its error. Only `host.ReadFile`
and the three tests h makes differ by host. The case analysis that turns three tests into a kind is
the same everywhere, so writing it in each host's cell would state one function three times.

So **`os` became a library module**, `lib/os.oro`: it declares `os-error`, writes h once, and defines
each portable name over **`os/host`**, which is what the cells in `lib/os/` now provide:

```lisp
(variant os-error not-found exists permission (other error))
(def classify (e)
  (cond (host.not-found? e)   not-found
        (host.exists? e)      exists
        (host.permission? e)  permission
        else                  (other e)))
(def ReadFile (path) (result.err-map classify (host.ReadFile path)))
```

| predicate | Go | JavaScript | Java |
|---|---|---|---|
| `not-found?` | `os.IsNotExist(e)` | `e.code === "ENOENT"` | `instanceof NoSuchFileException` |
| `exists?` | `os.IsExist(e)` | `e.code === "EEXIST"` | `instanceof FileAlreadyExistsException` |
| `permission?` | `os.IsPermission(e)` | `EACCES` or `EPERM` | `instanceof AccessDeniedException` |

Each cell's `ReadFile` and `WriteFile` are declared in the model, `(result.result (array (int 0 255))
error)` and `(result.result (tuple) error)`, and read through their target's niche. JavaScript and
Java gained one each: the try/catch templates' second result is the caught value or `null`, so
`(repr error (niche (host expr "%s === null")))` and `"%s == null"`. JavaScript also gained an `error`
type, which its cell had named and never declared. `err-nil` left the interface: a failed call's value
is bound only in its success arm, so there is nothing for it to guard.

## 2. The claim, checked

`examples/io/roundtrip.oro` now reads a path that is not there and prints its kind. On Go, JavaScript
and Java it prints `not-found`, through `os.IsNotExist`, `ENOENT` and `NoSuchFileException`
respectively, classified by the one h. `cmd/build`'s `TestEveryPortableNameRunsOnEveryHost` requires
`hi €\nok\n7\nnot-found\n` byte for byte from all three. Its guard reads the interface off `lib/os.oro`'s
exports, and a kind counts as exercised where it occurs as a word, since a nullary constructor is
eliminated by a `case` pattern rather than called. The structural check, `emit/portable_test.go`, now
compares `os/host`'s cells, which is where the hosts may differ.

## 3. The corpus

Six programs called the portable `os`: `wc`, `jsonfmt`, `freq`, `roundtrip`, `tally` and the
`read-loop` case. Each `(let (tuple src err) (os.ReadFile p) (if (os.err-nil err) …))` became
`(case (os.ReadFile p) (result.ok src) … (result.err k) …)`. **`wc`, `jsonfmt` and `freq` emit
byte-identical code on all three hosts**, as errors.md §12 predicted for a program that tested only
`err-nil`: the niche's test is the same `err == nil` the product's discriminator was, and the sum
reduces away. `read-loop`'s `case` sits inside `again`'s argument, because both outcomes go round.

## 5. Cost and what is not built

- **Emission**: `roundtrip` changed on three hosts (rewritten, and one line added). Windows's refusals
  for programs that use `os` now name `os/host`, the module it lacks. `lib/os.oro` compiled standalone
  meets the known double-load of a file directly under `lib/`, as `lib/result.oro` does.
- **Balance**: lib/os.oro is +20 code lines in `lib/`, and the six programs' call sites changed size
  by little.
- **Not built**: the 66 fallible Go declarations, the second half of step 5; `is-directory` and the
  other kinds errors.md §6 leaves out.
