# outcells-2026-10-09 — a host writes a cell through a reference; `(out τ)`; the Scan family

Stages B and C of `local` together, Go first ([ADR 0048](../../docs/decisions/0048-a-host-writes-a-cell-through-a-reference.md),
[spec/local.md](../../docs/spec/local.md) §5–6). Go's out-parameters are all caller-typed through
`any`, so the first program needed both: cells passed where Go stores, in Sscan's variadic `...any`
list, and `(out τ)` for a cell that lives for one call.

## 1. What was built

```lisp
((fmt.Sscan line (out go.bytestring) (out int)) (fn (name age n e) …))   ; (out τ): one call
(local age 0 name "" ((fmt.Sscan line age name) (fn (n e) …)))           ; cells in scope
```

- **The derivation.** f : X × Ref T → R that keeps no address is observably X × T → R × T. Inside
  the call the cell is a reference, the address of a fresh copy; after it the cell holds what the copy
  holds: `let r = (#ref c) in let y = (f … r …) in let c = (#deref r) in …`. `#ref`, `#fresh`
  and `#deref` are impure, so ADR 0010 keeps them around the call. The reference is an ordinary
  argument, so it passes through the retraction's definition, the variadic list and Go's box
  unchanged. A cell's new value as an extra result of the raw call was not possible: the raw call
  sits in a retraction definition of fixed arity, and Sscan's cell count varies per call.
- **Declarations.** `(cell T)`, the address of a T the host may write and does not keep, and
  `(cell go.Value)`, a cell of any type in Go's box (the position recorded, the parameter typed with
  the box, below which every `cell T` is derived). The target hands the loader a `cells` form per
  declaration, and a program loaded without them is refused. `(type (cell A) (host "*%s"))` on Go.
- **The nine Scan functions** under Go's names, each a partial success (fmt.oro). Go: 302 of 590
  names declared (51.2%, from 293); `fmt` 23 of 29; **cause I is closed**: its nine names were the
  Scan family.
- **The IR**: a `cell T` type and the statements `cell-ref`, `cell-fresh`, `cell-get`. Go prints one
  variable per call site, declared at the function's top, assigned at the call, and its address.
  JavaScript, Java and x86 refuse a reference; none of their hosts takes one yet.
- **The translation moved after resolution**, where a call names its declaration, and before the
  variadic rewrite, which gathers a call's references into its list.
- **`examples/lines/ages.oro`**, a tool over standard input: count, mean age and the oldest of `NAME
  AGE` lines, parsed by `(fmt.Sscan line (out go.bytestring) (out int))`, its state five cells
  (42 code lines). **`gauntlet/stdlib/acceptance/fmt-scan.oro`**: Sscan, Sscanln and Sscanf into
  `(out τ)` cells and into cells in scope.

## 2. Measurements

**The emitted Go is a programmer's.** For `(fmt.Sscan "42 ana" (out int) (out go.bytestring))`:

```go
var v0c int
var v1c string
v0c = 0
v0 := &v0c
v1c = ""
v1 := &v1c
v4h, v5 := fmt.Sscan("42 ana", v0, v1)
v6 := *v0
v7 := *v1
```

**The cost of the copy, measured** against hand-written Go (one process per benchmark, five runs
each, a thousand Sscan calls per run). Declared where it was used, inside the loop, Go moved a fresh
copy to the heap on each iteration:

| | allocs/op | B/op | ns/op (median) |
|---|---:|---:|---:|
| hand-written (`var v int` before the loop) | 3,000 | 69,008 | 238,913 |
| generated, copy declared at its use | 3,999 | 80,047 | 248,505 |
| generated, copy declared once at the top | 3,000 | 69,008 | 242,718 |

So the copy is declared once (ADR 0048, decision 6); the time is within the noise floor.

**Answers.** `ages` against a reference written in Go with `fmt.Sscan` itself, so the scanning rule
is Go's and not a model of it: six hand-made inputs (a blank line, one field, `1x` read as 1 and
`007` as octal, a third field ignored, ties, UTF-8 names, an unterminated last line) and three
random inputs of 2,000 lines, all equal (`cmd/build/ages_test.go`). A first reference written in
Python modelled Sscan wrongly (it rejected `1x` and read `007` as decimal); the program was right.
`fmt-scan` prints the four lines hand-written Go prints, a short scan leaving a cell as it was.

**Emission**: 556 runs; the 4 new are `ages.oro`'s; every other file byte-identical, through the
translation's move, the unifier's change and the purity fix. Proofs: 2,039 of 2,084 operations
(+16, `ages`), 351 of 369 loops (+1).

## 3. What failed first

1. **`thread` bound a call's head to a fresh name**, so `(fmt.Sscan …)` became `(#s1 …)` and the
   variadic rewrite, which runs after the translation, never saw the declaration. The same held for
   any variadic call with a cell argument inside a scope since stage A: `(fmt.Println a)` was never
   read as a list, and nothing had such a call. The head stays now, unless it is a cell.
2. **A primitive with no template printed as `()`.** The three forms were declared before their
   lowering existed, and lowering's fallback took them for host calls: `v1 := ()`, compiled by
   nothing, refused by nothing. Lowering now refuses a template-less call.
3. **The unifier merged two terms before unifying their arguments.** In Sscan's list, a `cell int`
   and a `cell string` unify with one element variable; with one constructor the second node was
   merged into the first, and the clash among their arguments came after: `var v3c int = "nobody"`.
   Two terms with one constructor unify only if their arguments do (`unifiable`).
4. **A loop variable kept its initial type.** Stage A's spec says a cell's type is the join of its
   writes, and the checker typed a loop variable by its initializer: a name scanned into a cell started
   with `""` was refused, `go.bytestring` against `string`. The checker now takes the least fixed point,
   as the IR's typing already did; the first version rebound the variables each round and discarded
   an element a store had solved (`TestABuildCarriesTheElementItsStoresSolved`).
5. **The reducer's purity was first-order**, and an effect was lost: `(seq (local a 5 (fmt.Println a))
   0)` reduced to `0`. A cell scope's state tuple carries the body's value as a λ's component; under a
   λ head that calls its parameter, `((fn (k) (k a a)) (fn (s a) …(Println s)…))`, the λ argument was
   taken for a value, and calling the variable k for "a value, not a call", so the redex was pure and
   weakened. A λ argument may be applied, by a primitive or by a λ head, so its body counts as run.
   Found by the acceptance program, whose fourth line was missing. It predates cells: any discarded
   higher-order redex that applied an effectful λ was weakened.

The copy's declaration and the template guard were missed on the first planting; each has its
witness now.

## 5. Not built

- **`errors.As`**, whose result names its cell's type, `(option T)`: a type variable bound by the cell
  parameter (mutscope-research.md §7.2). Next.
- **Win32's fixed-type cells** (`GetConsoleMode`'s `LPDWORD`): a stack slot on x86.
- **A cell passed to a definition**: cells are not values, so a function cannot abstract over a Scan
  call's cells; only a declaration's cell parameter takes one.
- **A cell holding a tuple**, still refused as "holds a function" (stage A).
