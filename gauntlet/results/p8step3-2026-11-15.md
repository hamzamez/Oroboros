## The algebra

A kept definition is a Hoare triple {P ∧ φ} f {ψ}: a call decides P(a⃗) ∧ φ(a⃗) and assumes
ψ(a⃗, r).
- Inlined, a site knows sp(body, Γ), the strongest postcondition under its own facts.
- Kept, it knows Γ ∧ ψ.

So ψ is taken as strong as the refinement layer decides, and φ as weak as the body needs (Theorems 3
and 4). Each half is decided in the logic that decides the residual's obligations (ADR 0037).

- **φ at the call** (ADR 0028). The reducer marks a kept call with the definition's instantiated
  `where`, `(#reqw f φ[a⃗] (f a⃗))`, where β would have marked the unfolded body.
  - An impure argument is no term a condition may copy, so its mark is false, and P4 inlines f.
  - A refusal is typed (`emit.RequireError`) and names the definition, so P4 inlines that one
    alone. Step 1's net dropped every definition.
- **φ by lifting** (Theorem 4). A refusal of the body whose conditions are all formulas over its
  parameters is conjoined into φ: assumed in the body, and marked at each call.
  - An obligation under a guard g is lifted as o, not g → o. That is stronger, so it stays sound,
    and a call it fails is inlined.
  - An index's domain condition is typed for it, as a mark's is.
  - A lifted conjunct is undone when its definition is dropped. An inlined call is then held to
    exactly what K = ∅ holds it to, which is the monotonicity of step 1.
- **ψ derived, never declared.** ψ is the greatest subset of a template set T that holds at every
  return: Houdini (Flanagan and Leino 2001), the greatest fixed point on 2^T.
  - Each candidate is a where-mark at every value tail of the body: the arms of an `if`, a `let`'s
    body, a continuation's body, a where-mark's body, a loop's exits (its `again`s are jumps), and a
    tuple's components λk. k v⃗. Each component is bound by the refiner's `let`, so a call's `ensure`
    attaches to it (Lemma 2).
  - A mark that holds is assumed beneath it, so the iteration removes failures until none fails.
  - A tail of several components that is no tuple fails every candidate. A candidate is never
    assumed where it was not decided.
  - T is r ≤ x and r ≤ len(p) for an integer result; len(r) = x, len(r) ≤ x, len(r) = len(p) and
    len(r) ≤ len(p) for a table result; and the IR's constant length hulls.
  - ψ is assumed at a call through the primitive's `ensure`, where its `where` held (Lemma 1).
- **Proposition D, the instance (f, W).** A parameter's set wider than every word the target holds
  ([−2⁶³, 2⁶⁴ − 1]: ℤ, unstated, a set above the words) is narrowed to S ∩ W, the parameter's sort
  read from its use (`emit.ParamTypes`). A set inside the words is left to the facts, which choose
  S or U (ADR 0079).
  - A call outside W is refused twice: by `CheckCallSets`, and by ADR 0033's conversion, which
    admits no unsigned value into a signed parameter. P4 then inlines f there.
- **A call on literals is its value.** f(c⃗) with every argument a literal is a closed term, which
  staging evaluates (ADR 0009). It is unfolded, and its normal form is taken when that is a literal.
  Kept, `bytes.width_of(0, 2⁶⁴ − 1)` was an unknown to its callers. A literal past int64 is the
  reader's closed term over + − ·.

## What failed first

1. **`sieve`'s len(r) = n failed at its tail**: the tail map bound values with `((fn (x) …) v)`,
   and the refiner's let is `(let v (fn (x) …))`. Only the second attaches `build`'s
   len(result) = n to the binder.
2. **`width_of` was never folded**: the kept-call branch ran only for a definition with a `where`.
3. **A literal past int64 is no `KInt`**: 2⁶⁴ − 1 is a closed term over + − ·.
4. **Proposition D exposed a soundness bug that predates P8.** `hostWrites` walked statements'
   regions but never a `branch` terminator's arms. A buffer an impure call writes in an arm was read
   as its zero fill. `repair`, writing through a now-kept `put` in every arm of its automaton, was
   typed `Array(0..0)`. Fixed, with `PlantWritesNoBranch`. No program shipped wrong by it: before
   P8, `put` was always inlined into stores.
5. **The core test of Ω overflowed the stack.** The kept-call branch, inline in `normalizeStep`,
   grew that recursive frame to about 5.6 KB, and a million steps of fuel passed 1 GB of stack before
   the fuel ran out. It is now its own function.
6. **A void kept call was named** (`%v = call void …`), which LLVM refuses. Printing it unnamed
   keeps it an expression, since W7 reads a statement call as consuming its buffer.
7. **`fnv`'s `hex` reprinted with another program's signature**: `cmd/check` reprints every
   program's text on one target, and a kept name is its program's. A registration replaces a stale
   one; only K(ℕ\*)'s instances are the target's.
8. **The `mk` witness needed a lower bound T does not have** (len(r) = n − 1). It was restated: a
   true len(r) = n a caller needs, and a false one only the plant assumes.

## What was not built

- **`readinto`'s n ≤ len(b)**. It needs the loop invariant lo ≤ len(#vb), whose preservation runs
  through `n = case {…}` and `k = if g > n {n} else {g}`, relational joins the refiner's templates
  do not carry. So `readfile`'s clamp stays: a missing proof, owed (time-boxed here).
- **A segment at a kept boundary** (`pe`): pass the view (base, lo, len), or allocate it. That is
  Proposition C for views.
- **Affine templates**, len(r) = x + c and r = x + c, the lower bounds `mk` over 0..n − 2 would
  need.
- **Instances for U and the rung above** (`print_int` at a hash is inlined), and **per-call
  fallback**: a call outside the contract inlines the definition everywhere, not at that call.
- **J's `ensure` on named results**: derived ψ made it unnecessary for every program met here.
