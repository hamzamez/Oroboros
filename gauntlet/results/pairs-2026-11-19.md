# pairs — the gauntlet's forms interleaved on four hosts, 2026-11-19

The measurements' method (CLAUDE.md's decided list, item 3; jsontok-2026-11-19 §3 (b)). A
process on this laptop slows with its age, about 3× some 3 s in. So two forms timed seconds apart
compare two windows of the machine, not two forms. Each host's harness now measures a pair in one
process, round by round.

## The method, and why it cancels the drift

Let a form's true time per call be a, its reference's b, and the machine's slowdown at time t a
factor s(t), slow against one round. A round that times the generated form, then the reference,
reads

  r₁ = a·s(t) / b·s(t+δ) = (a/b) · (1 − ε),   ε ≈ δ·s′/s,

and the next round, in the opposite order, reads r₂ = (a/b)(1 + ε). So the rounds alternate around
a/b. A pair of rounds cancels the drift's first-order term, √(r₁r₂) = a/b + O(ε²), and the median
of an ABBA sequence is centred on a/b. Both forms run one count of calls per round, n, sized once
so the reference's batch lasts about 20 ms. So r is a ratio of times per call. A pair reports:
- its median ratio, generated over hand-written;
- the rounds' range;
- each form's median ns per call;
- n.

process per pair, so one pair's heap, JIT or allocator state does not reach the next.

## What failed first

1. **JavaScript's two timing loops shared one source, and the second form read 1.7× faster.** The
   first harness gave each form a loop of its own by `new Function` over one text, as one call site
   per form requires. G1's dot at n = 65536 then read 1.716 one way and 1.686 the other: whichever
   form came second ran at 31 µs against 51–54 µs alone. V8's compilation cache gives one text one
   function, so the two loops were one function with one feedback vector. With the text made
   distinct (a numbered comment), the pair reads 1.023 and 1.065 in the two orders, against 51.3
   and 50.8 µs in separate processes. The self-test's twin case (two equal closures) does not
   reproduce the bias. G1's symmetric pair is the witness, recorded here.
2. **The JavaScript self-test's first "twice the work" was not twice the work.** A second loop of
   other arithmetic read 1.29 under the harness and 1.9 at top level. V8's cost for a loop called
   through a parameter is not a count of its operations. Twice the work is now the same call twice.
3. **The heredoc ate backslashes** (Java's `"\u0000register"` became a NUL byte). The marker is
   `--register`.
4. **`gauntlet/java/One.java` does not compile**: it calls `JsonTreeBench.shortsOf`, which ADR
   0083's byte[] tokenizer removed. `pairs.sh` compiles the harness without it. Fixing or deleting
   it is owed.

The gauntlet itself was not re-run. The smoke runs above shared the machine with a full
`cmd/check` and are not results. Re-measuring the published ratios with the pairs is the next
gauntlet, at the next assessment and hamza's to schedule, from a foreground terminal.
jsontok-2026-11-19 §2 asks that a run say which it was. hamza's foreground run of
