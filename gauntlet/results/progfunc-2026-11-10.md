# A library instance is a function of the program (ADR 0101, step 1)

Date: 2026-11-10. Item 1 of the standing measure's list after addsub-2026-11-10: the library's
operations as functions, off the plan's deliberately-not-next list. Decision:
[ADR 0101](../../docs/decisions/0101-a-library-instance-is-a-function-of-the-program.md); spec:
[ir.md §2.5](../../docs/spec/ir.md).

## What it is

An instance of the library is a closed λ checked once as a theory (ADR 0035). Calling it and β-reducing
it into the site are the same application, so not inlining is semantically free. What changes is
where its arithmetic is decided:
- **inlined**, at each site, with the site's facts;
- **as a function**, once, under its parameters' sets.

So the sets must be true and declared: a numeral's table is `array int 0 4294967295`, which since the
header became 2m + s is exactly its codomain (digitfacts-2026-11-10). The rest follows:
- **the call's obligation**: every argument's fact in its parameter's set, an element range for a
  table;
- **the result's set is a claim** the callee's body proves, a table's element range by its stores;
- **ownership is the frame rule**: the arguments borrowed, the result a birth the caller owns and
  releases. **W13** checks the callee's side, every returned table born in it. That made `rem` return
  a copy where |a| < |b|.

## What was built

- **The construct**, `call nat.f(ā)`, with a program function named among the target's primitives
  (its signature its own, pure, flagged `Program`). Every pass reads it as it reads a call, and the
  frame rule replaces a host call's conservative ownership in `ir/release.go`. The callee's body is in
  the program's text: `gen` and `build` write it, and the check's reprint registers what it reads
  (`ir.RegisterProgram`), so ADR 0038 holds. The IR step reprints all 241 functions exactly.
- **The callee pipeline** (`ir/progfunc.go`): lowered from the instance, decided under its parameters'
  sets, then the stages an entry takes after its rung (`afterRung`, factored out of `Entry`), the
  legality check, W13, the result's claim, and the shifts. It is built once per target and cached.
- **Which instances are called**: those whose result is a numeral or text and whose code is large:
  `add`, `sub`, `mul`, `mul-small`, `div`, `rem`, `render`. The others stay inlined: `of`, the
  comparisons, `rem-small`, `div-small` and the bound checks. Their results are bounded relationally
  (a remainder below its divisor, a short quotient's digit below B because its partial remainder is
  below the divisor), which no declared set can say. `div-small` was first a call; its result's claim
  refused it, correctly.
- **`mul-small`'s word operand** has the set the plan chose it for, `int 0 268435455`, and the call's
  obligation covers scalars too.

## What failed first, each found by the decision under the parameters' sets

- **`qrem`'s header** was written as 2·m₂, not through `signed`, so nothing bounded it below 2³². As a
  callee it had no site to hide behind, and its carried quotient lost [0, B).
- **A numeral parameter's elements were read as ⊤**: the type was first spelled
  `array (int 0 4294967295)`, as a host declaration spells a byte table. The IR's own convention is
  the bare `array int 0 4294967295` (`final.go` writes narrowed tables so), and the parenthesized form
  is read by no reader of an element range. **A finding beside this step**: a host declaration's
  `array (int 0 255)` has never given its element set as a fact either. It is not this step's to fix.
- **`PlantNatFault`** was planted in the inlining path, and `sub` is now a program function, so the
  fault no longer reached what it broke. `TestAnUnboundedDifferenceIsTheNumeralsOfAnyLength` caught
  it: "the witness cannot fail". The fault is now planted where the callee is built.

## Witnesses

- **`TestAProgramFunctionReturnsATableBornInIt`** (W13): returning a parameter is refused, for the
  reason; returning a table born in the function passes.
- **`TestACallsArgumentsAreInItsParametersSets`**: a call whose argument tables have unknown elements
  is refused. **The planted fault** `PlantNoCallSets` admits it.
- **`TestACallsResultIsReleasedByItsCaller`**: fib's loop frees its calls' results. **The planted
  fault** `PlantCallArgsEscape` reads the call as a host's, and fewer tables are freed.
- `big-fib`, `big-nat-ops`, `big-nat-div`, `big-sign` and `big-signed-ops` agree on four targets, and
  the four windows witnesses of the big-integer work pass.

## What was measured

**Compile time and code**, the step's purpose:

| | inlined | program functions |
|---|---|---|
| the 2,000-quotient program's compile | about 10 min | **19.5 s** |
| its binary | 483 KB | **73 KB** |
| its `main` | 29,579 operations | 2,762 |
| `examples/big/` in the check | baseline | **0.22× to 0.63×** |

**Run time**, best of five, three clean rounds (a first round was contaminated, Go's own time
doubled, most likely by a scan of the new executables, and is not recorded):

| program | inlined | program functions | Go, `math/big` |
|---|---|---|---|
| fib(10⁵) | 139.0–139.9 ms | 139.2–141.8 | 28.0–28.8 |
| fact(20,000) | 313.2–323.3 | 312.9–317.4 | 34.6–35.4 |
| 2,000 quotients | 202.4–205.7 | **183.7–184.7** | 89.8–94.9 |

The call costs nothing measurable, and neither does reuse across it, absent in this step. D is 10%
faster, plausibly from code that fits the caches.

**The counts** went from 6,178 of 6,232 operations and 668 of 692 loops to 5,717 of 5,771 and 649 of
673. A callee's operations are proven once per target, under its parameters' sets, and no longer
copied into each program's note; the unproven 54 and 24 are unchanged.

## What was not built

- **Step 2, reuse across a call**: destination-passing, the dead table's token a linear argument the
  callee's allocation takes by fit (Lorenzen, Leijen and Swierstra 2023).
- **Step 3, parameter `noalias`** on the callee's tables.
- **The fixed limbs' instances** as functions.
- **The host declarations' parenthesized element ranges** read as their sets.
