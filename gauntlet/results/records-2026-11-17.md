# Records in the language: ADR 0128, step 1

2026-11-17. ADR 0128's build order, step 1: the record in the language (items 1–7), on every
target, program first. hamza: "the whole record, and yes to r with {}".

**A record is a function on its labels, and every place a record can stand is one law.**
- **The reader** writes four forms.
- **The reducer** erases a record wherever it sees one built: by the lens laws read as δ-rules,
  and by the currying isomorphism at each binder a record reaches.
- **Load** curries a record in a header.
- **The residual** applies the bijection L ≅ {0…n−1} where a record is data.

No backend changed. Every existing program's emission is byte-identical. Five differential cases
agree on all four targets with answers computed by hand.

Two of ADR 0128's lifted positions are built, nested records and an export's record parameter.
The third, a record as a map's value, is not built, and neither is a buffer of records written in
program order. Both turned out to be the product's limits, and they fail for tuples identically
(§4).

## 1. What was built, law by law

| law | where | what it does |
|---|---|---|
| a value is its graph, total, in canonical order | `core/jrecord.go` `recordFormer` | `record { l : e }` and `record { l ∈ S }`, labels sorted by spelling, a value's components bound in written order first; X1 and X9 |
| projection and override at a value | `core/record.go` `recordRule` | `(#get l (#rec L …))` and `(#with l (#rec L …) x)`; X3. Nothing reads through an override (§3) |
| a path is lens composition | `override` | the paths as a trie: prefix-free (X10), and no term copied however many share a prefix |
| a cell's component | `write` | `p.l := e` is `p := p with { l : e }`, G6's place extended |
| the zero | `zeroOf` | 0 where 0 ∈ S_l, `none`, a nested zero; X11 where a component has none |
| an obligation is its components' | `splitRecordRequire`, `keepClaims` | r ∈ Π S_l iff each r.l ∈ S_l; a component a rule discards keeps its mark |
| currying at β and at a let | `curryRecordArgs`, `reduceLet` | (λq. b)⟨e…⟩ = (λc…. b[⟨c…⟩/q]) e… |
| bind is associative | `reduceLet` | (m >>= f) >>= g = m >>= (λx. f x >>= g), where the inner let ends in a record |
| currying at a loop's binder | `curryLoop` | a loop over a record is a loop over its components, each `again` passing them |
| a value whose tails are records is a product | `recordTails`, `takeApart` | the product's η, applied to a record-valued loop or conditional where it is bound |
| currying at a header | `curryRecords`, in Load | q curried, its record view q#r, every other use renamed; an export, a kept definition and a claim's lowering (ADR 0072) see only leaves |
| the binder decides `a.b` | `resolve` | a bound name is projected, an import's alias qualified |
| labels become positions on the residual | `core/recerase.go` | each term's shape, a least fixed point through a buffer's versions; `#rec` the tuple of its leaves, `#get` a leaf |

- **An export over a record**, `fn shift(p ∈ point, d) (record { x ∈ 0..110, y ∈ 0..100 })`,

## 3. What failed first

- **The canonical type `record(…)` collided with `Applied`**, which reads `F(A, B)` as a variant's
  instance: "shift takes a record(…). A variant type crosses a boundary as a RESULT". The format is
  `record{l: T; …}`, braces and semicolons, so no splitter of the other types cuts a record.
- **A record was let-bound whole.** β substitutes a duplicable value only, and `duplicable` knew
  tuples, not records.
- **β binds a value without passing through `reduceLet`**, so the record η was added at β's
  binding too, beside the product's.
- **A projection dropped an unread component's obligation**: `p.y ∈ 0..100` vanished with the
  component. `keepClaims` keeps every obligation. That is stricter than β's dead argument, whose
  contract CLAUDE.md lists as owed ("a dead call's contract"); a curried leaf the body never reads
  is that same gap.
- **Rules that read through an override** fired only where the base was unseen. There they
  accepted an override outside the domain: `(r with { y : 2 }).x` on r = record { x : 1 } answered
  1. Every component the reducer meets is a name or pure, so the override rule always fires where a
  base is seen. The others were dead code, and were deleted.
- **A planted fault went unseen.** `PlantWithWrongLabel` passed put–get, because the projection was
  answered without computing the override. Each rule now has its own fault and a case that reaches
  it.
- **`Body()` then `Fn` shifted an outer index by one**, `#2.0` in a residual. `Body` opens without
  lowering what looks through the binder, and `Fn` raises it. `openNamed` opens with `OpenWith`.
- **A table given by a rule never reached the residual pass**: β-tab copies it to each read. Only a
  store makes a record data, so the pass's test uses a buffer.

## 4. Not built, and why each is the product's

- **A record as a map's value**, the third lifted position. `m[1] := record {…}` then
  `case m[1] { 'some(r) -> r.x }` is refused on every target with "#p[0] is an indexing". So is the
  same program with a tuple, `m[1] := (a, b)`. A product as a map's value needs each backend's map
  to hold several slots per key: Go's map of a struct, JavaScript's and Java's values, and ADR
  0120's cells on LLVM. That is product work on four printers, owed with a case as its program.
- **A buffer of records written in program order**: `b[k] := record {…}` in a loop. The residual
  pass places it, as `(set #vb k (fn (#k) (#k …)))`. Lowering then refuses "(…) is 2 values where
  one is wanted", and identically for `b[k] := (k + 1, k * 2)`. products.md flattens a table of
  tuples only where `build` writes it, not through the state translation's versions.
- **`ensure` over a record result**: refused by name (`curryRecords`).
- **The step-2 host struct**: next, by ADR 0128's order.

  language declaration a module may shadow, as `some` and `none` may.
- **Emitted text changed**: none for an existing program. 20 new files, five cases on four
  targets, accepted.
- **Compile time**: 1.02× the baseline.
- **Run time**: a record erased costs nothing by construction. No program that pays for a record
  exists yet to time.
- **Proofs and refusals changed**: none for an existing program.
- **Less general**: nothing.
- **Owed, beyond §4**:
  - a refusal of a record component's claim names a tuple's component by index, "component 1 of
    its result", where the label would serve;
  - a curried leaf's obligation is checked twice when a nested record splits in two places, so
    `p#n#m` is marked twice.
