## 1. The algebra

Reduction already relies on the commuting conversion for sums (sums.md), and it is an equation between terms, so it is
also an equation under any predicate:

```
C[(if c a b)]            =  (if c C[a] C[b])
C[(let v (fn (x) e))]    =  (let v (fn (x) C[e]))          x fresh
```

Hence, for a goal G and any context C,

```
G(C[(if c a b)])  ⟺  (c → G(C[a]))  ∧  (¬c → G(C[b]))
```

A `let`'s binder becomes a fresh name `x`, with `x = v` assumed when `v` is linear and `joinConditional`'s facts when
`v` is itself a conditional. Otherwise `x` stays opaque, which only weakens.

This is **Nelson & Oppen's purification made exact**. Purification replaces an alien subterm by a fresh name carrying
what is known of it. Here the GOAL is split on the alien, so nothing has to be known of it in advance: no template
needs to foresee `2048`, which is a side of no guard in sight. Sound because exactly one branch is evaluated, under
the facts on its path.

It subsumes joinindex's template join for an index goal and the back-edge reading of inductive-2026-09-16, and both
now call it. It stays a **proof attempt**: an unprovable goal is propagated exactly as before, never refused. The split
is bounded at 64 leaves, because it is exponential in the number of aliens. The corpus's goals carry at most three.
