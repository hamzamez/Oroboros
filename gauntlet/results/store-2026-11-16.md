# A store owes its table's domain: the book's finding 70

2026-11-16. [ADR 0119](../../docs/decisions/0119-a-store-owes-its-tables-domain.md). Plan item 1 of
[assessment-2026-11-16](../../docs/assessment-2026-11-16.md). hamza, on three options: "do what you
recommend".

**A store `b[i] := v` now owes 0 ≤ i < len(b), as a read does.** One past the end, an index in `Int`,
and the off-by-one loop are refused on every target. Before, they compiled: Go panicked, JavaScript's
array grew, and windows wrote past the region. Two gaps in the analysis that the obligation exposed
are closed, each with a witness. Where a store's bound lies outside the decidable fragment, the
program guards it, and each guard names the proof it stands for. No program that built before is
refused, and every program measured runs at 0.99–1.02 of its old time.

## 1. The algebra

- **A table is a function on [0, n).** A store is its update at one point, set(f, i, x) = f[i ↦ x],
  a function on [0, n) only for i ∈ [0, n). So 0 ≤ i < len(c) is the condition for the store to be
  defined, as for the application f(i), and it is decided by the same procedure (`indexObligation`,
  `emit/refine.go`).
- **A guarded fact σ(G → C) holds everywhere**, so assuming C where G is entailed is sound. lang's
  facts were instantiated once, at the root, and only where their guard held there. A local theory
  extension (Sofronie-Stokkermans 2005) asks the instances on the terms present, and the guard is
  then entailed inside a scope. So the instances are now made where an obligation is: after a goal
  fails without them, and once per back edge in Houdini.
- **The midpoint needs no new fact.** For d = hi − lo ≥ 0, div_floor gives 2q ≥ d − 1, and the
  negated goal lo + q ≤ −1, tightened over ℤ, contradicts it with lo ≥ 0. A sign fact, x ≥ 0 ⇒
  x/k ≥ 0, was written first and removed: nothing needed it once div_floor was instantiated, and a
  fact no deletion can fail is untested.
- **F12, a square.** For every integer x, 0 ≤ x·x and x ≤ x·x. The square is an atom keyed by its
  operand, as a quotient is. The sieve's crossing loop starts at j = i·i.
- **An interval's containment is its ends'.** K(ℕ\*)'s product row writes [j, j + ma], so its stores
  lie inside o iff 0 ≤ j and j + ma < len(o): two comparisons once a row, not one a digit.

## 2. What failed first, and what each failure found

1. **19 runs refused at once.** The obligation's first sweep refused every windows program using
   `os` (argv's quote moves its count back by ns − ns/2), the sieve, freq, jsonfmt and three K(ℕ\*)
   programs. Each was read. The `os` and sieve refusals were missing analysis (§1, items 2 and 4).
   The rest were bounds outside the fragment (§3).
2. **The local instances first cost 5× the sweep's time**, then 1.7× windows' `os` compiles:
   - a clone and a seeding per obligation;
   - a second attempt at every failing Houdini candidate;
   - an exponential retry inside the split's own recursion.

   Now they are made only when a guarded fact's trigger is present and its guard holds, once per
   back edge, and at the top of a split. `pe` on JavaScript went 781 → 1,234 → 780 ms, and crc32 on
   windows 1,265 → 2,046 → 1,381.
3. **`print_int`'s sign slot**: `b[top − 1]` needs 1 ≤ top, and no Houdini template states a 1.
   The program was restated to carry the slot itself, p = top − 1, whose 0 ≤ p ≤ 19 the templates
   give (0 ≤ v and the frame v ≤ z). It is a restatement, not a clamp.
4. **The clamps claimsdemand-2026-10-13 called "stale"** in freq's writer were stale only because a
   store owed nothing. That is CLAUDE.md's *not refused is not proven*.
5. **`abandon` in a guard's arm does not compile.** In `put`'s `case` the buffer is read as frozen;
   in a loop the arm makes a join point the caller's `again` cannot leave (plan item 9). By ADR 0090
   an arm into ∅ leaves the buffer's threading unchanged, and the state translation does not use
   that. The guards skip instead, which is a defect, owed.
6. **The product row's guard per digit cost the 32-word product 8%** (median and minimum). Checked
   on the interval's ends once a row, it is 1.02 (median) and 0.997 (minimum).
7. **A rule written for one failure that a later change made unnecessary was removed**: the join
   skipping a tail into ∅ (ADR 0090), right by the algebra, needed by no program once the row's
   check moved. `mulm`'s size guard is still needed and stays.
8. **A test pinned the old opaque product**: `TestOpaqueAssumptionIsKept` used k·k, which is now an
   atom; it uses k·m. `TestABuildsBufferNotFrozenOutIsReleased` stored at an index read back out of
   a buffer, which the refinement layer cannot bound; its store now reads that buffer as the
   stored value instead, which is the same release shape. The book's chapter 12 showed the
   midpoint's old refusal; its block and the one false sentence now say what the compiler does.

## 3. The guards, each a missing proof

| program | store | why the fragment cannot bound it | the proof owed |
|---|---|---|---|
| jsonfmt, freq (4 targets) | the writer's `out[o]` | count, then build: o < len(out) relates two passes of one recurrence | the output as a fold of pieces: outlen = len ∘ render, len a monoid homomorphism (ADR 0119) |
| K(ℕ\*), the product row and the size store (windows) | `o[i + j]`, `o[cap − 1]` | the copies of ma, mb the row sees are not related to the caller's length; `size`'s lower bound is lost at a join | K(ℕ\*)'s carrier {t : len t ≥ 1} as a set; the join keeping `size`'s hull |
| windows' map keys | `out[rank]` | a rank below a count of occupied slots | a map's count related to its slots |

Each guard's arm is never taken while the program is right; one taken skips the store (§2.5).

## Paid and bought

- **Compile time**: the accepting run's figures are in ACCEPTED.md. The four confirmed regressions
  of the first sweep (windows' `os` programs, 1.6–1.8×) and `pe` on JavaScript (1.58×) were fixed
  before it (§2.2): crc32 1.09× and wc 1.17× of their paired baselines, `pe` 1.00×.
- **Run time**: §5, 0.99–1.02.
- **Code size**: the file programs' executables unchanged; the two K(ℕ\*) product programs
  17,920 → 18,432 bytes (the row's check); 20,000! unchanged.
- **Proofs**: 8,852 of 8,906 operations, against 8,857 of 8,911: five fewer operations, from the
  restated programs, and the same 54 unproven. Loops 924 of 962, unchanged.
- **Refusals changed**: a store outside its table's domain is refused on every target (the book's
  three programs). No corpus program's verdict changed.
- **Emitted text changed**: jsonfmt and freq on four targets (the guards); windows' print_int users,
  the K(ℕ\*) programs and the map keys.
- **Compiler lines**: non-test +143 / −9 (`emit/refine.go`: the store's obligation, local instances,
  the message; `emit/linear.go`: the square atom). Tests +101 / −6, and `cmd/build/store_test.go`
  55.
- **Language lines**: +101 / −23 (lang's F12, natnum, winmap, the two programs, print_int).
- **Rules made more general**: a guarded fact is used wherever its guard holds; a square is in the
  fragment. **Less general**: a store must be proven inside its table.
