# The string monoid in the language: the templates gone, two holes found

2026-11-16. [ADR 0117](../../docs/decisions/0117-a-string-is-the-table-of-its-utf-8-and-its-operations-are-the-languages.md).
hamza, on `targets/windows/strings.oro`'s `string_of` "and the likes which are still declared as
strings": "Go ahead, always mathematical and algebraic".

**The four string operations are definitions in the language, and no LLVM text is left in the
targets but a host's own instructions.** Doing it found and fixed:
- **a wrong answer**: windows accepted `string_of` outside the scalars;
- **a hole in ADR 0089's definedness**: a realization's host `where` was never decided;
- **a gap in the refinement layer**: a goal ≠ never met an assumed one;
- **a release hazard**: an identity coercion was read as a borrow.

`jsonfmt` runs at 0.94 of its time and the other file programs at 0.99–1.02, at a measured price
in compile time and code size (Paid and bought).

## 1. The algebra

- **ρ : Σ\* ≅ V ⊂ B\***, UTF-8, a monoid isomorphism onto the valid UTF-8. On the LLVM layer ρ is
  the identity on the representation. `llvm/str.utf8` is ρ, its `ensure` saying its image is V;
  `llvm/str.text` is ρ⁻¹ on V, its `where` being V. On (B₇)\*, `text_ascii` needs no obligation,
  because V's automaton loops at its start on every byte below 128.
- **Each operation is a table read back by ρ⁻¹** (`targets/llvm/lang.oro`):
  - η is `encode`, Table 3-7's rows under the scalars' domain;
  - `++` is `cat`, the rule x·y;
  - ι is `ascii_of`, a copy of the segment;
  - ι_V is `text_v`, a copy of the table.
- **V is a submonoid.** V = φ⁻¹(F) with F = {q₀} and q₀ initial, so δ(q₀, xy) = δ(δ(q₀, x), y) = q₀.
  So `++`'s obligation is decided on its rule: its length is proven len x + len y (a prefix could cut
  a sequence), and x and y are in V. It needs no pass.
- **The NUL is the allocator's.** b(n, w) = n·w + 9: every region holds one zero byte past its
  elements. `region` zeroes it with the rest, and a raw region writes it with one `store8`. So a
  table of bytes is x·0, Win32's C string, and ADR 0091's NUL needs no copy.

## 2. What failed first, and what each failure found

1. **`string_of` outside the scalars compiled on windows.** The template declared `a ∈ Int`, where
   Go's realization states the scalars' domain. `string_of(55296)`, a surrogate, and
   `string_of(2^30)` were refused on Go and emitted on windows, writing bytes outside V. `encode`
   states the domain, and both are now refused on windows too.
2. **A realization's host `where` was never decided.** With `encode`'s guard removed, so that
   `str.text` met bytes nothing proved valid, the program still built. `ir.Instance` ran the IR's
   decision and not the refinement layer that `ir.Entry` runs on a program. So ADR 0089's
   definedness had held for a term's integer operations alone. The instance is now refined.
3. **With the instance refined, three programs were refused** (`shortcircuit-win`,
   `quotient-corner`, `shift-div`). `lang.div`'s guard `b == -1` gives the fact ne(b, −1) on its
   other arm, and sdiv's `where` asks ne(b, −1) inside a disjunction, ne(a, −2⁶³) ∨ ne(b, −1). The
   refinement layer keeps an assumed ≠ as an atom under `neKey` (its sides ordered by ≠'s symmetry),
   but proved a goal ≠ only by its two strict sides, which no fact gives. A goal ≠ now also matches
   its atom. These terms had been right all along; nothing had checked them.
4. **The concatenation's obligation reached the decision as a rule**,
   `utf8_valid(alloc(table(n, k ↦ …)))`. The decision gained the structural cases of §1, and a `let`
   whose term is in V makes its name in V. A copy `i ↦ b(i)` arrives η-reduced as `table(len b, b)`,
   which the copy case accepts.
5. **ρ⁻¹ would have freed its own string.** `str.text(b)` is the identity, so the string is b's
   storage, but the release pass read a host call with a String result as borrowing its table. A
   program-level `str.text_ascii(b)` was released right after the coercion, with the string read
   after (`(storage %101)` in the IR). An identity coercion is a renaming, as a π is: its table
   escapes into the string.
6. **`cat`'s length was not bounded**: two strings each nearly `max_len` long have no table of their
   length. Σ_OS gains `max_len` (windows: 2⁴⁷ − 9), and a join past it is exhaustion. The guard
   compares the sum itself, since the interval domain keeps no relation between len x and M − len y.
7. **A realization is a term over the host's operations**, so `encode`'s base-64 digits are LLVM's
   `sdiv` and `srem`, not the language's `/` and `%`, which are themselves realized by terms.
8. **A file-read witness's planted fault changed its symptom.** The width taken before Theorem D′'s
   classes no longer crashes the reader: it now fails to read past 8 KiB. The witness asks for the
   file back, which the fault breaks either way.
9. **A precision witness lost its premise.** `TestALimbValueRendersOnWindows`'s planted fault,
   every loop widened to the function's thresholds, no longer reaches the renderer. `ascii` is a
   definition now, so `w − top` is ADR 0028's mark on its parameter, which the refinement layer
   proves from top ≤ w. Thresholds decide precision, any set is sound, and no program I tried still
   needs per-loop ones. The vacuous assertion is gone, and its witness is owed.

## 3. Agreement and the witnesses

- **η on every scalar** (`TestEveryScalarEncodes`): a program prints `string_of(c)` for all
  1,112,064 scalars on windows and on Go, whose `string(rune(c))` is an independent encoder. The two
  outputs are equal, 4,382,592 bytes, the domain's UTF-8 length; the length is pinned too, so two
  empty outputs cannot agree. Agreement by enumeration over a finite domain is a proof.
- `TestATermsHostWhereIsDecided`: `lang.cat`'s instance is proven. `PlantCatValid` (no submonoid
  case) refuses it, and `PlantTermWhereUnchecked` accepts the refused term, which is the hole.
- `TestAGoalDisequalityIsItsAtom`: `lang.div`'s instance is proven, and `PlantNeGoalUnmatched`
  refuses it.
- `TestAnIdentityCoercionMovesItsTable`: under `PlantCoercionBorrows` the coerced table is freed,
  one free more.

## 4. Measured

**The file programs** (`gauntlet/files`, 61 rounds, `winold` being item 8's build on the templates):

| | new / old | work: windows / C |
|---|---:|---:|
| `roundtrip` | 0.99 | 0.96 |
| `wc` | 1.00 | 1.42 |
| `count` | 1.02 | 1.03 |
| `freq` | 1.02 | 0.83 |
| `jsonfmt` | **0.94** | **0.65** (was 1.66) |

`jsonfmt`'s copy into its string was a `"no-builtins"` byte loop and is now a rule clang
vectorizes. Its work went from 1.66× C to 0.65×. That also answers files-2026-11-16's third residue.

**The gauntlet's windows files**: tree 1.02, the allocating stencil 1.02, into a buffer 0.996, the
references 0.99–1.00. The **tokenizer read 1.104**, disjoint over 10 rounds. Its function's assembly
is byte-identical old and new, and with functions and loops aligned to 64 bytes it reads **1.001**
(5,409 against 5,416 ns). So the 10% is where the code lands, layout bias (Mytkowicz et al. 2009),
as gauntlet-2026-11-16 §3d measured on identical code.

## Paid and bought

- **Compile time**: the median 1.00×. Three compiles are confirmed slower on windows, paired against
  `d52fa7c`'s `gen`: `examples/big/render` 281 → 578 ms (2.06×), the differential's `render` 375 →
  734 ms (1.96×), and `pe` 2,484 → 3,765 ms (1.52×). Refining the instances is not the cost (the same times with it off). The string
  terms are: each `++` and ι is now a loop inlined at every call and decided again. The corpus's IR
  grew from 111,214 to 132,666 operations.
- **Code size**: inlined terms where calls were. `roundtrip`'s windows file is 201 → 449 KB,
  `freq`'s 305 → 352 KB, and `jsonfmt`'s 237 → 284 KB. Calling a large realization term as a function (ADR 0101's called
  instances, as K(ℕ\*)'s are) would answer both, and is owed.
- **Run time**: §4.
- **Proofs**: 8,857 of 8,911 operations and 924 of 962 loops, against 886 of 924. The string terms
  add 38 loops, every one proven; the unproven are 54 and 38, as before.
- **Refusals changed**: `string_of` outside the scalars is refused on windows. The three programs
  refused for ne(b, −1) build again.
- **Emitted text changed**: every windows file (b(n, w) = n·w + 9; the strings' code).
- **Compiler lines**: non-test +156 / −6 (`emit/requires.go` +99 for the decision's cases,
  `emit/refine.go` +19, `ir/release.go` +25, `ir/realize.go` +16). Tests +145 / −12.
- **Target lines**: +129 / −21 in the LLVM and windows layers (`lang.oro`'s four definitions and
  `bytes`, `str.oro`'s coercions, `store8`, Σ_OS's `max_len`). `targets/windows/strings.oro`'s four
  templates are deleted.
- **Rules made more general**: a goal ≠ is proven by its atom; a realization's term is decided as a
  program is. **Less general**: `string_of` on windows takes only scalars, as everywhere.

## What was not built

- **ι_V as the identity**: the coercion is a move now, so a whole table could become its string
  with no copy. A segment is a view with no header, though, so `text_v` stays a copy until views
  and tables are told apart there.
- **Releasing strings** (R1e): a realization's tables are made after the release pass, and a coerced
  table escapes.
- **Calling large string terms as functions** (Paid and bought).
- **A program that needs a loop's own thresholds**, the precision witness §2.9 lost.
- **V decided on `encode`'s computed bytes**, without the guard: it needs a relational fact per
  position.
