# A variant's value is its tag and its slots, everywhere it must exist as data

2026-10-06. ADR 0042. unit-2026-10-06 §4 proposed it, and hamza said to continue. Three legal programs
were refused, and they were one case: a sum that must exist as a value, with payloads of several types
or none. The error model's read loop is one of them.

## 1. The representation

data.md §5.5.5's Theorem R, realized at every join point. A variant's value is
**(tag, s₁ … sₙ)**, one slot per distinct payload type of its declaration. Each constructor writes its
payload into its own slot and `#any` into the others:

```
(variant (result T E) (ok T) (err E))     ok  = λp. λk. k 0 p #any
                                           err = λp. λk. k 1 #any p
(variant msg (text string) quiet)          quiet = λk. k 1 #any
```

`case` binds, in each arm, the slot its constructor writes (`#p`, `#p1`, …), and nothing else. That is
Theorem R's decoder, which reads only the slot the tag selects, so what an unselected slot holds is
never observed. Reduction is unchanged: a known constructor still fuses with its `case`, and the
`#any`s go with the unused slots.

**`#any` is the zero of its slot's type**, which makes the value honest, and not only harmless. On the
IR it is `zero`, a value whose type the slot decides: a function's result takes the signature's type,
a loop's result the join of its exits. A scalar zero then becomes a constant, `0`, `false`, `0.0` or
`""`. A non-scalar one is printed as its host's zero: `nil` or `*new(T)` on Go, `null` on Java and
JavaScript, 0 on x86, where every value is a qword. **The unit's one value is represented by 0**, the
singleton {0} ⊂ int.

**The slots are the declaration's, not the instance's.** A constructor is a definition, built before
any instance exists, so its term has one shape everywhere. `(result int int)` at a signature is
`(int, int, int)`. Merging two slots of one type is the sharing corollary, an optimisation left
untaken, since no existing program crosses a boundary that way.

## 2. The measurement that decided it would land cleanly

**Every existing emitted file is byte-identical**, and every differential case, 49 before this step, agrees on four targets.
The hypothesis was that `#any` at an `int` slot settles to exactly the literal 0 a nullary constructor
wrote, and that an enum keeps its one slot. Both held, and so did the proof counts: 1,970 of 2,015 on
the old corpus. The one changed output is a refusal message, `lib/result.oro` compiled standalone on
Windows, which prints the residual's slots.

## 4. Four gaps it exposed, none about sums

Each was there before. A sum at a join point is the first program that reached it.

1. **A table written as its graph had no length** in the refiner (`valueLength`) unless a `let` bound
   it. `(array e₀ … eₙ₋₁)` is a function on [0, n), so its length is n.
2. **An `#any` tail is ⊥ in a join.** This already held: `valueLength` treats a tail without a length
   as `again` is treated, and the other arm decides. It needed no code, only the witness.
3. **A dead arm.** For input 0 no exit of the loop is `rows`, so the `rows` arm is dead and its index
   cannot be proven. The tag's tails are constants, so it ranges over exactly that set, {0, 2}. The
   facts kept only the interval hull [0, 2], which contains 1. Now they also keep the exact set
   (`facts.finite`), and a guard naming a value outside it opens an infeasible path: assume 1 ≤ 0.
   This is the join in the lattice of finite sets, of which the hull is the over-approximation.
4. **Ex falso was never read.** `assumeEQ` records a contradiction as 1 ≤ 0, and its comment says the
   facts then "entail everything". `entails` had no such rule. It does now, **first**: a planted fault
   showed that checked after the goal's own shape, it missed a dead arm whose goal the equations had
   already reduced to a constant.

And one printer bug: **Go's table literal of variables in a narrow range** was emitted as
`[]uint16{v1, v8}` without conversion, and Go refused it. It had been unreachable, because rule 1's
absence refused the program first. A refusal hid a wrong answer, as CLAUDE.md says one can.

## 5. Witnesses and planted faults

| rule | witness | planted fault, and what caught it |
|---|---|---|
| constructors and slots | `TestAMixedSumAtABoundaryIsItsTagAndItsSlots`; `TestTypeArgumentsAreWrittenAndCounted` | — |
| a literal's length | `TestASlotIsProvableWhereItsTagSelectsIt`, row 1 | rule off: 3 failures |
| the tag's exact set | the same test, row 3 | rule off: fails |
| ex falso | the same test, row 3 | rule off: fails; checked after the goal's shape: `TestALiveArmIsStillChecked` passed vacuously until it moved |
| a live arm is still checked | `TestALiveArmIsStillChecked`, an index past a two-element table under a live tag | every `=` guard taken as dead: fails |
| Go literal conversion | `cases/sum-slots.oro` on Go | rule off: `go build` refuses the output |
| four targets agree | `cases/sum-slots.oro` | — |

The anti-vacuity row did its job twice. Its first planted fault passed, which found that ex falso came
after the constant-goal case.

## 6. Cost and what is not built

- **Emission** byte-identical. **Compile time** within the gate.
- **Not built:** merging slots of one type at a boundary; dropping a unit slot rather than holding 0;
  zero results at a function boundary (data.md §3.6).
