# surface-2026-10-25: two questions of the surface, decided and built

The 10-24 plan's item 2 (assessment-2026-10-24 §5), hamza's two questions of 2026-10-24: "do we have to
`+inf`? isn't there a better spelling?" and "should go back to private by default. and instead of export
use pub?" Each is an ADR, built, with the corpus moved.

## 1. The unbounded range (ADR 0077)

**The set.** A range is a convex subset of the chain (ℤ, ≤). With no ends to the chain, the non-empty
ones are [a, b], ↑a, ↓b and ℤ, closed under ∩ (↑a ∩ ↓b = [a, b]), so a range is fixed by which bounds
it has. **An absent bound is no element**: ±∞ are the ends of the IR's abstract domain, which needs a top,
not of a set of integers.

**Decided**: `lo..` is ↑lo and `..hi` is ↓hi; the core keeps `(int lo +inf)`; `` `+inf` `` is refused
naming the omitted end; `..` alone is refused naming `Int`. The bound is absent where the next token
cannot begin one, a header's mode and clause words included (`n ∈ 0.. inout`).

**What a measurement changed.** The plan proposed `Nat` for `0..`. A range declared above the word is a
representation request as well as a set (ADR 0019, 0029):

| | result |
|---|---|
| `fn inc(n ∈ 0..) { n + 1 }` applied to `x ∈ 0..100`, result `0..200` | refused: "a range above the word is a WIDENING, not a refinement" |
| the same with `n ∈ 0..2^100` | refused, the same |
| the same with `n ∈ 0..2^62` | accepted, 1 of 1 operations bounded |

So `Nat` would name the bignum rung while reading as ℕ, a homonym, and abstract.md's own `i ∈ Nat` for an
index is the misreading. **`Nat` waits** for the question this opens: whether a declared set should stop
being a representation request, with ρ chosen from proven facts as everywhere else (ADR 0034, 0049).

**Answered the same day.** hamza: yes, a declared set is a claim and the facts choose the representation
(ADR 0079, not built; `Nat` follows it). And hamza proposed a word `inf`, +∞ on the right and −∞ on the
left; weighed and rejected in ADR 0077's "Why not", chiefly because `..` is closed, so `0..inf` would put
inf in the set, and because one word would name two elements by position.

**Built**: `core/jparse.go` (the omitted end, `beginsOperand`, the refusals), `core/jshow.go` (messages
print `0..`). Four sites in `examples/big/`, 28 in tests. Emission and counts byte-identical; four windows
refusals quote `0..` (accepted).

## 2. Visibility (ADR 0078)

**Measured first:**

| | |
|---|---|
| `private` marks in the corpus | 55, in 6 files |
| in files hiding all or nearly all they define | 52: `emit/bignum.oro` 16/16, `emit/winmap.oro` 16/16, `examples/tally/tally.oro` 20/21 (an entry file, nothing imports it) |
| hidden in the user libraries | 2 of 25 |
| public library definitions another file names | 11 of 23 |
| the core's relations | one, `(export …)`, read as the interface and, for the compiled module, as the entry points |

**The algebra.** A module's interface is a sub-signature I ⊆ Σ, and an importer sees the reduct T|I; the
entry points are another subset E ⊆ Σ, whose claims cross to the host. Two relations, different in
content (`lib/result`'s I holds `err_map`, which takes a function and cannot be an entry point). Which
side of I is written is Parnas's question, and a name in I is a promise whether it carries code or not.

**Decided**: `pub` marks the interface, private the default; `export` marks an entry point only, and
`pub export` is both; the core has `(pub …)` and `(export …)`; `private` is refused.

**Found building it: an empty interface showed everything.** `checkExported` read a module with no
exported names as "no signature yet; everything is visible", so a library hiding every definition hid
none. Twelve test snippets depended on it (a `module lib/scale { fn twice … }` used from outside). Closed:
a library module always has an interface, and an empty one hides all.

**Built**: `core/jparse.go` (the markers, `interfaceDecls`, `declStart` for the variant registry, which
wanted `set` at a line's start), `core/abs.go`, `core/decl.go`, `core/read.go` (`PubDecl`, `(pub …)`),
`core/reduce.go` (`Module.Pub`, `HasPub`, the check), `core/jspell.go` (`pub` reserved for σ_J).

**The corpus**: 29 `pub` in nine library files, each interface unchanged; the 55 `private` gone; `u128`
and `win/fmt` mark their public functions `export` as well, the entry points they had when compiled alone,
so their emission is unchanged. A first run without `win/fmt`'s marks lost 8 operations and a loop from the
counts, its standalone compile emitting nothing: the marks restore them.

**Emission**: programs byte-identical. `lib/os` (go, js, java) and `lib/result` (all four) compiled alone
emit an empty file where they were refused for compiling their interface as entry points; accepted.
2,103 of 2,148 operations and 353 of 376 loops.
