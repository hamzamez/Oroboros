## What failed first

1. **The telescope's open end held i above the word.** An export's parameter takes its
   representation from its set (ADR 0079), and the separation lost the set's hull. The hull is
   target data, so it is computed where the program meets the target. It was first put in
   `ir.Entry`, which the residual's range decision never reaches, so it moved to the target's
   `Env`, which every driver calls.
2. **An end naming no earlier parameter was accepted.** `TestEndpointGrammarRefusesTheRest`
   requires `n ∈ 0..x` to be refused. A dependent product's set may name only what is bound before
   it, so the separation applies only then.
3. **A range payload, once accepted, was not enforced.** `'circle(n)` with n ≤ 5000 built against
   0..1000, a wrong answer that the refusal had prevented. A constructor has no contract to decide
   its payload's set, so the payload is refused again, in J, and owed.
4. **The step limit's J head broke every target file.** `head` was also `liftAxioms`' comparison,
   `head(f) == "module"`, and J's `ShowName` quotes a keyword. The message has its own `headJ`.
5. **The top-level claim captured a target's host constants** (`MaxScanTokenSize ∈ set { 2^16 } =
   host …`). The parser now knows when it reads a target.
6. **`bitsyntax_test` pinned `(- x)`**: its expectation is now `(- 0 x)`, the definition of −x.

## Paid and bought

- **Compile time**: 1.02× the baseline by the median, and no program confirmed slower.
- **Run time and code size**: unchanged. No emitted code changed on any target.
- **Proofs**: 6,977 of 7,031 operations and 747 of 785 loops, unchanged.
- **Refusals changed**: two in the corpus, both diagnostics accepted with their reason (`kara`'s
  hint reads `p[i]`, `pe`'s step limit is J). Eight forms that were refused now build.
- **Compiler lines**: +461 / −13 non-test (`emit/hull.go` 125 new; `core/jparse.go`,
  `core/decl.go`, `core/reduce.go`, `core/read.go`, `core/jshow.go`, `emit/post.go`,
  `emit/linearity.go`, `emit/check.go`, `emit/target.go`, `ir/big.go`, `ir/lower.go`, the two
  drivers). Tests: 233 lines.
- **Language lines**: none.
- **Rules made more general**: a range's end may be a constant or an earlier parameter; a `use`
  path may hold `_`; a top-level value may claim its set; an export may return a rule. **Less
  general**: none.
- **The book**: chapters 0–4 and 6 pass their checker, 309 blocks. The four outputs that quoted a
  fixed message were updated, and the two sentences calling `#1.0` a wart removed.

## What was not built

- **A payload that is a range**: a constructor's contract, its payload's set decided at each
  construction. Refused in J until then.
- **A telescope in a result**, `(0..n)` over a parameter: its ensure is relational, which
  `CheckEnsures` decides only for constant bounds.
- **A segment or rule at a kept function's boundary** (`pe`): pass the view, or let P4 inline that
  call alone.
- **A variant as a parameter's set**, which sums.md §6 refuses at load.
