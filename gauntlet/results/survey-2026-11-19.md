# survey — how much of Win32 a program can call, re-measured, 2026-11-19

hamza, 2026-11-19, reading the README: "32.0% callable and linkable, this is the old figure from
windows. is that still true? after all the work we have done?"

It was not true, in either direction. The survey (`gauntlet/stdlib/win32.go`) decides "callable"
by its own model of what a program can pass, `canPass`, written 2026-09-08: an argument is a word, a
C string, or a pointer SAL marks optional, passed as NULL. Every argument form built since,
ADR 0129–0132 among them, was invisible to it. And it counted a UTF-16 string as a C string, though
the `W` functions' strings are not built (ADR 0091's rest).

## What was measured

| model | callable | % of 12,377 | callable and links |
|---|---:|---:|---:|
| 2026-09-08's, as published | 4,474 | 36.1 | 3,963 (32.0%) |
| 2026-09-08's, wide strings out | 3,266 | 26.4 | |
| **today's**, structs the target declares | **4,352** | **35.2** | **3,739 (30.2%)** |
| today's, every struct the SDK defines | 5,733 | 46.3 | |

So the published 32.0% counted about 1,200 UTF-16 functions a program cannot call. On the same
terms the work since added 1,086 entry points, from 26.4% to 35.2%. Today's model is a lower bound:
a struct passes only where the windows target declares its layout, nine records today. It is up to
46.3% as structs are declared, each layout derived and checked against clang (ADR 0128).

## Today's model, rule by rule (`canPass2`, `model2`)

| argument | passes as | ADR |
|---|---|---|
| a word, a C string read by the callee, NULL where SAL says `_opt_` or `_Reserved_` | as before | |
| `_Out_ T*`, T a word or a declared struct | a result, the call's `&r` | 0131 |
| `_Inout_ T*` | a cell, `x ∈ T inout` | 0048, 0135 |
| `_In_ T*` | `&x`, a cell's address or a struct's copy | 0130 |
| a byte region with its count a parameter: `_In_reads_bytes_(n)`, `_Out_writes_(n)` over bytes, an LPSTR the callee writes | one segment | 0132 |
| a struct by value the target declares, a record or a word (LARGE_INTEGER) | the bare set, by the triple's ABI | 0129 |
| a `void*` the callee reads or frees (`_In_`, `_Frees_ptr_`, `_Pre_notnull_`) | the `ptr` the host gave | 0084 P6 |

What still does not pass:
- a wide string;
- a typed array (`_In_reads_(n) DWORD*`);
- an output buffer with no count parameter;
- a pointer whose direction SAL does not say;
- a callback parameter (tier 1);
- a struct result by value;
- a variadic.

## What failed first

1. **The model had no check against the compiler.** `TestTheSurveysModelCallsWhatTheTargetDeclares`
   now holds it to the declarations. Every C function the windows target declares and a program
   calls must be callable by the model, and two UTF-16 functions must not be. Its first run found
   eleven functions the target calls that the model called uncallable, each a missing rule:
   - `LPRECT` and `LPMSG` had no pointee. `reStruct` read `} RECT, *PRECT, FAR *LPRECT;` and kept
     RECT only. The starred names are now the struct's pointers, which also resolved 14 typedefs
     the old model had counted unresolved: 11,270 declarable became 11,284;
   - LARGE_INTEGER, a union, is declared by the target as LONGLONG, a word;
   - annotations left in a parameter's type (`__drv_freesMem(Mem) _Frees_ptr_opt_ LPVOID`) are now
     read as its SAL;
   - a `void*` handed back (HeapFree, HeapSize, VirtualFree);
   - a struct by value (PtInRect's POINT), which the old classifier refused before the model was
     asked.

   `RtlZeroMemory` is a macro in the SDK, outside the survey's universe, and is logged.
2. **Read ten of what it admits** (a survey's first number describes the measurer): `MsiEnumProductsA`'s
   `_Out_writes_(MAX_GUID_CHARS+1) LPSTR`, a buffer the callee writes with no count parameter, was
   counted callable as a C string, in the old model too. A C string is now an input only, and an
   output one a segment.
3. **The report printed "CALLABLE AND IT LINKS" twice**, once per model. Each is labelled by its
   model now, so the old figure cannot be quoted for the new.

## Owed

- **The struct bound's upper half**: parsing a struct's fields to say which layouts are derivable,
  so the published figure is not a lower bound only.
- **A typed array** (`_In_reads_(n) DWORD*`) as a segment of words, and **a wide string** (ADR
  0091's rest), the two largest remaining argument forms.
