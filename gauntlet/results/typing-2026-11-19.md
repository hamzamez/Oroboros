# typing — an unread binding's typing claim is checked (ADR 0137), 2026-11-19

`fn f(n ∈ 0..9) (Int) { s ∈ String = n; 0 }` compiled on every target: β dropped the unread binding,
and its claim, a set that is no range, left no mark. A range's claim keeps a mark (`#req`), and
a read typing claim is decided by its ascription, `(the "string" n)`.

## What was built

A claim e ∈ S is a statement of the program, owed where it is written, whoever reads e. A
range's claim is already kept that way (claims-2026-11-16, deadclaims-2026-11-18), so the typing
claim takes the same rule:
- **The mark** `(#is "S" e body)` (`core.TypingName`). Its value is body's. When β drops a pure
  unread binding, `hoistObligations` moves the binding's typing claim onto the body, as it moves
  a range claim. That claim is the ascription D wrote, `(the "S" e)`, with S no range and no
  buffer's sort. `holdsClaim` takes it, so an argument evaluated zero times is normalized for it,
  as a range claim's is.
- **The decision** is the type checker's, the procedure that decides a read claim. `ir.Entry`
  keeps the residual with its marks, erases them from what every pass reads, and checks the marked
  residual too. Each mark is read as what it claims, `(let (the S e) (fn (#_) body))`, a binding
  of the claim nothing reads, with the header's sets ascribed to the parameters
  (`emit.AscribeParams`). The checker learns a parameter's type from its uses, and a claim may be
  a parameter's one use: without the header's sets, `s ∈ String = n` taught it that n is a String.
- **A top-level constant's** typing claim, `s ∈ String = 3`, the same item at the top level
  (deadclaims-2026-11-18 §4): `ir.DecideConstantClaims` already normalizes each claimed constant
  alone, and now checks its residual's ascriptions too: *s: an integer literal is Int, but String
  is required here (a constant's claim, decided where it is written: ADR 0137)*.
- **The message** is the checker's, with the claim named: *main: an integer literal is Int, but
  String is required here (the claim of a binding nothing reads, decided where it is written:
  ADR 0137)*.

`TestAnUnreadTypingClaimIsChecked` (`cmd/build/typingclaim_test.go`), on windows and Go:
- an unread false claim in a kept definition, one in main, and a top-level constant's are each
  refused naming String;
- a read false claim is refused as before;
- unread true claims (a range, a Boolean, a String) build and print 7;
- the fault `core.PlantTypingClaimDropped` drops the claim with its value, and the three unread
  false claims build again.

## The measurement ADR 0137 item 3 asks

Compile time on the corpus, and the residuals unchanged where no such claim is written:
- **Outcomes**: no outcome of the 712 runs, or of windows32's 178, changed by the marks. Every
  emitted-text change of the run that accepted this step is ADR 0138's `urem` → `srem` swap. The
  marks are erased before any pass that prints reads the residual, so no program's code can change.
  No program of the corpus has a false unread typing claim: none is refused.
- **Compile time**: the sweep at 1.04× the baseline with ADR 0138 in the same tree, within the
  gate and the noise. A program pays a second type check only where a mark is left, and nothing
  else changes what reduction does: an unread argument is normalized for its claim, as a range
  claim's already is.

So the mark stays the method, and the alternative, a type check on the trees before reduction,
is not needed.
