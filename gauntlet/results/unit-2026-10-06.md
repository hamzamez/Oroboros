# The unit, a discard that was captured, and where a sum must exist as data

2026-10-06. hamza, on 1 + E for a host call that succeeds with nothing: *"if b is what the algebra
says, and we get a better language go ahead."* (b) was `(tuple)`, the empty product, as the unit. This
records what was built (§1–3), and the representation question it raised, which is a proposal (§4).

## 1. `(tuple)`, the terminal object

data.md §3.6. 1 = Π over the empty index set: one value, and exactly one function A → 1 for every A,
the dual of `abandon`'s 0 (errors.md §8). A × 1 ≅ A, and 1 + E is the exception monad's value type for a
computation with no result, so one `result` serves every fallible call: `(result (tuple) error)` for
`WriteFile`, `Close` and `Flush`, with no second variant.

- **The term** is the Church tuple at n = 0, `(tuple)` ⟶ `(fn (#k) (#k))`. Destructuring is β at
  arity 0. η at n = 0 says every value of type 1 is `(tuple)`.
- **The type** is `(tuple)`, canonically `prod()` (`core.UnitType`). `(tuple x)` stays refused, since
  (tuple T) ≅ T. `(array (tuple))` is refused as a type: a table of units is its length.
- **Eliminated within a program it costs nothing.** Reduction removes the unit with the sum:

```go
	if v15 {
		fmt.Println(2)
		return 0
	}
	return v1
```

is `(case (try (result.ok _) (save k) (seq (print 2) (result.ok (tuple)))) (result.ok _) 0 (result.err e) e)`.
`gauntlet/differential/cases/unit.oro` agrees on four targets.

## 2. A `_` in a pattern was captured by `seq`'s binder

`(try (result.ok _) …)` inside a `seq` was refused: *the pattern is the success constructor … got
(result.ok #0.0)*. `seq` read as `((fn (_) b) a)`, its binder spelled `_`. The reader expands `match`
before an enclosing `seq` closes its λ. `case` and `try` expand later, in Load, so their `_` had
already been closed over: it was the `seq`'s bound variable, not a fresh discard. values.md had named
the hazard: *"`seq` uses `_`, which a user COULD write."*

A binder written `_` binds nothing, so the reader now spells it `#_`, which no source can write, as
`tuple` spells `#k`: in `seq`, in `(let _ …)`, and once per discarded component of a tuple pattern
(`core/let.go`, `discards`). `(let _ e b)` and `(seq e b)` still read as the same term
(`TestABindingIsTheApplicationItMeans`). Every emitted file is byte-identical.

## 4. Proposed: a sum is typed as a sum where it must exist as data

The unit's payload at a boundary or join point is refused. Two findings show it is not the unit's
problem:

- `(result (tuple) int)` returned at a signature is refused: *variants carry different payload types*,
  counting `prod()` as one;
- **`(variant msg (text string) quiet)` returned at a boundary is refused by W5**, *int 0 0 flows into
  the function's result, which is string*. A nullary constructor's payload is the literal 0, which fits
  only an `int` slot. A nullary constructor is a constructor with payload 1, `quiet ≅ (quiet (tuple))`,
  so this is the same case, and it predates the unit;
- and from sumloop-2026-10-06, **a `try` in a real read loop** yields `(ok acc) | (err e)` with `acc :
  int` and `e : error`. That is refused, *a loop's exits are int and string*. The error model's loops
  need it.

**What the algebra says.** data.md §5.5.5 already has the representation, Theorem R. A sum value that
must exist as data is `(tag, S₁ … Sₖ)`, one slot per distinct payload type. A slot the tag does not
select is **unconstrained**, and decoding inverts encoding because `case` reads only the selected slot.
It was specified for function boundaries. A loop exit, a scope exit and a join point are the same
situation: a place where a sum must be a value. A payload of type 1 adds no slot.

**Why it cannot be done on tuples.** An unconstrained component is sound only under the tag
discipline. Joining `(tuple 1 (tuple))` with `(tuple 2 5)` and reading component 1 would observe a
value nobody wrote. So the compiler must know the value is a *sum*: that only constructors write
its slots and only a tag-guarded `case` reads them.

**The proposal: Theorem R at the declaration, with an unconstrained value the compiler alone writes.**
1. **A constructor carries one slot per payload position of its declaration**, filling the others with
   `#any`, an unwritable, pure, compiler-generated value meaning "unconstrained". For
   `(variant (result T E) (ok T) (err E))`: `ok = λp.λk. k 0 p #any`, `err = λp.λk. k 1 #any p`. A
   nullary constructor, and a payload of type 1, fill every slot with `#any`. `case` binds the slot its
   arm's constructor writes. Reduction is unchanged: a known constructor still fuses with its `case`,
   and `#any` disappears with the unused slot.
2. **`#any` types as the unknown**, as `abandon` does (expect-2026-10-06). It agrees with every slot's
   type, and that is sound for the reason Theorem R is: only a constructor puts it there, in a slot its
   tag does not select, and only the `case` that tag guards reads a slot.
3. **On the IR, `#any` is a value with an open type**, solved by the slot it fills, and each printer
   prints its host's zero of that type: `0`, `""`, `nil`, `null`, `false`, and on x86 0.
4. **Slots of one type merge** where an instance makes two positions equal: `(result int int)` is
   `(tag, int)`, Theorem R's sharing corollary. So every sum crossing a boundary today keeps its
   representation, and the emission gate should show no change for an existing program.

**What it replaces.** The boundary check in `core/reduce.go` (`uniformPayload` and its refusal, which
become this). The literal 0 as a nullary payload, including the `none` a map read builds. The "a loop's
exits are A and B" refusal for a sum.

**What it costs.** In core: `Sum.Defs`, `caseForm`'s eliminator arity, and the map read's `none`. In
emit: the term checker's rule for `#any`. On the IR: one value kind, its typing and four printers' zero
values. Then the tests that pin constructor terms. Measured by the gate (byte-identical expected) and by
three programs that are refused today: the string-payload enum, `(result (tuple) int)` at a signature,
and a read loop with `try` over two payload types.

**An intermediate step**, if hamza wants one: steps 2–3 alone, with `#any` as the nullary payload
instead of 0. That is the proposal at k ≤ 1. It closes the first two findings without touching
`case`. The third needs step 1.
