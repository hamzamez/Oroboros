# A variadic is a function of a table: over one type (G), and over Go's box (H)

2026-10-08. The first closable wall of gocoverage-2026-10-06 §4, G: six names that `strings.oro`'s
header called "the variadic wall". It was not one.

## 1. What it is

Go's `...T` is the free monoid on T, T* = ⋃ₙ Tⁿ. A function on it can be declared in two ways:
- one declaration per length, the restrictions f|Tⁿ, which is forced when the elements' types differ
  (`fmt`'s `...any`);
- one declaration on the whole, which needs a value of T*.

The language has one: `(array T)`. Inside the Go function the parameter's value is a `[]T`, and a call
`f(s...)` passes `s` unchanged (the Go spec, "Passing arguments to ... parameters"). So

```lisp
(sig NewReplacer ((oldnew (array bytestring))) Replacer pure
  (where (= (% (len oldnew) 2) 0))
  (host expr "strings.NewReplacer(%s...)" (import "strings")))
```

is exact: every length at once, the empty one included, with no copy at the call. The emitted Go is
`strings.NewReplacer(v6...)`.

## 2. What was declared

| name | file | |
|---|---|---|
| `NewReplacer`, a spread | `strings.oro` | precondition: an even count, or Go panics |
| the `Replacer` type, `Replace` | `strings.oro` | pure: immutable after construction, no declared equality |
| `Replacer.WriteString` | `strings.oro` | a partial success, the relevant 1 + E (ADR 0044) |
| `MultiReader`, `MultiWriter`, spreads | `io.oro` | the concatenation of streams and the fan-out of a write |

Each file states the algebra. A Replacer is a finite rewriting system in which the first matching
pair wins: Go turns `"aaa"` into `111` under (a→1, aa→2), and into `21` under (aa→2, a→1).
MultiReader is the monoid of streams whose unit is the empty reader.

**Three conditions of a spread, read off Go's source:**
1. **Sharing.** The table is handed over by reference. That is sound because all three copy it and
   none writes it (`append([]string(nil), oldnew...)`; `make` and `copy`; a new slice).
2. **Variance.** A table of concrete readers is not a table of `io.Reader`, because a pointer and an
   interface value are represented differently, so the conversion would copy. A table written at the
   call is built at the declared element (`[]io.Reader{v1, v3}`). One bound to a name keeps its
   elements' join and is refused: *rs is array go/strings.Reader, but array go/io.Reader is required
   here*. That is sound. Typing a literal's element from its uses is the principled extension, and
   none of the six names needs it.
3. **The domain.** The even count is the precondition of flattening (A×A)* into a single list.

The `strings.oro` and `io.oro` headers no longer call it a wall.

## 3. What failed first

1. **The precondition was refused on a literal.** `(strings.NewReplacer (array "a" "1" "b" "2" "c"
   "3"))` gave *requires rem(len((array …)), 2) <= 0, which does not follow*. A definition's `where`
   is reduced, so the reducer folds `len` of a literal and `%`. A host declaration's `where` went to
   the refinement layer alone, whose fragment is linear. **Fixed by the third route**,
   `core.Evaluate` (refinements.md §3a): the instantiated goal is reduced by the reducer's own folding
   before the fragment is asked. An odd literal is now refused with *which is false at this call*. A
   table the prover knows nothing about is still refused, and a caller that declares the evenness in
   its own `where` is proven by the assumption route.
2. **The host check could not read the manifest's own types.** Go's API lists a package's types
   unqualified (`*Replacer`, `Reader`), and the reader marked them unreadable. It now qualifies them
   with their package (`goToHandIn`).
3. **The `Replacer` companion was unchecked** until its module was listed. Once listed, the check
   found both methods missing `(import "strings")`.

## 4. The check

`gauntlet/stdlib/tooling_test.go` reads a **spread** automatically: a hand name the survey lacks
whose last parameter is a table and whose template ends `...)`. It compares the spread with the
manifest's line, as the fixed parameters followed by `array T`. No list is kept, so every spread is
checked. Two planted mistakes are caught: a table of the wrong element, and a template that does not
spread.

## 6. Measured

- Declared: **290 of 590 (49.2%)**, from 284 (48.1%). G is gone from the causes.
- Emission is byte-identical across the corpus: no program called a host `where` that evaluation now
  decides differently.

## 7. Not built

- Typing a table literal's element from its uses, so a bound table of concrete readers can be passed
  as `io.Reader`s (condition 2).
- Evenness of a length built at run time: divisibility by a constant, Presburger arithmetic, which is
  decidable (Cooper 1972). It waits for a program that builds the pairs dynamically.
- The generator could now declare variadics over one type itself, since Go's own typing rule
  justifies `(array T)` (ADR 0023). Not done: the hand declarations come first.

# Part 2: H, a variadic over `any`

hamza chose option C ("more honest"), and kept the language's `any` (ADR 0045).

## 8. What it is

The language's `any` is no type: the absence of a claim, filled in at each call, so a declaration over
it has a fixed number of holes (`Println`, `Println2`, `Println3`), and `(array any)` was refused by
the IR as *not final*. Go's `any` is the empty interface, ∃X. X, a box: a type, so `...any` is a table
of boxes, Go's `[]any`, and H is G over Go's box.

- `go.Value` (`targets/go/builtin.oro`) is Go's `any` as a host type.
- `(implements any go.Value)` (`targets/go/go.oro`) says it has no methods, and the edge is derived
  for every type held as one host value (`Target.oneHostValue`, spec/types.md §3.3): no per-type
  list.
- `fmt.oro` declares each function for one value under Go's name and for any number as NAME-All:
  `Print`, `Println`, `Printf`, `Sprint*`, `Fprint*`, `Errorf`, and H's `Append`, `Appendln`,
  `Appendf`. The 20 two- and three-operand declarations are gone. 220 of the corpus's 231 print calls
  pass one value, so the one-value forms keep Go's names.

## 10. What failed first

1. **`(array any)` was refused by the IR**, *not final*: the language's `any` has no representation.
   That is the finding that separates the two `any`s.
2. **A declared box with no rule refused `42`**, *an integer literal is int, but go/fmt.Value is
   required*: the edge must exist. Declaring it per type worked and was a closure stated by hand, so
   the edge is derived.
3. **The type was keyed wrong.** Declared at the top of `go.oro`, `Value` had no module and the printer
   emitted `[]/*go.Value?*/{…}`. A type is owned by its module, so it lives in `(module go …)` with
   `go.bytestring`.
4. **A table of tuples reached a host cut down to its first components, and that predates H.**
   `(strings.Join (array (tuple "a" "1") (tuple "b" "2")) "-")` emitted
   `strings.Join([]string{"a", "b"}, "-")` on the previous commit: a wrong answer. The checker does not
   type a tuple, and lowering took the first value of a term that yields several, in 19 places
   (`l.value(t, r)[0]`). A position that holds one value now refuses several (`lowerer.single`).
5. **That refusal found another wrong program**: an emit test had compared a `result` with `io.EOF`
   since ADR 0044. It compared the tag, and the emitted Go did not compile, which nothing checked
   because the test never compiles Go. It now reads the error through the result.
6. **A `Print` statement's value is its first argument**, so `factorials.oro`'s loop exit, which had
   returned `n` through `Println2`, returned the table through `PrintlnAll`, and its exits disagreed.
   The exit now returns `n` explicitly. The output is identical to the previous commit's.
