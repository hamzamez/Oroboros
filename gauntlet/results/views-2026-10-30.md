# views-2026-10-30: ADR 0084's portable part, program first

The 10-24 plan's 6b, step 3: [ADR 0084](../../docs/decisions/0084-an-address-is-an-integer-and-ownership-is-a-view.md)
(an address is an integer, ownership a view), the part that runs on every target, built for one
program. hamza: "go ahead with the build, program first. always mathematical and algebraic."

## 1. The program

[examples/pe/pe.oro](../../examples/pe/pe.oro) reads a Windows executable's headers and section table,
and checks and sets its checksum: what Go's `debug/pe` reads and what imagehlp's `CheckSumMappedFile`
computes.

```
pe FILE        machine, sections, timestamp, characteristics, magic, entry, image base,
               each section, and the stored and computed checksums
pe FILE OUT    the same, and OUT a copy of FILE with its checksum set
```

It uses each agreed piece once:

| piece | in the program |
|---|---|
| separation, a set a program names | `set Head = set { t ∈ Array(0..255) : len(t) <= 4096 }` |
| `out` on a set of tables (U3) | `(buf, read) = os.ReadAt(path, 0, out Head)`: a fresh region of Head's longest length, filled by the host |
| a segment as a view | `buf[0:n]`, the filled part; `h[o:o + 8]`, a section's name |
| codecs | `bytes.get(h, p + 4, u16)`, `u32`, `u64`, all little-endian |
| the linear result | `var b := bytes.copy(src)`, then `bytes.put(b, at, u32, c)` and `os.WriteFile(out, b)` |

**The reference** is `experiments/pe/ref`: Go's `debug/pe` for the headers, the raw eight bytes of
each section name (which `debug/pe` resolves through the string table), and
`MapFileAndCheckSumW` from imagehlp for both checksums.

## 2. Measured

**Correctness.** On eight files (`notepad.exe`, `kernel32.dll` and `cmd.exe` from System32, the
32-bit `notepad.exe` and `kernel32.dll` from SysWOW64, `explorer.exe`, and this repository's Go
binaries `gen.exe` and `build.exe`), the program prints exactly the reference's lines on Go, the JVM
and JavaScript. On `notepad.exe`, the checksum it computes equals the one the linker stored.
`pe gen.exe OUT` writes a copy that differs from `gen.exe` in exactly the checksum's bytes, the
three targets' copies are byte-identical, and Windows' function reports stored = computed on it.

**Proofs.** Every integer operation is proven inside its target's word and every loop proven to
terminate: 340 of 340 and 20 of 20 on Go and the JVM, 364 of 364 and 20 of 20 on JavaScript, where
the 64-bit image base is held as a pair.

**A differential case**, `codecs`, runs the codecs (u16, u32, u64, big-endian, signed, a partial one
through `check`), a segment and two linear copies at run time, and agrees with Python on Go,
JavaScript and the JVM.

## 3. What was built

| | algebra | where |
|---|---|---|
| **separation** `set { x ∈ S : φ }` | χ = χ_S ∧ φ: a binder in it is a binder in S and φ, a parameter's `where` or a result's `ensure` | J's reader; D (`core/decl.go`, `separated`) |
| **a set definition** `set Head = S` | an explicit definition, eliminable (Padoa): unfolded where used | J's reader |
| **a segment** `b[lo:hi]` | k ↦ b(lo + k) on [0, hi − lo), formed where 0 ≤ lo ≤ hi ≤ len b; a rule, so it fuses | J's reader; δ (`core/reduce.go`, `segment`) |
| **a rule's domain** | (table n f)(i) = f(i) for i ∈ [0, n): kept as an obligation | `betaTab` |
| **`inf` and `sup`** | a range's least and greatest elements, static; a range is a static value, copied freely, refused at run time (Law S) | δ; `staged` |
| **codecs** | partial isomorphisms Bᵏ ⇀ S, (k, inf S, sup S, order); d = Σ bᵢ·256ⁱ, sign extension u ⊕ 2^{8k−1} − 2^{8k−1}, encoding v & (2^{8k} − 1) = v mod 2^{8k} on ℤ | `lib/bytes.oro` |
| **the linear result** | a scope is a state transformer (Theorem V): moving a region composes two scopes, `adopt (build n (λr. R)) (λb. B) = build n (λr. (λb. B) R)`; any other initializer is copied in | `adopt`, `owned`; `writtenCells` |
| **`out` on a set of tables** | a fresh region of S's supremum length, lent to the call; the rest of the block runs in its scope | J's reader (`outTables`) |

## 4. What failed first

Each is now a test with a planted fault (`emit/adr0084_test.go`), checked to fail with its rule removed.

- **A rule's index past its end was accepted** (pre-existing). `((table n f) i)` reduced to `(f i)` with
  no domain, so an 8-byte segment read at index 8 returned the byte after it. The index now carries
  0 ≤ i < n, split as ADR 0075 splits a bound: 0 ≤ i a range the IR decides, i < n a relation the
  refinement layer decides.
- **A buffer a host filled was read as its zero fill** (pre-existing, newly harmful). A `build`'s buffer
  starts as {0}, and a host's in-place write was bound to the same value, so every read after
  `os.ReadAt` was "proven" 0. The 342 "proven" operations of the first build were vacuous, and on
  JavaScript the realization chosen from that interval was 32-bit `|`, which printed an image base of
  0x40000000 for 0x140000000. A host's in-place write now joins its parameter's declared element set.
- **Honest facts then found the program's own faults**: the checksum's odd-byte arm continued with
  `i + 2`, which can leave the word; and a guard `i + 1 < len && (i == at || …)` lowered to a computed
  Boolean, losing the bound. The sum now runs over w = ⌊len/2⌋ words, 2j + 2 ≤ 2⌊len/2⌋ ≤ len.
- **The decoders used `|`** for disjoint digits. That equals `+` on ℤ, but JavaScript's `|` is 32-bit:
  decoding is now the sum, exact on every target.
- **`string_of` of a byte was refused** (pre-existing): its domain, x ≤ 55295 ∨ x ≥ 57344, was a
  disjunction only the refinement layer saw. ADR 0075's reading extends to a finite union of ranges,
  [0, 55295] ∪ [57344, 1114111], decided on the IR's intervals; the refinement layer gets the host's
  disjunction back when they do not prove it.
- **A `where` calling a helper of its module** (`width(c)`) was never resolved to the module.
- **A where-mark's condition** was never reduced again after a value was substituted into it, and an
  obligation inside it was not its own; both hoisted.
- **A claim was not a fact.** `v ∈ S = e`, once proven, now bounds v for the refinement layer: each
  decoder arm claims [0, 2^{8k}), which the IR proves of a sum of bytes.
- **A written `var` was a cell** unless initialized by an array literal, and a cell lent to a borrowing
  callee was refused. A binder written element by element, directly or through a borrow, is a buffer
  (`writtenCells`).
- **Locally nameless terms**: rebuilding a λ from `Body()` shifted its outer indices twice. The move is
  built closed.
- **Template holes**: a group result named its destinations by component, counting a buffer written
  in place, which has no host value.

## 5. Not built

- **A product of codecs** (a record) and a power (a fixed array): a codec holding codecs is a
  recursive static value, the algebra of sorts' (spec/typevalues.md §10).
- **A signed 8-byte codec**, whose unsigned reading lies in the unsigned word.
- **A segment moved out as a linear result**, and two segments of one buffer lent at once.
- **Uninit on LLVM**: `out` allocates zeroed on every target, which the three managed hosts do anyway.
- **The refinement layer's gaps**, each worked around: a table's element set is unknown to it, and a
  buffer's length through a loop of stores (a `get` after `put`).
- **A definition that borrows and returns a pair** counts one result component, so the program binds
  `read` whole.
- **LLVM's attributes, handles as host types, allocation by place**: with `ir/llvm`. **P4, P5, record
  layout as codecs**: with 6d.

## 6. Cost

**The check** (`cmd/check -skip tooling`) passes every step. The corpus counts move to **4,008 of
4,060** integer operations proven and **476 of 499** loops, with the new program, library and case; the
two unproven operations added are the 64-bit codec on windows, which MASM has no unsigned word for
(the case skips windows; `ir/llvm` will realize it). Every existing program's emission is unchanged
except `roundtrip.oro`, which now calls `os.ReadAt` so that every host runs it.

**One compile is slower, accepted for review**: `examples/os/wc.oro` on Go, about 2× (765 → 1,562 ms
paired). A rule's index now carries its domain. A literal length makes it a range on the index,
decided on the IR's intervals at no cost; `wc` indexes four rules of symbolic length, i < len(av) − 2,
a relation only the refinement layer decides, and one such obligation runs that layer's walk over the
whole program, which `wc` did not need before. Measured: with the relation's mark alone removed, 857
ms. The obligation is the soundness fix itself; a relational IR route for it is not built.

**Size**: the compiler grew by about 1,560 lines (`core`, `emit`, `ir`, `cmd`, tests included), the
libraries, programs and cases by about 400, of which the language's own code is `examples/pe` (about
150 lines) and `lib/bytes` (about 190). The balance ran the usual way.
