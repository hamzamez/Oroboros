# work-2026-10-22: work stays where it was written

ADR 0071, the 10-21 plan's item 1 (assessment-2026-10-21 §5). Found reading `shape`'s Go in the 10-21
round (observer-2026-10-21 §5): β substituted a pure value used once into a loop's body, where it ran
on every iteration.

## 1. What it is

β's one-occurrence rule, `let x = e in E[x] ⟶ E[e]` for a pure e, preserves meaning (ADR 0010) and
multiplies e's cost by the number of times E evaluates its hole. It counted occurrences in the text.
It now counts **evaluations** in the semiring {0, 1, ω}, where a λ multiplies its body by its shot: 1
for a β-redex, `let`, `build`, `build-map` and an elimination's continuation; ω for `loop`'s body,
`table`'s rule, and a λ handed to a definition, a primitive or a parameter holding a λ
(`core/work.go`). This is Moran and Sands' improvement theory for call-by-need: substitution is an
improvement exactly when the hole runs at most once, or e is a value. It is GHC's OnceInLam
(Peyton Jones and Marlow 2002).

The witness, before (Go):

```go
for ; ; v23 = (v23 + 1) {
    ...
    v30 := (v4 * v4)      // n * n + 7, written once, before the loop
    v32 := (v30 + 7)
```

and after: `v9 := (v4 * v4)`, `v11 := (v9 + 7)` before the `for`.

## 2. What else it took

Each found by a test failing once the count changed:

- **Let-floating** (Peyton Jones, Partain and Santos 1996). A static pair with a computed length
  normalizes to `(let (alen p) (fn (n) (fn (sel) …)))`. That is not a value, so it was bound, and
  `dot`'s fusion stopped (`TestSameTermTwoNormalForms`, `TestSourceLetCannotBlockFusion`). Now
  `n := alen p` is bound at the redex and the λ substituted.
- **β's rule on a residual let.** A binder made for an ω use under a λ handed to a definition (an
  `expect` arm, the cell translation's state) is left with one evaluation once that λ is applied by
  staging. `reduceLet` substitutes only duplicable values, so the binding stayed
  (`TestExpectContinuesOnSuccessAndCrashesOtherwise`, `TestACellReducesToTheLoopVariableItMeans`,
  `TestTheUnitAndADiscardInsideASequence`). It now applies β's own rule. effects.md §7c's table-read
  guard holds there on any spelling of the variable (`readsTable`). The first version used
  `readsBoundTable`, which knows only a bound index, and moved `ls`'s `av[1]` past its host calls. The
  answer was harmless, since `os.Args` is immutable, but on a buffer it is the swap miscompile.
  Witness: `TestATableReadStaysBeforeAnImpureBodyThroughALet`.
- **The IR reads a measured length as the length.** With `len(a)` bound before `dot`'s loop, the IR's
  length π and §9.4's re-slicing, which looked for `len X` measured inside the loop, lost `v1[:n]`. Go
  would then bounds-check `v1[i]`. A guard on a value defined as `len x` now guards x's length
  (`lenOfV`, `lenBinder`), and `restrict` takes the guard's own n as its bound.
- **Lowering truncated a let's several values.** `l.push(vs[:1], …)` kept a variant's tag and dropped
  its slot. Binding `lib/os`'s payload outside its constructor reached that path, and only W5 caught
  the ill-typed result. Lowering now refuses with `single`'s reason, as it did before.
